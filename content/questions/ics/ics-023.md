递归函数

```c
long f(long n) {
    if (n <= 1) return 1;
    return f(n - 1) + f(n - 2);
}
```

回答：

(1) `f(5)` 的值是多少？

(2) 计算 `f(5)` 的整个过程中，`f` 一共被调用多少次（包括最初的一次）？

(3) 递归调用链最深时，同时有多少个 `f` 的活动记录？

(4) 若每个活动记录占 32 字节，最深时这些活动记录共占多少栈空间？

## 提示

先手算小值，找出递推。调用次数也满足递推：一次调用加上两个子调用的次数。最长调用链沿着 \(n-1\) 一直往下走。

## 解析

**(1)** 由定义：

\[
f(0)=f(1)=1,
\]

\[
f(2)=f(1)+f(0)=2,
\]

\[
f(3)=f(2)+f(1)=3,
\]

\[
f(4)=f(3)+f(2)=5,
\]

\[
f(5)=f(4)+f(3)=5+3=8.
\]

**(2)** 设 \(T(n)\) 为计算 `f(n)` 时 `f` 的调用总次数（含自身）。基例

\[
T(0)=T(1)=1.
\]

对 \(n\ge2\)，一次调用加上两个子调用的次数：

\[
T(n)=1+T(n-1)+T(n-2).
\]

依次算：

\[
T(2)=1+1+1=3,\qquad T(3)=1+3+1=5,
\]

\[
T(4)=1+5+3=9,\qquad T(5)=1+9+5=15.
\]

所以一共调用 \(15\) 次。

**(3)** 最长的一条链是

\[
f(5)\to f(4)\to f(3)\to f(2)\to f(1),
\]

其中 \(f(1)\) 是基例，不再向下调用。这条链上同时存活 \(5\) 个活动记录。另一条 \(f(5)\to f(4)\to f(3)\to f(2)\to f(0)\) 长度也是 \(5\)。所以最深时同时有 \(5\) 个。

**(4)** 每个活动记录 32 字节，最深时

\[
5\times32=160\ \text{字节}.
\]

结论：**(1) `f(5) = 8`；(2) 共调用 \(15\) 次；(3) 同时有 \(5\) 个活动记录；(4) 共占 \(160\) 字节栈空间。**

## 常见错误

一是把 `f(0)` 当成 \(0\)，按标准斐波那契算得 `f(5)=5`；本题基例返回的是 \(1\)。二是只数最长链上的 \(5\) 次调用，把「调用次数」与「栈深度」混为一谈——递归树会分叉，总调用次数远大于深度。三是把栈深度算成 \(6\)，把 `main` 的栈帧也算进 `f` 的活动记录。四是算栈空间时按 \(4\) 层或 \(6\) 层乘，得到 \(128\) 或 \(192\)。
