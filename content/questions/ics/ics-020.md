函数 `f` 的参数 `a`（`long` 数组首地址）放在 `%rdi`，元素个数 `n` 放在 `%rsi`，返回值放在 `%rax`。汇编如下：

```
    movl $0, %eax
    movl $0, %ecx
.L2:
    cmpq %rsi, %rcx
    jge .L3
    movq (%rdi,%rcx,8), %rdx
    testq %rdx, %rdx
    jle .L4
    addq %rdx, %rax
.L4:
    addq $1, %rcx
    jmp .L2
.L3:
    ret
```

回答：

(1) 写出等价的 C 函数。

(2) 若数组为 \(\{3,-1,4,0,-5,9\}\)、\(n=6\)，返回值是多少？

(3) 上述执行过程中，循环体（从 `movq` 到 `jmp`）执行了几次？`cmpq` 执行了几次？

(4) 若 \(n=0\)，返回值是多少？

## 提示

`jge` 是有符号「大于等于」，这里的 `cmpq %rsi, %rcx` 在判断 \(i\ge n\) 是否成立。`testq %rdx, %rdx` 后接 `jle`，是在跳过所有小于等于 \(0\) 的元素。注意 `%rax` 在循环前已被清零。

## 解析

**(1)** `%rcx` 是下标 \(i\)，`%rax` 是累加和。循环条件 `i >= n` 时退出，否则取出 `a[i]`；若 `a[i] > 0` 就累加，否则跳过。等价 C 代码：

```c
long f(long *a, long n) {
    long s = 0;
    for (long i = 0; i < n; i++)
        if (a[i] > 0)
            s += a[i];
    return s;
}
```

**(2)** 只累加正数：

\[
3+4+9=16.
\]

\(-1\)、\(0\)、\(-5\) 都被 `jle` 跳过。

**(3)** 下标 \(i=0,1,2,3,4,5\) 时循环体各执行一次，共 \(6\) 次；\(i=6\) 时 `cmpq` 判断 \(6\ge6\) 成立，直接跳到 `.L3`。所以 `cmpq` 一共执行

\[
6+1=7
\]

次。

**(4)** \(n=0\) 时，第一次 `cmpq` 就满足 \(0\ge0\)，直接返回。由于循环前执行了 `movl $0, %eax`，返回值是 \(0\)。

结论：**(1) 返回数组中所有正数元素之和；(2) 返回 \(16\)；(3) 循环体 \(6\) 次，`cmpq` \(7\) 次；(4) 返回 \(0\)。**

## 常见错误

一是把 `jle` 当成无符号比较，或者把 \(0\) 也算进和里。二是把循环体执行次数数成 \(7\)：第 7 次只做了条件判断，没有进入循环体。三是忽略 `movl $0, %eax`，认为 \(n=0\) 时返回值不确定。四是把 `(%rdi,%rcx,8)` 当成 `a[i]` 的地址却忘了 `long` 是 8 字节，比例因子写成 \(4\) 或 \(1\)。五是把 `%rcx` 与 `%rdx` 的用途弄反：`%rdx` 只是临时存放当前元素。
