函数 `f` 的两个 `long` 参数 `x`、`y` 分别放在 `%rdi`、`%rsi`，返回值放在 `%rax`。汇编如下：

```
cmpq %rsi, %rdi
setl %al
setg %dl
movzbl %al, %eax
movzbl %dl, %edx
addl %edx, %eax
ret
```

回答：

(1) 这段代码相当于 C 的什么表达式？

(2) 求 \((x,y)=(3,5)\)、\((5,3)\)、\((4,4)\) 时的返回值。

(3) 如果把 `setl` 换成 `setb`，对 \((x,y)=(-1,1)\) 返回值是多少？说明原因。

## 提示

`cmpq %rsi, %rdi` 计算的是 \(x-y\)，并设置条件码。`setl` 表示「有符号小于」，依据是 \(SF\ne OF\)；`setg` 表示「有符号大于」；`setb` 表示「无符号小于」，依据是 \(CF=1\)。`movzbl` 是零扩展，不是符号扩展。

## 解析

**(1)** `setl %al` 把「\(x<y\)」写入 `%al`，`setg %dl` 把「\(x>y\)」写入 `%dl`。两个 `movzbl` 把 1 字节的 0/1 零扩展成 32 位，最后相加。因此返回值是

```c
return (x < y) + (x > y);
```

对任意两个数，二者恰好一个成立，所以它等价于「\(x\ne y\)」的布尔值：不相等返回 \(1\)，相等返回 \(0\)。

**(2)** 代入：

- \((3,5)\)：\(3<5\) 成立，\(3>5\) 不成立，返回 \(1+0=1\)；
- \((5,3)\)：\(5<3\) 不成立，\(5>3\) 成立，返回 \(0+1=1\)；
- \((4,4)\)：两个都不成立，返回 \(0\)。

**(3)** 把 `setl` 换成 `setb` 后，第一个条件变成「无符号小于」。\(-1\) 的 64 位位模式是全 \(1\)，作为无符号数是 \(2^{64}-1\)，它并不小于 \(1\)，所以 `setb` 给出 \(0\)。第二个条件 `setg` 仍是有符号比较，\(-1>1\) 不成立，给出 \(0\)。两者相加返回

\[
0.
\]

但 \(-1\ne1\)，按 (1) 的语义本应返回 \(1\)。这说明一旦混用无符号比较，负数会破坏「\(x\ne y\)」这个逻辑。

结论：**(1) 返回 \((x<y)+(x>y)\)，即 \(x\ne y\) 的布尔值；(2) 依次为 \(1\)、\(1\)、\(0\)；(3) 返回 \(0\)，因为无符号比较下 \(-1\) 被视为 \(2^{64}-1\)，不小于 \(1\)。**

## 常见错误

一是把 `setl` 当成无符号比较，或把 `setb` 当成有符号比较，混淆 \(SF/OF\) 与 \(CF\)。二是把 `movzbl` 当成符号扩展：它把高 24 位清零，`%al` 里的 \(1\) 不会变成 \(-1\)。三是把 `cmpq %rsi, %rdi` 的方向记反，算成 \(y-x\)，于是 `setl`/`setg` 的含义整体颠倒。四是第 (3) 问只看 `setg` 就下结论，忘了 `setb` 对负数的结果也会变。
