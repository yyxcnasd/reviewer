有下面的 C 代码，`int` 占 4 字节，数组按行优先存放，`a` 的首地址为 `0x1000`：

```c
int a[3][4];
```

回答：

（1）`sizeof(a)` 与 `sizeof(a[1])` 分别是多少？

（2）`&a[2][3]` 的地址是多少？

（3）`a[1] + 2` 的地址是多少？它指向哪个元素？

（4）`a[1]` 与 `a` 的类型分别是什么？为什么 `a + 1` 与 `a[1] + 1` 前进的字节数不同？

（5）若 `int *p = &a[0][0];`，那么 `p + 6` 指向哪个元素？

## 提示

二维数组 `int a[3][4]` 的元素是「4 个 int 组成的一维数组」。地址偏移公式是「行下标 × 列数 + 列下标」再乘以元素大小。指针加法按「所指类型的大小」缩放：`a` 指向一行（16 字节），`a[1]` 指向一个 int（4 字节）。

## 解析

二维数组的地址计算只需抓住两件事：行优先存储（整行存完再存下一行）和「指针加 1 前进多少由所指类型决定」。把 `a` 看成一个「元素是 `int[4]` 的数组」，`a[i]` 就是第 `i` 个 `int[4]`，它退化为指向首元素的 `int *`；这样 `a+1` 跳过一整行 16 字节，而 `a[1]+1` 只跳过一个 int 4 字节，就都顺理成章了。

（1）`a` 是 \(3\times4\) 的 `int` 数组：
\[
\texttt{sizeof}(a)=3\times4\times4=48,
\]
\[
\texttt{sizeof}(a[1])=4\times4=16.
\]

（2）行优先下，`a[2][3]` 前面有
\[
2\times4+3=11
\]
个 `int`，所以偏移为 \(11\times4=44\) 字节：
\[
\&a[2][3]=\texttt{0x1000}+44=\texttt{0x102C}.
\]

（3）`a[1]` 指向第 1 行首元素，即 `&a[1][0]`。它的偏移是
\[
(1\times4+0)\times4=16,
\]
所以
\[
a[1]+2=\texttt{0x1000}+16+2\times4=\texttt{0x1018},
\]
指向 `a[1][2]`。

（4）`a[1]` 的类型是 `int *`（指向一行的首元素）；`a` 的类型是 `int (*)[4]`（指向「含 4 个 int 的数组」）。因此：
- `a + 1` 前进一整行 \(4\times4=16\) 字节，指向第二行；
- `a[1] + 1` 前进一个 `int` 4 字节，指向 `a[1][1]`。

（5）`p` 是 `int *`，`p + 6` 前进 \(6\times4=24\) 字节。把一维下标 6 按行优先还原：
\[
6=1\times4+2,
\]
即第 1 行第 2 列，所以 `p + 6` 指向 `a[1][2]`（与（3）的地址相同）。

## 常见错误

一是把 `&a[2][3]` 的偏移算成 \(2\times3\times4=24\)（把列数 4 写成 3，或把行、列下标相乘）。二是认为 `a + 1` 只前进 4 字节——`a` 的元素是整行，不是单个 `int`。三是把 `a[1]+2` 的地址算成 `0x1000+16+2=0x1012`，忘记乘 `sizeof(int)`。四是把 `p+6` 的行列还原算错（6 对应第 1 行第 2 列，不是第 6 个元素所在行的第 0 列）。
