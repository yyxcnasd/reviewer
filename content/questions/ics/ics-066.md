函数 `f` 的参数 `x` 放在 `%rdi`，返回值放在 `%rax`，汇编实现是

```
f:
    leaq    (%rdi,%rdi,4), %rax     # rax = 5*x
    leaq    (%rax,%rax,2), %rax     # rax = 3*(5x) = 15x
    sarq    $4, %rax                # rax >>= 4（算术右移）
    ret
```

(1) 用含 floor/ceil 的式子写出 `f(x)`，并求 `f(100)`、`f(-100)`。

(2) 若有人把这段汇编"翻译"成 C 的 `return x * 15 / 16;`，两者在什么 x 上结果不同？给出反例，并解释编译器为什么不会用 `sarq` 来实现 C 的 `/16`。

(3) `x` 取多大时，第二条 `leaq` 的中间结果会超出 64 位有符号范围？此时 C 写法是什么行为，而这段汇编实际得到什么？以 \(x=2^{62}\) 为例算出结果。

## 提示

`leaq` 只算地址、不访存，所以两条 `leaq` 是在做常数乘法；`sarq` 是**算术右移**，对负数是向下取整而不是向零取整。把「乘 15 再除 16」拆成「乘」和「移位」两步，分别检查舍入方向与溢出。

## 解析

**(1)** 两条 `leaq` 依次把 \(x\) 变成 \(5x\)、再变成 \(15x\)；`sarq $4` 是算术右移 4 位。算术右移对补码数的效果是

\[
x \gg 4=\left\lfloor \frac{x}{16}\right\rfloor
\]

（对正负都成立：\(-1 \gg 4=-1=\lfloor -1/16\rfloor\)）。所以

\[
f(x)=\left\lfloor \frac{15x}{16}\right\rfloor
= x-\left\lceil \frac{x}{16}\right\rceil .
\]

后一个等号来自 \(\lfloor x-a\rfloor=x-\lceil a\rceil\)。

数值验证：

- \(f(100)=\lfloor1500/16\rfloor=\lfloor93.75\rfloor=93\)，而 \(100-\lceil6.25\rceil=100-7=93\)；
- \(f(-100)=\lfloor-1500/16\rfloor=\lfloor-93.75\rfloor=-94\)，而 \(-100-\lceil-6.25\rceil=-100-(-6)=-94\)。

**为什么想到**：看到 `leaq` 的 `(a,b,4)` 形式先还原成「乘 5」，再看到 `sarq` 立刻换成「除以 2 的幂、向下取整」——这两步是把汇编翻成数学表达式的固定动作。

**(2)** C 的整数除法 `/` 是**向零截断**，而 `sarq` 向下取整。对负数且不能整除时，两者差 1：

\[
(-100)\times15/16=-93\quad(\text{C 向零截断}),\qquad
\left\lfloor \frac{15\cdot(-100)}{16}\right\rfloor=-94.
\]

再如 \(x=-1\)：C 得 \(0\)，汇编得 \(-1\)。正数或能整除时两者一致。

编译器不会用 `sarq` 实现 C 的 `/16`：C 规定向零截断，负数时要补一个修正（典型做法是对负数先加 \(15\)，或用 `idiv`），单独一条算术右移会改变负数的结果。**只有**在编译器能证明 \(x\ge0\)（或把除法改成无符号）时，才会放心用右移。

**(3)** 第二条 `leaq` 计算 \(15x\) 的 64 位结果，数学上超过 \(2^{63}-1\) 就发生回绕（C 的 `x*15` 此时是未定义行为）。阈值约为

\[
|x|>\frac{2^{63}-1}{15}\approx6.15\times10^{17}.
\]

汇编不会"报错"，而是按模 \(2^{64}\) 回绕。取 \(x=2^{62}\)：

\[
15\cdot2^{62}=15\cdot2^{62},\qquad
2^{64}=16\cdot2^{62},
\]

所以位模式按有符号解释是

\[
15\cdot2^{62}-2^{64}=-2^{62},
\]

再算术右移 4 位：

\[
f(2^{62})=\frac{-2^{62}}{16}=-2^{58}=-288230376151711744.
\]

**为什么想到**：要判断溢出，先确定中间结果属于哪一步（这里是 \(15x\)，不是最终值），再用 \(2^{64}\) 的模运算把回绕结果翻译回有符号数；右移只影响已经回绕后的位模式，所以"先回绕、后移位"的顺序不能反。

## 常见错误

一是把 `sarq $4` 当成"除以 16 并四舍五入"或"向零截断"，对负数算成 \(-93\)。二是只看到 `x*15/16` 就以为和汇编等价，忽略了 C 的除法向零、移位的向下取整。三是把溢出判断放在最终结果 \(15x/16\) 上——实际溢出发生在中间的 \(15x\)，\(x\) 只要超过约 \(6.15\times10^{17}\) 就回绕。四是回绕后忘记做有符号解释，把 \(-2^{62}\) 当成巨大的正数再右移，结果符号全错。
