设表达式语言只含命题变项 \(p,q,r,\dots\) 与二元联结词 \(\wedge,\vee\)。一个串称为**合法前缀式**，如果按前缀读法（先读根，再依次读左、右子表达式）它能唯一确定一个公式。对串 \(s\)，记 \(v(s)\) 为其中变项个数，\(b(s)\) 为其中二元联结词个数。

(1) 证明：\(s\) 是合法前缀式，当且仅当

\[
v(s)=b(s)+1,
\]

且 \(s\) 的每个真前缀 \(t\) 都满足 \(v(t)\le b(t)\)。

(2) 设 \(C_b\) 是含 \(b\) 个二元联结词的合法前缀式（不区分变项与联结词的具体名称）的个数。证明 \(C_0=1\)，且

\[
C_{b+1}=\sum_{i=0}^{b}C_iC_{b-i},
\]

从而 \(C_b=\dfrac{1}{b+1}\dbinom{2b}{b}\)。

(3) 说明 (1)(2) 依赖「只有二元联结词」这一条件：若允许一元联结词 \(\neg\)，令 \(b=1\)、一元联结词个数为 \(1\)、变项个数为 \(2\)，列出所有合法的前缀式并计数；再说明为什么此时不能直接套用 Catalan 公式。

## 提示

(1) 用「还差几个操作数」来想：从空串出发，读一个变项就消耗一个「待填的位置」，读一个二元联结词就把一个待填位置换成两个。于是定义

\[
S(t)=v(t)-b(t),
\]

真前缀必须满足 \(S(t)\le0\)，而整个串满足 \(S(s)=1\)。

(2) 合法串一定以二元联结词开头。把第一个二元联结词记下来，剩下的串会被唯一地切成两个合法前缀式——这个「切点」就是第一个操作数刚好读完的位置。

(3) 一元联结词不消耗两个操作数，它只把「一个位置」仍变成一个位置，所以路径的步长从 \(\pm1\) 变成了 \(-1,0,+1\) 混合。

## 解析

(1) **必要性。** 对公式结构归纳。变项 \(p\) 没有真前缀，且 \(S(p)=1\)，成立。设 \(s=\circ\,u\,w\)，其中 \(\circ\) 是二元联结词，\(u,w\) 是合法前缀式。

- 对 \(u\) 的真前缀 \(t\)，串 \(\circ t\) 是 \(s\) 的真前缀，且 \(S(\circ t)=-1+S(t)\le-1<0\)（用归纳假设 \(S(t)\le0\)）；
- 串 \(\circ u\) 是 \(s\) 的真前缀，且 \(S(\circ u)=-1+1=0\)；
- 对 \(w\) 的真前缀 \(t\)，串 \(\circ ut\) 是 \(s\) 的真前缀，且 \(S(\circ ut)=-1+1+S(t)=S(t)\le0\)；
- 整个串 \(S(s)=-1+1+1=1\)。

所以每个真前缀都满足 \(S\le0\)，且总和为 1。

**充分性。** 对串长归纳。设 \(s\) 满足两条条件。

若 \(s\) 以变项开头：若 \(s\) 的长度大于 1，则真前缀「这个变项」满足 \(S=1>0\)，与条件矛盾；所以 \(s\) 就是单个变项，合法。

若 \(s\) 以二元联结词 \(\circ\) 开头：从 \(\circ\) 之后开始扫描，取最短的非空前缀 \(u\)（连同 \(\circ\) 一起）使 \(S(\circ u)=0\)，即 \(S(u)=1\) 的最短前缀。这样的 \(u\) 存在，因为整个串 \(S(s)=1\)。由最短性，\(u\) 的每个真前缀 \(t\) 都满足 \(S(t)\ne1\)；又 \(\circ t\) 是 \(s\) 的真前缀，故 \(-1+S(t)\le0\)，即 \(S(t)\le1\)，于是 \(S(t)\le0\)。由归纳假设，\(u\) 合法。

剩下部分 \(w\) 满足 \(S(w)=1\)；对 \(w\) 的真前缀 \(t\)，\(\circ ut\) 是 \(s\) 的真前缀，故 \(S(t)=S(\circ ut)\le0\)。由归纳假设，\(w\) 也合法。于是 \(s=\circ uw\) 合法。切点由「最短性」唯一确定，这就是前缀式唯一可解的原因。

(2) 设 \(s\) 含 \(b\ge1\) 个二元联结词。由 (1)，\(s\) 以二元联结词 \(\circ\) 开头。用 (1) 充分性证明中的切法，把 \(s\) 唯一写成

\[
s=\circ\,u\,w,
\]

其中 \(u,w\) 分别含 \(i\) 与 \(b-1-i\) 个二元联结词，\(i=0,\dots,b-1\)。反过来，任取这样的 \(u,w\) 拼成 \(\circ uw\)，由 (1) 的条件逐段检查可知它合法。所以

\[
C_b=\sum_{i=0}^{b-1}C_iC_{b-1-i},
\]

即 \(C_{b+1}=\sum_{i=0}^{b}C_iC_{b-i}\)，且 \(C_0=1\)（只有一个变项）。

求通项：设 \(F(x)=\sum_{b\ge0}C_bx^b\)。由递推，\(F=1+xF^2\)，解得

\[
F(x)=\frac{1-\sqrt{1-4x}}{2x}.
\]

由二项式展开 \(\sqrt{1-4x}=1-2\sum_{b\ge0}\dfrac{1}{b+1}\dbinom{2b}{b}x^{b+1}\)，代回即得

\[
C_b=\frac{1}{b+1}\binom{2b}{b}.
\]

前几项是 \(1,1,2,5,14,\dots\)。关键的一步是把「串」翻译成「路径」：每个真前缀 \(S\le0\)、整串 \(S=1\) 的格路，正是 Catalan 结构。

(3) 允许一元 \(\neg\) 后，\(b=1\)、一元个数 1、变项个数 2 的合法前缀式有 3 个：

```
¬∧pq      # ¬(p∧q)
∧¬pq      # (¬p)∧q
∧p¬q      # p∧(¬q)
```

共 3 个，而 Catalan 给出的 \(C_1=1\) 只是「一个二元联结词、没有一元联结词」的个数（即 `∧pq`、`∨pq` 两种具体联结词下的同一种形状）。

原因是路径模型变了：变项仍使 \(S\) 加 1，二元联结词使 \(S\) 减 1，而一元 \(\neg\) 不改变 \(S\)。于是「每个真前缀 \(S\le0\)、整串 \(S=1\)」的路径不再是「\(\pm1\) 步、每步必降」的 Dyck 路，Catalan 的计数前提（每一步都是 \(\pm1\) 且从 0 出发）被破坏。但唯一可解性仍然成立，因为前缀式的语法树结构仍由前缀读法唯一确定——计数改变的是「形状的个数」，不是「可解性」。

## 常见错误

- 把条件写成「每个真前缀 \(v(t)>b(t)\)」。这是把后缀式的条件套到前缀式上；前缀式开头的第一个符号如果是二元联结词，立即 \(v=0<b=1\)，所以正确方向是 \(v(t)\le b(t)\)。
- (2) 中把切点取成「第一个 \(S\) 回到 0 的位置」却不说明为什么唯一。切点的唯一性来自「最短前缀」，这是唯一可解性的核心。
- 用 Catalan 公式时忘了先固定「只有二元联结词」。一元联结词不改变 \(S\)，必须单独计数，不能把 \(\neg\) 当作二元联结词处理。
- 把 \(C_b\) 理解成「具体公式的个数」。变项与联结词的具体名称不同，公式就不同；\(C_b\) 数的是形状，带名称的个数要再乘相应的选择数。
