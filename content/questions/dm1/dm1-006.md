用归结推理法证明

\[
(P\lor Q)\land(\neg P\lor R)\land(\neg Q\lor R)\Rightarrow R.
\]

要求：写出出发公式、子句集、每一步归结所用的子句，并说明为什么归结出空子句就说明原推理成立。

## 提示

归结法不是从结论往前推，而是把"推理正确"变成"某个公式不可满足"。要证的蕴含式是 \(A_1\land A_2\land A_3\to R\)，先把它改写成 \(A_1\land A_2\land A_3\land\neg R\)，再化成合取范式。

## 解析

关键的一步是想起定理：\(A\Rightarrow B\) 成立当且仅当 \(A\land\neg B\) 是矛盾式。所以归结法的出发公式是

\[
G=(P\lor Q)\land(\neg P\lor R)\land(\neg Q\lor R)\land\neg R.
\]

把它化成合取范式，得到四个子句，构成子句集

\[
S=\{P\lor Q,\ \neg P\lor R,\ \neg Q\lor R,\ \neg R\}.
\]

归结过程：

| 序号 | 子句 | 来源 |
|---|---|---|
| (1) | \(P\lor Q\) | 子句集 |
| (2) | \(\neg P\lor R\) | 子句集 |
| (3) | \(\neg Q\lor R\) | 子句集 |
| (4) | \(\neg R\) | 子句集（结论的否定） |
| (5) | \(\neg P\) | (2) 与 (4) 归结，消去互补对 \(R,\neg R\) |
| (6) | \(\neg Q\) | (3) 与 (4) 归结，消去互补对 \(R,\neg R\) |
| (7) | \(Q\) | (1) 与 (5) 归结，消去互补对 \(P,\neg P\) |
| (8) | \(\square\) | (6) 与 (7) 归结，消去互补对 \(Q,\neg Q\) |

为什么归结出空子句就能收工？因为每一步归结式都是两个子句的逻辑推论，所以 \(S\) 与 \(S\cup\{\text{归结式}\}\) 同可满足；出现空子句说明 \(S\) 不可满足。而 \(S\) 不可满足恰好等价于 \(G\) 是矛盾式，也就等价于原推理 \(A\Rightarrow R\) 成立。这条链子每一步都能写出来，所以归结法是可靠的。

## 常见错误

- 出发公式写成 \(A\lor\neg R\) 或只取 \(\neg R\)，这等于在证别的东西。必须是 \(A\land\neg R\)。
- 归结一次就把用过的子句删掉。归结式要加入 \(S\)，但原子句仍然保留，后面还可以再用。
- 把 \(\neg P\lor R\) 与 \(\neg R\) 归结错成 \(\neg R\) 或 \(\neg P\lor\neg R\)。消去 \(R\) 与 \(\neg R\) 后只剩 \(\neg P\)。
- 只归结出一个单文字就宣布证完；必须有空子句，即两个互补的单文字归结。
- 把推理演算的分离规则混进来。归结是"纯机械"的方法，不能中途用假言推理。
