## 数据表示

### 补码与整数范围

结论：\(n\) 位无符号整数的范围是 \([0,2^{n}-1]\)；补码表示的有符号整数范围是 \([-2^{n-1},2^{n-1}-1]\)。同一串位按两种解释读出的值一般不同。

| 位数 | 无符号范围 | 补码范围 |
| --- | --- | --- |
| 8 | \(0\sim255\) | \(-128\sim127\) |
| 16 | \(0\sim65535\) | \(-32768\sim32767\) |
| 32 | \(0\sim2^{32}-1\) | \(-2^{31}\sim2^{31}-1\) |
| 64 | \(0\sim2^{64}-1\) | \(-2^{63}\sim2^{63}-1\) |

条件：补码与无符号共用同一套加法电路，按位取反再加 \(1\) 就是相反数的补码，即 \(-x=\sim x+1\)。

例：8 位下 \(5=\texttt{00000101}\)，所以 \(-5=\texttt{11111011}\)（`0xFB`）。`0xFF` 按无符号读是 \(255\)，按补码读是 \(-1\)。

### 溢出判断

结论：无符号加法看进位标志 CF，和小于任一加数即溢出；补码加法看溢出标志 OF，同号相加而结果异号即溢出（等价说法：最高位的进位与次高位的进位不同）。

条件：减法 \(a-b\) 按 \(a+(-b)\) 处理，两条规则照用；`lea` 只算地址、不写标志，所以不能用它判断溢出。

例：8 位 \(127+1\)：`0x7F + 0x01 = 0x80`，补码读作 \(127+1=-128\)，同号变号，OF=1；无符号 \(127+1=128\) 没进位，CF=0。反过来 `0xFF + 0x01 = 0x00`：无符号 \(255+1\) 溢出，CF=1；补码 \(-1+1=0\)，OF=0。

### 移位与符号扩展

结论：`shl`/`sal` 左移、低位补 0，相当于乘 \(2^{k}\)；`shr` 逻辑右移、高位补 0，用于无符号除以 \(2^{k}\)；`sar` 算术右移、高位复制符号位，用于补码除以 \(2^{k}\)（向负无穷取整）。

条件：移位量只取低若干位，32 位指令取 \(\bmod 32\)，64 位取 \(\bmod 64\)，所以 `shl $35, %eax` 实际只移 \(3\) 位。

符号扩展：`movsx` 把源操作数的符号位复制到高位（如 `movsbl`、`movswl`，以及 `eax` 到 `rax` 的 `cltq`）；`movzx` 高位补 0（如 `movzbl`、`movzwl`）。

例：8 位 `0x80` 按补码是 \(-128\)，符号扩展到 16 位得 `0xFF80`，仍是 \(-128\)；零扩展得 `0x0080`，变成 \(128\)。

### 字节序

结论：x86-64 是小端（little-endian），多字节数据的低字节放在低地址；大端（big-endian）相反，高字节在低地址。

例：32 位数 `0x12345678` 从地址 \(a\) 开始存放，小端在 \(a,a+1,a+2,a+3\) 处依次是 `78 56 34 12`，大端是 `12 34 56 78`。

条件：字节序只影响多字节标量（`int`、指针、浮点数）的存储顺序，字符数组和按字节访问不受影响；网络协议通常用大端。

## 浮点数（IEEE 754）

### 字段布局

结论：IEEE 754 单精度 32 位：符号 \(s\) 占 1 位、阶码 \(e\) 占 8 位、尾数 \(f\) 占 23 位，偏置 \(127\)；双精度 64 位：符号 1 位、阶码 11 位、尾数 52 位，偏置 \(1023\)。规格化数的值为

\[
(-1)^{s}\times(1.f)\times2^{e-\text{bias}}.
\]

| 格式 | 总位数 | 符号 | 阶码 | 尾数 | 偏置 |
| --- | --- | --- | --- | --- | --- |
| 单精度 | 32 | 1 | 8 | 23 | 127 |
| 双精度 | 64 | 1 | 11 | 52 | 1023 |

例：单精度下 \(12.5=1100.1_{2}=1.1001_{2}\times2^{3}\)，阶码 \(e=3+127=130=\texttt{10000010}\)，尾数取 `1001` 后面补 0，拼起来是 `0x41480000`。

### 规格化、非规格化与特殊值

结论：按阶码 \(e\) 分三类（以单精度为例，双精度把 \(127\) 换成 \(1023\)、位数换成对应值）：

- \(1\le e\le254\)：规格化数，\(E=e-127\)，值 \((-1)^{s}(1.f)2^{E}\)。
- \(e=0\)：非规格化数，\(E=1-127=-126\)，值 \((-1)^{s}(0.f)2^{-126}\)；\(f=0\) 时是 \(\pm0\)。
- \(e=255\)：特殊值，\(f=0\) 是 \(\pm\infty\)，\(f\ne0\) 是 NaN。

非规格化的作用：在 \(0\) 附近给出等间距的数，避免下溢时直接跳到 \(0\)。

例：`0x00000000` 是 \(+0\)，`0x80000000` 是 \(-0\)，`0x7F800000` 是 \(+\infty\)，`0xFF800000` 是 \(-\infty\)，`0x7FC00000` 是 NaN。

### 范围、舍入与 ulp

结论：单精度最大规格化数约 \(3.4\times10^{38}\)，最小规格化数 \(2^{-126}\approx1.18\times10^{-38}\)，最小非规格化数 \(2^{-149}\approx1.4\times10^{-45}\)；双精度对应约 \(1.8\times10^{308}\)、\(2.2\times10^{-308}\)、\(4.9\times10^{-324}\)。

舍入模式四种：向偶数舍入（默认）、向零、向 \(+\infty\)、向 \(-\infty\)。

ulp（末位单位）：规格化数在 \(2^{E}\) 处的间距是 \(2^{E-23}\)（单精度）、\(2^{E-52}\)（双精度）；在 \(1.0\) 处单精度 ulp 是 \(2^{-23}\approx1.19\times10^{-7}\)，双精度是 \(2^{-52}\approx2.2\times10^{-16}\)。

例：单精度下 \(1+2^{-23}\) 能表示，\(1+2^{-24}\) 正好落在两个可表示数中间，按向偶数舍入得 \(1\)。

## 汇编基础

### 常用指令

结论（AT&T 语法，源操作数在前、目的在后）：

| 指令 | 作用 | 例 |
| --- | --- | --- |
| `mov` | 传送，不写标志 | `mov %eax, %ebx` |
| `lea` | 算有效地址，不访存 | `lea 8(%rdi,%rsi,4), %rax` |
| `add`/`sub` | 加/减，写条件码 | `add $1, %rax` |
| `imul` | 有符号乘 | `imul %rsi, %rax` |
| `sal`/`shl` | 左移 | `sal $2, %eax` |
| `sar` | 算术右移 | `sar %cl, %eax` |
| `shr` | 逻辑右移 | `shr $1, %eax` |
| `and`/`or`/`xor`/`not` | 位运算 | `xor %eax, %eax`（清零） |
| `cmp` | 做减法但不写回，只设标志 | `cmp %rsi, %rdi` |
| `test` | 做与但不写回，只设标志 | `test %rax, %rax` |
| `jmp` | 无条件跳转 | `jmp .L1` |
| `jcc` | 条件跳转 | `je .L1` |
| `call` | 压返回地址并跳转 | `call foo` |
| `ret` | 弹出返回地址并跳转 | `ret` |
| `push`/`pop` | 压栈/出栈，`rsp` 减/加 8 | `push %rbp` |
| `inc`/`dec` | 自增/自减 | `inc %eax` |

条件：`cmp a, b` 计算的是 \(b-a\)，`test a, b` 计算的是 \(b\wedge a\)，两个都把结果丢掉、只留标志。

### 寻址方式

结论：内存操作数写作 `D(Rb,Ri,S)`，有效地址为

\[
\text{地址}=D+R[Rb]+S\cdot R[Ri],
\]

其中 \(D\) 是常数偏移，\(Rb\) 是基址寄存器，\(Ri\) 是变址寄存器，比例因子 \(S\in\{1,2,4,8\}\)。

省略形式：`(%rax)` 只有基址；`8(%rax)` 基址加偏移；`(%rax,%rdx,4)` 基址加变址乘 4；`8(,%rdx,4)` 只有变址加偏移。

例：`mov 8(%rdi,%rsi,4), %rax` 把地址 \(rdi+4rsi+8\) 处的 8 字节读入 `%rax`；`lea (%rdi,%rsi,4), %rax` 只算地址，结果是 \(rax=rdi+4rsi\)，常被编译器用来做三操作数加法。

### 条件码与条件跳转

结论：`cmp`/`sub` 设置四个标志——CF（无符号进位/借位）、ZF（结果为零）、SF（结果为负）、OF（有符号溢出）；`test` 只设 ZF、SF，并把 CF、OF 清零。

| 指令 | 含义 | 条件 |
| --- | --- | --- |
| `je`/`jz` | 等于/为零 | ZF=1 |
| `jne`/`jnz` | 不等 | ZF=0 |
| `jg`/`jnle` | 有符号大于 | ZF=0 且 SF=OF |
| `jge`/`jnl` | 有符号大于等于 | SF=OF |
| `jl`/`jnge` | 有符号小于 | SF≠OF |
| `jle`/`jng` | 有符号小于等于 | ZF=1 或 SF≠OF |
| `ja`/`jnbe` | 无符号大于 | CF=0 且 ZF=0 |
| `jae`/`jnb` | 无符号大于等于 | CF=0 |
| `jb`/`jnae` | 无符号小于 | CF=1 |
| `jbe`/`jna` | 无符号小于等于 | CF=1 或 ZF=1 |
| `js`/`jns` | 符号位为 1/0 | SF=1 / SF=0 |
| `jo`/`jno` | 溢出/未溢出 | OF=1 / OF=0 |

例：`cmp %rsi, %rdi; jg .L1` 在 \(rdi>rsi\)（按有符号比较）时跳转；把 `jg` 换成 `ja` 就变成按无符号比较。

### switch 跳转表

结论：`switch` 的 case 值密集且跨度不大时，编译器生成跳转表——每个表项是一个分支的代码地址，用 `jmp *表(,%rax,8)` 一次跳转；case 值稀疏时退回 if-else 链或二分查找。

条件：跳转表要求 case 值集中（如 \(0\sim n\)），表项 8 字节，表长由最大、最小 case 决定，缺失的 case 填 default 的地址。

例：`switch(x){case 0:…; case 1:…; case 2:…; default:…}` 生成 3 项的表，先判断 \(x\le2\)（无符号比较）再 `jmp *表(,%rax,8)`；超出范围走 default。

## 函数调用

### 调用约定与寄存器

结论（System V AMD64）：整数/指针参数依次放 `%rdi`、`%rsi`、`%rdx`、`%rcx`、`%r8`、`%r9`；浮点参数放 `%xmm0`–`%xmm7`；整数返回值在 `%rax`，浮点返回值在 `%xmm0`。超过 6 个的整数参数从右到左压栈，第 7 个参数在进入函数后位于 `8(%rsp)`（返回地址之上）。

寄存器归属：callee-saved 是 `%rbx`、`%rbp`、`%r12`–`%r15`、`%rsp`，被调用者要用就得先保存、返回前恢复；caller-saved 是 `%rax`、`%rcx`、`%rdx`、`%rsi`、`%rdi`、`%r8`–`%r11` 以及全部 `%xmm`，调用返回后调用者要自己重新加载。

例：`f(a,b,c,d,e,f,g)` 的 `g` 在 `8(%rsp)`，前 6 个依次在 6 个参数寄存器里；函数里调用别的函数前，要把自己还要用的 caller-saved 寄存器先存起来。

### 栈帧与 16 字节对齐

结论：栈向低地址增长，`%rsp` 指向栈顶。典型序言是 `push %rbp; mov %rsp, %rbp; sub $N, %rsp`，尾声是 `leave; ret`；局部变量在 `%rbp` 的负偏移处，保存的 callee-saved 寄存器也在栈帧里。

对齐规则：执行 `call` 之前 `%rsp` 必须是 16 的倍数；`call` 压入 8 字节返回地址，所以进入被调用函数时 \(rsp\equiv8\pmod{16}\)，序言里 `push %rbp` 后再 `sub` 一个 16 的倍数就能恢复对齐。

例：进入函数时 \(rsp\equiv8\pmod{16}\)；`push %rbp` 后 \(rsp\equiv0\pmod{16}\)；`sub $16,%rsp` 后仍是 \(0\pmod{16}\)，此时再 `call` 就满足要求。
若函数不 `push %rbp`，则要 `sub $8` 来补这 8 字节，才能继续调用其他函数。

## 数组与结构体

### 数组寻址

结论：一维数组 `T A[N]` 中元素 \(i\) 的地址是 \(A+i\cdot\text{sizeof}(T)\)；二维数组按行优先存放，`T A[R][C]` 中元素 \((i,j)\) 的地址是

\[
A+(i\cdot C+j)\cdot\text{sizeof}(T).
\]

指针算术：`p+i` 的地址是 \(p+i\cdot\text{sizeof}(*p)\)，步长由所指类型决定。

例：`int A[3][5]` 中 `A[2][3]` 距首地址 \((2\times5+3)\times4=52\) 字节；`int *p; p+3` 比 `p` 大 12 字节，而 `char *q; q+3` 只大 3 字节。

条件：数组名在表达式里退化为首元素地址，所以 `A[i]` 等价于 `*(A+i)`，`&A[i][j]` 才能取到元素地址。

### 结构体对齐与填充

结论：每个成员的偏移必须是其对齐要求的倍数（通常等于成员大小，最大到 8 或 16）；结构体总大小是最严格对齐要求的倍数；编译器在成员之间和末尾插入填充字节。

例：`struct {char c; int i; short s;}` 中 `c` 在偏移 0，填充 1–3，`i` 在 4–7，`s` 在 8–9，末尾补到 12，所以 `sizeof` 为 12、对齐为 4。

例：`struct {int i; char c; double d;}` 中 `i` 在 0–3，`c` 在 4，填充 5–7，`d` 在 8–15，`sizeof` 为 16；把 `d` 放到最前面可以省掉一部分填充。

条件：联合体的大小等于最大成员的大小，对齐取最严格成员的对齐；指针与 `long` 在 64 位下按 8 字节对齐。

## 缓冲区溢出

### 栈布局与攻击

结论：函数栈帧从低地址到高地址依次是局部缓冲区、保存的 `%rbp`、返回地址、调用者的栈帧（更高地址处还有栈上传入的参数）。向缓冲区写入超过其长度的数据，会依次覆盖保存的 `%rbp` 与返回地址。

条件：栈上缓冲区、输入长度不受检查、栈可执行（或能找到可用 gadget）三者具备时才可能执行注入代码；否则通常改用 ROP 串联已有代码片段。

例：`char buf[8]; strcpy(buf, 长字符串);` 中超出 8 字节的部分写进 `buf` 之上的空间，覆盖返回地址后 `ret` 会跳到攻击者指定的地址。

### 常见防御

结论：常见防御分五类：

- 栈保护（canary）：函数返回前检查栈上的哨兵值（`%fs:0x28`）是否被改，被改就调用 `__stack_chk_fail` 终止。
- ASLR：随机化栈、堆、共享库的基址，让攻击者猜不到目标地址。
- NX/DEP：把栈和堆标记为不可执行，注入的机器码无法直接运行。
- PIE 与 CFI：位置无关可执行文件配合控制流完整性检查，限制跳转目标。
- 代码层：用 `fgets`、`strncpy` 等带长度限制的函数替代 `gets`、`strcpy`，并做边界检查。

例：开启 canary 后，想覆盖返回地址必须先原样保留 canary 的值，否则函数在 `ret` 之前就被检测并终止；这也是为什么溢出攻击常要先泄露 canary。
