## 3.1 汇编基础与寻址方式

### 寄存器与操作数

x86-64 有 16 个通用寄存器：`%rax %rbx %rcx %rdx %rsi %rdi %rbp %rsp` 和 `%r8`–`%r15`。每个都有 32/16/8 位的别名（`%eax`、`%ax`、`%al`）。**写 32 位寄存器会把高 32 位清零**，这是编译器省一条指令的常用手段（例如 `movl $0, %eax` 就等价于把整个 `%rax` 清零）。

操作数有三类：立即数（`$0x10`）、寄存器（`%rax`）、内存（`(%rax)`）。AT&T 语法是「源在前、目的在后」，指令带长度后缀 `movb/movw/movl/movq`。

### 寻址方式

最通用的内存操作数是

\[
D(R_{b},R_{i},S)=\text{Mem}[R_{b}+R_{i}\times S+D],
\]

其中 \(S\in\{1,2,4,8\}\)，是元素大小。四项都可以省略：`(%rax)`、`8(%rax)`、`(%rax,%rdx,4)`、`8(%rax,%rdx,4)`。

**例**：`movq 8(%rdi,%rsi,4), %rax` 把地址 \(R_{rdi}+4R_{rsi}+8\) 处的 8 个字节读进 `%rax`。若 `%rdi` 存数组首地址、`%rsi` 存下标，它取的是 `int` 数组元素——因为比例因子 4 正好是 `int` 的大小。

### mov 与 lea 的区别

- `mov 8(%rax), %rbx`：**访存**，读地址 \(R_{rax}+8\) 处的内容。
- `lea 8(%rax), %rbx`：**只算地址**，把 \(R_{rax}+8\) 这个数放进 `%rbx`，不读内存。

`lea` 因此成了「不设条件码的算术指令」：

```
leaq (%rdi,%rdi,2), %rax   # rax = 3*x
leaq 0(,%rdi,8), %rax      # rax = 8*x
leaq 1(%rdi,%rdi,2), %rax  # rax = 3*x + 1
```

**最容易错的一步**：把 `lea` 当成 `mov`，以为它会读内存；或者看不出 `lea` 的算术含义。反汇编里大量 `lea` 其实是在做乘加运算，而不是取地址。

### 数据传送与扩展

`movz` 零扩展、`movs` 符号扩展（`movsbq` 把字节符号扩展到四字）；`push`/`pop` 操作栈；`imul` 乘法；`sal`/`sar`/`shr` 移位；`and`/`or`/`xor` 位运算。注意算术运算大多会设置条件码，`mov` 和 `lea` 不设置。

### 例：一句 C 的汇编

`long f(long *p, long i) { return p[i]; }` 的典型汇编是

```
f:
    movq (%rdi,%rsi,8), %rax
    ret
```

地址是 \(p+8i\)，8 正是 `long` 的字节数。若把 `long` 换成 `int`，比例因子就要改成 4，这是「数组寻址」题最爱考的一步。

## 3.2 分支与循环

### 条件码

CPU 用四个标志位记录最近一次算术/逻辑运算的结果：`CF`（无符号进位/借位）、`ZF`（结果为零）、`SF`（结果为负）、`OF`（有符号溢出）。`cmp`、`test`、`add`、`sub` 等会设置它们；**`mov` 和 `lea` 不设置**。

- `cmp b, a` 计算 \(a-b\) 并设标志（AT&T 顺序：后一个操作数减前一个）。
- `test b, a` 计算 \(a\&b\) 并设标志；`test %rax, %rax` 是最常用的「判零/判负」。

### 跳转指令与有符号/无符号

| 指令 | 含义 | 用于 |
| --- | --- | --- |
| `je` / `jne` | 相等 / 不等 | 两种都行 |
| `jg` / `jge` / `jl` / `jle` | 大于 / 大于等于 / 小于 / 小于等于 | **有符号** |
| `ja` / `jae` / `jb` / `jbe` | 高于 / 高于等于 / 低于 / 低于等于 | **无符号** |

**最容易错的一步**：有符号和无符号比较用错指令。\(-1\) 与 \(1\) 比较，有符号看是 \(-1<1\)，无符号看是 \(2^{64}-1>1\)，结论正好相反。汇编层没有「类型」，全看你用哪条 `jcc`。

### if-else 与循环

- `if (a <= b) ... else ...` 的典型做法：条件取反先跳到 `else`，再顺序执行 `then` 分支。
- 循环：`while`/`for` 先测试再进循环体（可能一次都不执行），`do-while` 先执行再测试（至少一次）。编译器常把循环变量的递减改成「减到 0 用 `jne`」，这样少一条比较。

**例**：

```c
long sum(long n) {
    long s = 0;
    for (long i = 1; i <= n; i++) s += i;
    return s;
}
```

对应的循环骨架大致是

```
    movl $1, %eax        # i = 1
    movl $0, %edx        # s = 0
.L2:
    cmpq %rdi, %rax
    jg .L3               # i > n 时跳出
    addq %rax, %rdx
    addq $1, %rax
    jmp .L2
.L3:
    movq %rdx, %rax
```

注意 `jg` 而不是 `ja`：`i` 和 `n` 都是有符号的 `long`。

### switch 与跳转表

当 `case` 值比较密集时，编译器生成**跳转表**：一张存着各分支地址的数组，用 `jmp *.L4(,%rdi,8)` 一次跳过去，时间复杂度 \(O(1)\)。前面通常有一条边界检查 `cmp $n, %rdi; ja default`，用**无符号**比较同时排除负数（负数作为无符号数是巨大的，`ja` 直接命中 default）。

`case` 值稀疏（比如 0、100、1000）时跳转表会有大量空洞，编译器改用比较链或二分查找。判断「该不该用跳转表」，看 `case` 值的范围是否密集。
