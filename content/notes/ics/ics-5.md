## 5.1 数组与指针

### 一维数组

声明 `T A[N]`：内存里是一段连续的 \(N\times \text{sizeof}(T)\) 字节，`A` 就是首地址，

\[
\&A[i]=A+i\cdot\text{sizeof}(T).
\]

**例**：`long a[5]`，每个元素 8 字节，`&a[3]` 相对 `a` 偏移 24 字节。若 `%rdi` 存 `a`、`%rsi` 存 `i`，取 `a[i]` 就是 `movq (%rdi,%rsi,8), %rax`。

### 指针算术

指针加减按**所指类型的大小**缩放：

```c
long a[5] = {10, 20, 30, 40, 50};
long *p = a + 2;      /* p 指向 a[2]，地址比 a 大 16 字节 */
char *c = (char *)a;  /* c 指向同一个字节，但 +1 只走 1 字节 */
```

- `p - a` 是 2（相差 2 个元素，不是 2 字节）；
- `c + 8` 与 `&a[1]` 是同一个地址；
- `*(long *)(c + 8)` 取回 `a[1]` 的值 20。

**最容易错的一步**：把「指针 + n」当成「地址 + n 字节」。`int *q = p + 1` 地址加 4；`char *q = (char *)p + 1` 地址加 1。做这类题先问一句「步长是多少字节」。

### 二维数组与行优先

`T A[R][C]` 按行优先存放，元素 `A[i][j]` 的地址是

\[
\&A[i][j]=A+(i\cdot C+j)\cdot\text{sizeof}(T).
\]

**例**：`int A[10][20]`，`int` 为 4 字节：

- `&A[3][5]` 相对 `A` 偏移 \((3\times20+5)\times4=260\) 字节；
- `A[i]` 是「行指针」，类型 `int (*)[20]`，所以 `A[i] + j` 的地址加 \(4j\)；
- `sizeof(A) = 10\times20\times4 = 800`，`sizeof(A[0]) = 20\times4 = 80`。

**最容易错的一步**：把 `A[i][j]` 的偏移算成 \((i\cdot R+j)\cdot4\)。行优先是「先走完一整行再换行」，系数是列数 \(C\)，不是行数 \(R\)。

数组作为参数传给函数时会退化成指针，`sizeof` 拿不到数组长度，必须另传长度。这也是「函数里 `sizeof(arr)` 为什么是 8」的原因。

## 5.2 结构体、联合体与对齐

### 对齐规则

编译器保证：

1. 每个成员的偏移是它自身对齐要求（通常等于自身大小，最大 8）的整数倍；
2. 结构体的总大小是「最大成员对齐」的整数倍；
3. 不满足时插入填充字节。

所以结构体的 `sizeof` 往往大于成员大小之和。

**例**：

```c
struct S {
    char   c;   /* 偏移 0 */
    int    i;   /* 偏移 4（1-3 是填充） */
    char   d;   /* 偏移 8 */
    double x;   /* 偏移 16（9-15 是填充） */
    short  s;   /* 偏移 24 */
};              /* sizeof = 32（25-31 是尾部填充） */
```

`double` 要求 8 字节对齐，所以 `d` 后空 7 个字节；结构体最大对齐是 8，所以总大小补到 32。

### 重排省空间

同样五个成员，按「大的在前、小的在后」排：

```c
struct T {
    double x;  /* 0 */
    int    i;  /* 8 */
    short  s;  /* 12 */
    char   c;  /* 14 */
    char   d;  /* 15 */
};             /* sizeof = 16 */
```

从 32 字节降到 16 字节，语义一点没变。

**最容易错的一步**：结构体数组的步长（stride）是 `sizeof(struct)`，**包含填充**。`struct S arr[4]` 里 `arr[2]` 相对 `arr` 的偏移是 \(2\times32=64\)，不是按成员大小之和算的 \(2\times26\)。

### 联合体

联合体的所有成员共享同一段内存，大小等于最大成员的大小（再按对齐取整），同一时刻只能安全地使用一个成员。常用来节省空间，或做「同一块字节的不同解释」（类型双关），但要注意字节序和对齐。考试里判断联合体大小，先取最大成员大小，再向上取整到最大对齐的倍数。
