## 这一章要会什么

- 用三种等价算法在负数与补码位模式之间来回换，并记住 TMin 取负还是它自己
- 判断无符号加法、有符号加法各自什么时候溢出，写出回绕后的结果
- 正确做符号扩展、零扩展、截断，并解释 `-1 < 0u` 为什么是假
- 拆 IEEE 754 的三段字段，认出规格化数、非规格化数、\(\pm\infty\) 与 NaN
- 用 ulp 和吸收现象解释 `0.1 + 0.2 != 0.3`、\((a+b)+c\ne a+(b+c)\)

## 2.1 整数

### 补码的三种等价算法

:::定理
条件：要在一个 \(w\) 位位模式和有符号整数之间转换。

三种算法结果相同。一是最高位权重取负：

\[
B2T(x)=-x_{w-1}2^{w-1}+\sum_{i=0}^{w-2}x_i2^{i}.
\]

二是取反加一：\(-x=\sim x+1\)。三是从右往左找到第一个 1，保留它，它左边的位全部取反。
:::

什么时候用：手算负数位模式、验证 `~x+1`、从位模式反推十进制值。


:::注意
补码范围不对称，\(-2^{w-1}\le x\le 2^{w-1}-1\)。最小值取负还是它自己，\(\abs{\text{TMin}}=2^{w-1}\) 比 TMax 大 1；8 位时 `-(-128)` 仍然是 `-128`。
:::
### 无符号与补码共用一套加法

:::定理
条件：两个 \(w\) 位整数相加或相减。

机器只做模 \(2^{w}\) 的加法，位模式相同，区别只在解释。无符号溢出看「结果小于任一加数」；有符号溢出看「同号相加、结果变号」。
:::

什么时候用：判断溢出、解释 C 的整数回绕、分析 `cmp` 之后的 `CF` 与 `OF`。


:::注意
异号相加永不溢出；无符号减法的借位等价于加 \(2^{w}\)。8 位时 \(\texttt{0x7D}+\texttt{0x0B}=\texttt{0x88}\)：无符号 \(136\) 不溢出，有符号 \(125+11\) 溢出成 \(-120\)。
:::
### 符号扩展、零扩展与截断

:::定理
条件：把整数换成更宽或更窄的类型。

符号扩展把高位全部复制符号位；零扩展高位补 0；截断丢掉高位，再按新类型重新解释。
:::

什么时候用：`(short)x`、`(unsigned char)x`、传参时的整型提升、把 `int` 放进 `long`。


:::注意
先扩展再解释，顺序不能反。\(\texttt{(char)0x1FF}\) 得 \(\texttt{0xFF}\)，作为有符号数是 \(-1\)；\(\texttt{0x8F}\)（\(-113\)）符号扩展到 16 位是 \(\texttt{0xFF8F}\)，不是 \(\texttt{0x008F}\)。
:::
### 有符号与无符号混算的转换

:::定理
条件：一个表达式里同时出现有符号和无符号。

C 先把有符号操作数转成无符号，再按无符号规则运算，负数会变成巨大的正数。
:::

什么时候用：写比较、排序，或 `strlen` 返回值参与减法时。


:::注意
`-1 < 0u` 的结果是**假**，因为 \(-1\) 先被转成 \(2^{32}-1\)；`-1 > 1u` 为真。开 `-Wsign-compare` 能在编译期抓到大部分这类问题。
:::
### 算术右移与逻辑右移

:::定理
条件：把整数右移 \(k\) 位。

无符号数用逻辑右移，高位补 0；有符号数用算术右移，高位补符号位（x86 的 `sar`）。左移都是低位补 0。
:::

什么时候用：快速乘除 \(2^{k}\)、从位模式里取字段、解析指令编码。


:::注意
`-8 >> 1` 是 \(-4\)；`(unsigned)(-8) >> 1` 是 \(2147483644\)。C 里对负数左移、移位数不小于位宽都是未定义行为，考试不要按「实际机器会怎样」去算。
:::
### 小端字节序与 `0x12345678`

:::定理
条件：把一个多字节整数存进内存，要写出各地址上的字节。

x86-64 是小端，低字节放在低地址：

\[
\texttt{0x12345678}\ \longrightarrow\ \texttt{78 56 34 12}.
\]
:::

什么时候用：缓冲区溢出时构造返回地址、理解 `char *` 强转后逐字节读、网络字节序转换。


:::注意
字节序只影响内存排布，不影响寄存器里的数值；网络传输用大端，所以有 `htons`、`htonl`。小端机器上把 \(\texttt{0x0000000000401234}\) 写进溢出字符串，要写成 \(\texttt{34 12 40 00 ...}\)。
:::
## 2.2 浮点数

### IEEE 754 的三段字段

:::定理
条件：给一个 32 位或 64 位的浮点位模式。

单精度是 \(1+8+23\) 位，双精度是 \(1+11+52\) 位，分别是符号 \(s\)、阶码 \(E\)、尾数 \(f\)。
:::

什么时候用：拆位、编码、判断两个浮点数是否相等。


:::注意
单精度偏置是 \(127\)，双精度是 \(1023\)；不要把 8 位阶码和 23 位尾数的位数记反。
:::
### 规格化数、非规格化数与特殊值

:::定理
条件：看阶码 \(E\) 的取值判断类型。

\(E\ne0,255\) 是规格化数，\(V=(-1)^{s}(1.f)2^{E-127}\)；\(E=0\) 是非规格化数，\(V=(-1)^{s}(0.f)2^{-126}\)；\(E=255\) 且 \(f=0\) 是 \(\pm\infty\)，\(f\ne0\) 是 NaN。
:::

什么时候用：位模式转数值、判断一个数能不能表示、解释除零为什么得到 \(\infty\)。


:::注意
非规格化数没有隐含的 1，阶码固定为 \(1-\text{bias}\)，不是 \(E-\text{bias}\)。这是它能和 0 平滑衔接的原因。
:::
### 非规格化数与 \(2^{-149}\)

:::定理
条件：阶码为 0 且尾数不为 0。

单精度最小正非规格化数是 \(2^{-149}\approx1.4\times10^{-45}\)，最大非规格化数略小于 \(2^{-126}\)。
:::

什么时候用：解释「逐渐下溢」、为什么 0 与最小规格化数之间还有一串等间距的数。


:::注意
\(\texttt{0x00000001}\) 就是 \(2^{-149}\)；\(\texttt{0x007FFFFF}\) 是最大非规格化数。规格化数的最小值是 \(2^{-126}\)，两者相差约 \(2^{23}\) 倍。
:::
### 偏置、范围与有效位数

:::定理
条件：估算一种浮点格式能表示多大、多精确。

单精度范围约 \(\pm3.4\times10^{38}\)，最小规格化数 \(2^{-126}\)；有效位 24 位（隐含 1 加 23 位尾数），约 7 位十进制有效数字；双精度 53 位，约 16 位十进制。
:::

什么时候用：判断会不会上溢/下溢、精度够不够。


:::注意
范围由阶码决定，精度由尾数决定，两者别混。`float` 能表示很大的数，但不代表能精确表示它。
:::
### 向偶数舍入与 0.1 的二进制

:::定理
条件：十进制小数转浮点，或运算结果落在两个可表示数之间。

默认向偶数舍入，正好在中点时取尾数为偶数的那个；\(0.1\) 的二进制是无限循环，单精度存成

\[
0.1_{f}=0.100000001490116\ldots
\]
:::

什么时候用：解释 `0.1 + 0.2 == 0.3` 为什么为假、为什么输出会出现 `0.30000000000000004`。


:::注意
不是「四舍五入」，中点规则是「向偶数」；`float` 的 \(0.1\) 和 `double` 的 \(0.1\) 是两个不同的值。
:::
### 吸收现象与结合律失效

:::定理
条件：一个大数和一个小数相加。

ulp 随数量级增大而增大。单精度在 \(10^{8}\) 附近 ulp 是 8，加 1 会被完全舍掉；于是

\[
(10^{10}_{f}+(-10^{10}_{f}))+1.0_{f}=1.0,\qquad 10^{10}_{f}+\bigl((-10^{10}_{f})+1.0_{f}\bigr)=0.
\]
:::

什么时候用：解释浮点求和的误差、为什么求和要按绝对值排序或用 Kahan 求和。


:::注意
吸收不是 bug，是有限精度的必然；比较浮点数不要用 `==`，要设容差。第二式里 \(-10^{10}+1\) 先被舍成 \(-10^{10}\)，所以结果变成 0。
:::
## 常见问法与易错点

- 问「这个位模式是多少」：先确认字长和有无符号，再套公式；同一串 \(\texttt{0xFF}\) 在无符号、补码、\(\texttt{char}\) 下答案不同。
- 问「溢出没有」：无符号看「结果小于加数」，有符号看「同号相加变号」，两套判据不能混用。
- 问「扩展后是什么」：有符号用符号扩展，无符号用零扩展；截断后要按新类型重新解释。
- 问「浮点为什么算不准」：答「二进制不能精确表示 + 舍入 + 吸收」，不要只说「精度不够」。
- 非规格化数是最容易漏的一种：只要看到阶码全 0，就要立刻想到「没有隐含 1，阶码是 \(1-\text{bias}\)」。
