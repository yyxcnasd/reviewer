## 这一章要会什么

- 写出方程的阶、通解、特解，用初值条件定常数
- 陈述初值问题解的存在唯一性条件（只记结论）
- 解可分离变量、一阶线性、伯努利三类方程
- 按特征根的三种情形写出二阶齐次方程的通解
- 为非齐次方程设出正确的特解形式（含重数判断）

## 7.1 常微分方程的基本概念

### 阶、通解与特解

:::定义
含未知函数及其导数的方程叫微分方程，最高阶导数的阶数叫方程的阶。\(n\) 阶方程的一般形式是

\[
F\left(x,y,y',\dots,y^{(n)}\right)=0.
\]
:::

:::定义
代入后成为恒等式的函数叫解；含 \(n\) 个独立任意常数的解族叫通解；由初值条件定出常数后的解叫特解。

初值问题：

\[
\begin{cases}
y'=f(x,y),\\
y(x_0)=y_0.
\end{cases}
\]

几何上通解是一族积分曲线，特解是过定点的那一条。二阶方程的通解含两个常数，初值要给 \(y(x_0)\) 与 \(y'(x_0)\)。
:::

:::例
\(y'=y\) 的通解是 \(y=C\e^{x}\)，过 \((0,1)\) 的特解是 \(y=\e^{x}\)。
:::

:::例
\(y'=2x\) 的通解是 \(y=x^{2}+C\)，每给一个初值就确定一个 \(C\)，对应族中一条曲线。
:::
### 初值问题解的存在唯一性

:::定理
条件：\(f(x,y)\) 在矩形 \(R=\{(x,y):\abs{x-x_0}\le a,\ \abs{y-y_0}\le b\}\) 上连续，且关于 \(y\) 满足 Lipschitz 条件：存在 \(L>0\)，使

\[
\abs{f(x,y_1)-f(x,y_2)}\le L\abs{y_1-y_2}.
\]

初值问题在 \(\abs{x-x_0}\le h\) 上有唯一解，其中 \(M=\max_R\abs{f}\)，\(h=\min\left(a,\dfrac{b}{M}\right)\)。

一阶线性方程更直接：\(P,Q\in C(I)\) 时，方程 \(y'+P(x)y=Q(x)\) 的初值问题在 \(I\) 上有唯一解。
:::

用法：验证“连续 + Lipschitz”，\(f_y\) 连续是常用的充分条件；结论只保证局部有唯一解，不保证能写出表达式，证明“解存在”的题可直接引用。


:::例
\(y'=y^{2}\)，\(y(0)=1\)。在矩形 \(\abs{x}\le1\)、\(\abs{y-1}\le1\) 上 \(f=y^{2}\) 连续，且 \(\abs{y_1^{2}-y_2^{2}}\le4\abs{y_1-y_2}\)，满足 Lipschitz 条件，故初值问题在 \(0\) 附近有唯一解 \(y=\dfrac{1}{1-x}\)。
:::
## 7.2 一阶常微分方程的初等解法

### 可分离变量方程

形式：\(y'=f(x)g(y)\)，或写成 \(M(x)\,\d x+N(y)\,\d y=0\)。

条件：\(g(y)\ne0\) 时可以分离变量。

:::结论
\[
\frac{\d y}{g(y)}=f(x)\,\d x,\qquad
\int\frac{\d y}{g(y)}=\int f(x)\,\d x+C.
\]
:::

:::注意
分离前先检查 \(g(y)=0\) 给出的常数解，它们可能在除法中丢掉；隐式通解可以不显式解出 \(y\)。
:::

:::例
\(y'=2xy\)，分离得 \(\d y/y=2x\,\d x\)，积分得 \(\ln\abs{y}=x^{2}+C\)，通解 \(y=C\e^{x^{2}}\)；若 \(y(0)=3\)，则特解为 \(y=3\e^{x^{2}}\)。
:::
### 一阶线性方程

形式：\(y'+P(x)y=Q(x)\)。

条件：\(P,Q\) 在区间上连续。

结论（常数变易公式）：

\[
y=\e^{-\int P(x)\,\d x}\left[\int Q(x)\e^{\int P(x)\,\d x}\,\d x+C\right].
\]

用法：先化成标准形（\(y'\) 的系数为 1），再套公式；也可以两边乘积分因子 \(\mu=\e^{\int P\,\d x}\)，左边凑成 \((\mu y)'=\mu Q\) 再积分。

:::例
\(y'+y=\e^{-x}\)。取 \(\mu=\e^{x}\)，得 \((\e^{x}y)'=1\)，故 \(y=\e^{-x}(x+C)\)。
:::

:::例
\(y'+\dfrac{1}{x}y=x\)（\(x>0\)）。积分因子 \(\mu=x\)，方程化为 \((xy)'=x^{2}\)，积分得 \(xy=\dfrac{x^{3}}{3}+C\)，即 \(y=\dfrac{x^{2}}{3}+\dfrac{C}{x}\)。
:::

:::注意
\(Q\equiv0\) 时是齐次方程，直接分离变量更快，不必套公式。积分常数在同一个方程里只加一次，别重复加。
:::
### 伯努利方程

形式：\(y'+P(x)y=Q(x)y^{n}\)，其中 \(n\ne0,1\)。

条件：\(n\ne0,1\)，否则方程本来就是线性或可分离的。

:::结论
令 \(z=y^{1-n}\)，由 \(z'=(1-n)y^{-n}y'\)，方程化为关于 \(z\) 的一阶线性方程

\[
z'+(1-n)P(x)z=(1-n)Q(x).
\]
:::

用法：两边先除以 \(y^{n}\) 再换元；解出 \(z\) 后回代 \(z=y^{1-n}\)。


:::注意
\(n>0\) 时 \(y=0\) 也是解，而换元时假设了 \(y\ne0\)，最后要单独补上。
:::

:::例
\(y'+y=y^{2}\)。两边除以 \(y^{2}\)，令 \(z=y^{-1}\)，得 \(z'-z=-1\)，解出 \(z=1+C\e^{x}\)，故 \(y=\dfrac{1}{1+C\e^{x}}\)。
:::
## 7.3 二阶常系数线性微分方程

### 齐次方程的特征根法

方程：\(y''+py'+qy=0\)，其中 \(p,q\) 为常数。特征方程：

\[
r^{2}+pr+q=0.
\]

设 \(C_1,C_2\) 为任意常数，按判别式 \(\Delta=p^{2}-4q\) 分三种情形：

- \(\Delta>0\)，两根 \(r_1\ne r_2\)：\(y=C_1\e^{r_1x}+C_2\e^{r_2x}\)。
- \(\Delta=0\)，二重根 \(r=-p/2\)：\(y=(C_1+C_2x)\e^{rx}\)。
- \(\Delta<0\)，共轭复根 \(\alpha\pm\beta\i\)：\(y=\e^{\alpha x}\left(C_1\cos\beta x+C_2\sin\beta x\right)\)。

:::例
\(y''-3y'+2y=0\)，特征根为 \(1,2\)，通解 \(y=C_1\e^{x}+C_2\e^{2x}\)。
:::

:::例
\(y''+y=0\)，特征根为 \(\pm\i\)，通解 \(y=C_1\cos x+C_2\sin x\)。
:::

:::例
\(y''-2y'+y=0\)，特征根为二重根 \(1\)，通解 \(y=(C_1+C_2x)\e^{x}\)。
:::

:::注意
复根情形要把 \(\i\) 消掉写成实函数，不能把 \(\e^{(\alpha+\beta\i)x}\) 当答案；二重根记得多乘一个 \(x\)。特征根与通解的形式一一对应，先判根再套公式。
:::
### 非齐次方程的特解设法

方程：\(y''+py'+qy=f(x)\)，通解 = 齐次通解 + 一个特解 \(y^{*}\)。

第一类右端：\(f(x)=P_m(x)\e^{\lambda x}\)。设

\[
y^{*}=x^{k}Q_m(x)\e^{\lambda x},
\]

其中 \(Q_m\) 是待定的 \(m\) 次多项式，\(k\) 是 \(\lambda\) 作为特征根的重数：不是根取 \(0\)，单根取 \(1\)，二重根取 \(2\)。

第二类右端：\(f(x)=\e^{\alpha x}\left(A\cos\beta x+B\sin\beta x\right)\)。设

\[
y^{*}=x^{k}\e^{\alpha x}\left(a\cos\beta x+b\sin\beta x\right),
\]

其中 \(k\) 是 \(\alpha+\beta\i\) 作为特征根的重数，只能取 \(0\) 或 \(1\)。

叠加原理：\(f=f_1+f_2\) 时分别求特解再相加。

:::例
求 \(y''-y=\e^{x}\) 的特解。特征根为 \(\pm1\)，\(\lambda=1\) 是单根，设 \(y^{*}=ax\e^{x}\)，代入得 \(2a\e^{x}=\e^{x}\)，故 \(a=\frac12\)，\(y^{*}=\frac{x}{2}\e^{x}\)。
:::

:::注意
\(k\) 由右端的 \(\lambda\) 是否为特征根决定，这一步最容易漏；右端是纯多项式时相当于 \(\lambda=0\)，要检查 \(0\) 是否为特征根。
:::

:::例
求 \(y''+y=\cos x\) 的特解。\(\alpha+\beta\i=\i\) 是特征根，故设 \(y^{*}=x(a\cos x+b\sin x)\)，代入得 \(y^{*}=\dfrac{x}{2}\sin x\)。
:::

:::例
求 \(y''-y=x\) 的特解。\(\lambda=0\) 不是特征根，设 \(y^{*}=ax+b\)，代入得 \(-ax-b=x\)，故 \(a=-1\)、\(b=0\)，\(y^{*}=-x\)。
:::
### 通解结构与初值定常数

:::结论
非齐次方程的通解 = 齐次方程的通解 + 非齐次方程的一个特解；两个任意常数由 \(y(x_0)=y_0\)、\(y'(x_0)=y'_0\) 唯一确定。
:::

:::例
\(y''-3y'+2y=0\)，\(y(0)=0\)，\(y'(0)=1\)。通解 \(y=C_1\e^{x}+C_2\e^{2x}\)，代入得 \(C_1+C_2=0\)、\(C_1+2C_2=1\)，解得 \(C_2=1\)、\(C_1=-1\)，故 \(y=\e^{2x}-\e^{x}\)。
:::

:::注意
先写通解再代初值，常数解出后要回代检查两个初值条件都满足。
:::
## 常见问法与易错点

- 分离变量时两边除以 \(g(y)\)，丢掉 \(g(y)=0\) 的常数解。
- 一阶线性方程没先化成 \(y'\) 系数为 1 的标准形，直接套公式。
- 伯努利方程忘记除 \(y^{n}\)、或用错 \(z=y^{1-n}\) 的指数。
- 特征根为共轭复数时把复函数留在通解里，没有化成实函数。
- 非齐次特解漏掉 \(x^{k}\) 因子，或把不是特征根的 \(\lambda\) 也乘了 \(x\)。
