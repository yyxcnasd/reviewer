投稿一道题

左边写，右边实时预览。课内的题填课程与章节；只是觉得有意思的题，大分类选「其他」就行，不必挂课程。写完一键开 GitHub issue，或把 .md 下载下来交给管理员。

Markdown + \( \) 公式 一题一个文件 Ctrl+B 加粗 · Ctrl+I 斜体
分类
题本身

括号、$、反引号会自动配对；Tab 跳出；Ctrl+Z 可以撤销工具条插入的内容。数学可以用缩写：e、d、abs{}、R，见符号与缩写。

预览content/questions/…

左边写题面，这里同步显示排版结果。行内公式用 \( \)，独立公式用 \[ \]。

投稿之后
一道题从你写下来到出现在题库里，要过三步。

    
    
      
  1. 提issue 里带着完整的 frontmatter 和文件名建议；太长放不下就下载 .md 附在评论里
    2. 
      
  2. 审管理员看数学、看标签与难度、看有没有重复，必要时在 issue 里讨论
    3. 
      
  3. 归档合并后自动进题库、标签页和对应章节，范围与统计一起更新
