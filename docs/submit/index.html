复习册/投稿

投稿一道题

左边写，右边实时预览。写完可以一键开一个 GitHub issue，或者把 .md 文件下载下来交给管理员。合并之后它就是一个独立的题目文件。

格式 Markdown + \( \) 每题一个文件 标签与难度必填

一到四个。管理员可以在 taxonomy.yml 里加新标签。

预览content/questions/…

左边写题面，这里会同步显示排版后的样子。公式用 \( \) 写行内，\[ \] 写独立成行。

投稿之后

一道题从你写下来到出现在题库里，要过三步。

提

1. 开 issue
   标题：[题目投稿] …
   标签：question-submission
   正文：就是预览里那整段

issue 里带着完整的 frontmatter 和文件名建议。issue 太长放不下时，下载 .md 附在评论里。

审

2. 管理员审
   看数学对不对
   看标签与难度
   看有没有重复
   必要时在 issue 里讨论

管理员会把 issue 转成一个文件（scripts/issue-to-question.mjs 可以从 issue 正文直接生成），提交 PR。

归档

3. 合并
   git merge
   npm run build
   Pages 自动更新

   新题出现在：题库 / 标签页 / 章节

合并后重新构建，题目进入题库、标签页与对应章节；范围统计和首页数字一起更新。
