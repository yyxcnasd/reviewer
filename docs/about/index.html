关于这本册子

复习册：把课程范围、讲义要点、题库与解析放在一处的复习站。微积分 A1 与线性代数是第一批模块，考试轮次（期中 / 期末）可切换。

范围

范围写在 content/courses.yml 里，按考试轮次分开写。导航右上角切换轮次，范围表、考纲、题目页的范围、题库的筛选会一起变。

期中：微积分 A1 到第 4.3 节泰勒公式（含）——实数系与数列极限、函数极限与连续、导数与微分、中值定理与洛必达、泰勒公式；线性代数到第 3 章向量组的秩之前——线性方程组与行列式、矩阵、n 维向量与线性相关。

期末：两门课整本。微积分 A1 第 1–7 章（加上定积分、广义积分、常微分方程），线性代数第 1–4 章（加上秩与解的结构）。

以任课教师的正式通知为准。要改范围，改 courses.yml 里对应小节的那一行，不用动页面代码。

内容怎么组织的

所有中文内容都是仓库里的 Markdown 文件：一题一个文件放在 content/questions/，一章要点一个文件放在 content/notes/，章节与轮次范围写在 content/courses.yml。构建脚本读这些文件，生成题库、标签页、章节索引和这一页。

题目全部自编，难度按「基础、常规、综合、挑战」四档标，个别难题会写明关键那一步怎么想到。图片来自公有领域与开放授权的藏品，出处见下表。

技术

纯静态站点。一个 Node 脚本把 Markdown 生成 HTML，公式用 KaTeX 在构建时渲染成 HTML，关掉 JavaScript 也能读题。部署在 GitHub Pages，链接都是相对路径，放在任何子路径下都能用。

本站文字与题目以 CC BY-SA 4.0 发布，代码以 MIT 发布。图片版权属于各自的收藏机构，见下表。

常见问题

范围以哪个为准？任课教师的正式通知。本站按课本目录整理，期中、期末两套范围可以在右上角切换。

现在有多少道题？149 道，全部自编，每题都有提示、解析和一条常见错误。

为什么有些章节是灰的？那是不在当前轮次范围里的内容。切到另一个轮次，颜色会跟着变。

进度存在哪里？「已做」「收藏」只存在你自己的浏览器（localStorage），不上传，换设备或清缓存就没了。

投稿要写什么格式？Markdown，公式用 ( ) 和 [ ]。缩写（e、d、abs{} 之类）见符号与缩写。投稿页有实时预览，会顺手生成 frontmatter 和文件名。

题目合并之后会怎样？它会成为 content/questions/ 下的一个文件，出现在题库、对应标签页和所属章节里。

能打印吗？能。速查表、每篇要点、每道题都有打印样式；整份卷子在「导出」页生成，A4 排版。
