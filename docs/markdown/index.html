怎么写

投稿页和题库里的题目都按这套写法。大部分是普通 Markdown，额外加了一个「区块」语法。

公式

行内用 \( … \)，独立成行用 \[ … \]。这两种最稳，别用 $…$（和代码里的美元符号会打架）。

行内 \(f'(x_0)\) 与独立：

\[
f'(x_0)=\lim_{h\to 0}\frac{f(x_0+h)-f(x_0)}{h}
\]

常用符号有缩写，写起来短，渲染出来是规矩的正体：

区块

定义、定理、例、注意这类内容，用 ::: 包起来。第一行写类型（可带标题），最后一行单独一个 ::: 收尾。区块里可以照常写公式、列表、代码。

:::theorem[中值定理]
若 $f$ 在 $[a,b]$ 上连续、在 $(a,b)$ 内可导……
:::
:::theorem[中值定理]英文类型 + 方括号标题。类型决定颜色，标题随便写。
:::definition
设 $f$ 在 $x_0$ 的邻域内有定义……
:::
:::definition定义。也可以写 :::定义，不给标题。
:::example[3.1]
求 $x^2$ 的导数。
:::
:::example[3.1]例题，标题写编号。
:::warning[易错]
分子必须同时出现 $f(x_0+h)$ 与 $f(x_0)$。
:::
:::warning[易错]注意 / 易错，红色线。danger、caution 同色。
:::info[提示]
先把公式配成标准形式再算。
:::
:::info[提示]提示、小技巧，蓝色线。tip、remark 同色。
:::proof
由中值定理……
:::
:::proof证明过程。
:::定义
设 $f$ 在 $x_0$ 的邻域内有定义……
:::
:::定义中文类型也能直接写，兼容更短的写法。

类型词决定颜色与默认标题，标题写在方括号里（可省略）：

类型显示颜色
theorem lemma proposition定理 / 引理 / 命题墨色
definition定义墨色
corollary conclusion推论 / 结论墨色
example例蓝色
warning danger caution note注意红色
info tip remark提示蓝色
proof证明灰色
中文：定义 定理 引理 命题 性质 结论 推论 例 注意 易错 警告 提示 证明同上同上

标题、列表、表格

## 二级标题
### 三级标题

- 无序列表
1. 有序列表

| 类型 | 字节 |
| --- | --- |
| int | 4 |

标题不要跳级（h2 下面直接 h3）；表格第一行是表头，第二行写 | --- |。

代码

```c
long f(long x) { return x * 2; }
```

代码块里的 $、\ 不会被当成公式，可以放心写汇编和 LaTeX 源码。

题目怎么写

  • 题面直接写，不要加「题目：」这样的前缀；分小问用 (1)、(2)。
  • 提示、解析、常见错误各用 ## 提示、## 解析、## 常见错误 起头，顺序固定。
  • 解析里说清「关键的那一步为什么能想到」，别只贴过程。
  • 答案写结论本身，能一行写完就一行。
