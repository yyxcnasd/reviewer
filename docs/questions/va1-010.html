实数系与实数列的极限 · 计算题

微积分 A1 计算题 难度 自编
导出这道题 VA1-010 · ←→ 翻题 · E 展开 · D 记已做

设

an=n+1−n(n=1,2,… ).a_n=\sqrt{n+1}-\sqrt{n}\qquad(n=1,2,\dots).an​=n+1​−n​(n=1,2,…).

（1）求 lim⁡n→∞n an\lim\limits_{n\to\infty}\sqrt{n}\,a_nn→∞lim​n​an​；

（2）判断 ana_nan​ 与 1n\dfrac{1}{\sqrt{n}}n​1​ 是同阶无穷小还是等价无穷小，并说明理由。

提示+

根式相减先分子有理化：n+1−n=1n+1+n\sqrt{n+1}-\sqrt{n}=\dfrac{1}{\sqrt{n+1}+\sqrt{n}}n+1​−n​=n+1​+n​1​。再把 n\sqrt{n}n​ 乘进去，分母提出 n\sqrt{n}n​。

解析（先自己做一遍再看）展开
答案

12\dfrac{1}{2}21​，同阶但不等价

（1） 分子有理化：

an=n+1−n=(n+1)−nn+1+n=1n+1+n.a_n=\sqrt{n+1}-\sqrt{n} =\frac{(n+1)-n}{\sqrt{n+1}+\sqrt{n}} =\frac{1}{\sqrt{n+1}+\sqrt{n}}.an​=n+1​−n​=n+1​+n​(n+1)−n​=n+1​+n​1​.

于是

n an=nn+1+n=11+1n+1.\sqrt{n}\,a_n=\frac{\sqrt{n}}{\sqrt{n+1}+\sqrt{n}} =\frac{1}{\sqrt{1+\dfrac{1}{n}}+1}.n​an​=n+1​+n​n​​=1+n1​​+11​.

又因为

∣1+1n−1∣=1n1+1n+1≤1n→0,\left|\sqrt{1+\frac{1}{n}}-1\right| =\frac{\dfrac{1}{n}}{\sqrt{1+\dfrac{1}{n}}+1} \le \frac{1}{n}\to 0,​1+n1​​−1​=1+n1​​+1n1​​≤n1​→0,

所以 1+1n→1\sqrt{1+\dfrac{1}{n}}\to 11+n1​​→1，从而

lim⁡n→∞n an=11+1=12.\lim_{n\to\infty}\sqrt{n}\,a_n=\frac{1}{1+1}=\frac{1}{2}.n→∞lim​n​an​=1+11​=21​.

（2） 比较 ana_nan​ 与 1n\dfrac{1}{\sqrt{n}}n​1​：

an1n=n an→12.\frac{a_n}{\dfrac{1}{\sqrt{n}}}=\sqrt{n}\,a_n\to\frac{1}{2}.n​1​an​​=n​an​→21​.

这个比值趋于非零常数 12\dfrac{1}{2}21​，所以 ana_nan​ 与 1n\dfrac{1}{\sqrt{n}}n​1​ 是同阶无穷小；但比值不趋于 111，所以它们不是等价无穷小。

也就是说，an∼12na_n\sim\dfrac{1}{2\sqrt{n}}an​∼2n​1​。

常见错误展开

一是把 n+1−n\sqrt{n+1}-\sqrt{n}n+1​−n​ 直接写成 n+1∼n\sqrt{n+1}\sim\sqrt{n}n+1​∼n​ 然后相减得 000——等价无穷小只能替换乘除因子，不能对减法中的每一项分别替换。二是把「同阶」和「等价」混为一谈：同阶只要求比值趋于非零常数，等价要求比值趋于 111。三是算 n an\sqrt{n}\,a_nn​an​ 时把 n\sqrt{n}n​ 只乘到分母的一项上，得到 12n\dfrac{1}{2\sqrt{n}}2n​1​ 之类的错误结果。
