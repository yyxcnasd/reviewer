汇编语言与程序的机器级表示 · 计算题

计算机系统概论 计算题 难度 自编 投稿：自编
导出这道题 ICS-018 · ←→ 翻题 · E 展开 · D 记已做

执行下列指令前，%rdi = 3、%rsi = 5：

leaq (%rdi,%rsi,4), %rax
leaq 8(%rax,%rax,2), %rdx
salq $3, %rdx
movq %rax, %rcx
subq %rdi, %rcx

回答：

(1) 执行完后 %rax、%rdx、%rcx 各是多少？

(2) 第二条 lea 等价于 C 的哪个表达式？

(3) 如果要用一条 lea 算出 8x+y8x+y8x+y（其中 xxx 在 %rdi、yyy 在 %rsi），写出这条指令。

提示+
lea 只计算地址，不访问内存；地址表达式形如 disp(base,index,scale)，算的是 disp + base + index * scale，其中 scale 只能取 1,2,4,81,2,4,81,2,4,8。salq $3 是左移 3 位，等于乘 888。

解析（先自己做一遍再看）展开
答案

(1) %rax=23\%rax=23%rax=23、%rdx=616\%rdx=616%rdx=616、%rcx=20\%rcx=20%rcx=20；(2) 3×%rax+83\times\%rax+83×%rax+8；(3) leaq (%rsi,%rdi,8), %rax

(1) 第一条：

%rax=%rdi+4×%rsi=3+4×5=23.\%rax=\%rdi+4\times\%rsi=3+4\times5=23.%rax=%rdi+4×%rsi=3+4×5=23.

第二条：

%rdx=8+%rax+2×%rax=8+3×23=8+69=77.\%rdx=8+\%rax+2\times\%rax=8+3\times23=8+69=77.%rdx=8+%rax+2×%rax=8+3×23=8+69=77.

第三条左移 3 位：

%rdx=77×8=616.\%rdx=77\times8=616.%rdx=77×8=616.

第四、五条把 %rax 复制到 %rcx 再减去 %rdi：

%rcx=23−3=20.\%rcx=23-3=20.%rcx=23−3=20.

(2) 由上面 %rdx = 8 + 3 * %rax，第二条 lea 等价于

rdx = 3 * rax + 8;

即 leaq 8(%rax,%rax,2), %rdx 中的 %rax 既作基址又作变址，比例因子 222 使它变成 333 倍的 %rax。

(3) 需要 8x+y8x+y8x+y，把 yyy 作基址、xxx 作变址、比例因子取 888：

leaq (%rsi,%rdi,8), %rax

结论：(1) %rax = 23，%rdx = 616，%rcx = 20；(2) 3 * rax + 8；(3) leaq (%rsi,%rdi,8), %rax。

常见错误展开

一是把 leaq 当成 movq，以为它会读 %rdi + 4 * %rsi 处的内存。二是把 (%rdi,%rsi,4) 算成 4×3+5=174\times3+5=174×3+5=17，比例因子乘错了对象——它乘的是变址 %rsi。三是把 8(%rax,%rax,2) 算成 8+2×%rax8+2\times\%rax8+2×%rax，漏掉了基址那一份 %rax。四是把 salq $3 当成右移或除以 888，方向反了。五是第 (3) 问比例因子选 444 或把基址、变址写反。
