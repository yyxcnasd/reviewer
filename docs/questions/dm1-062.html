谓词逻辑的基本概念 · 证明题

离散数学1 证明题 难度 自编 投稿：自编
导出这道题 DM1-062 · ←→ 翻题 · E 展开 · D 记已做

设 DDD 是非空论域，P,QP,QP,Q 是一元谓词。约定 (∀x)(\forall x)(∀x) 与 (∃x)(\exists x)(∃x) 都遍历 DDD。

(1) 证明

(∀x)(P(x)∧Q(x))⇔(∀x)P(x)∧(∀x)Q(x).(\forall x)\bigl(P(x)\wedge Q(x)\bigr)\Leftrightarrow(\forall x)P(x)\wedge(\forall x)Q(x).(∀x)(P(x)∧Q(x))⇔(∀x)P(x)∧(∀x)Q(x).

(2) 判断 (∀x)(P(x)∨Q(x))⇔(∀x)P(x)∨(∀x)Q(x)(\forall x)\bigl(P(x)\vee Q(x)\bigr)\Leftrightarrow(\forall x)P(x)\vee(\forall x)Q(x)(∀x)(P(x)∨Q(x))⇔(∀x)P(x)∨(∀x)Q(x) 是否普遍有效：证明成立的那个方向；对每个 n≥2n\ge2n≥2，在 ∣D∣=n|D|=n∣D∣=n 的论域上构造 P,QP,QP,Q 使左真右假。

(3) 对给定的解释 (D,P,Q)(D,P,Q)(D,P,Q)，精确刻画「两边等值」成立的充要条件；再求「对一切 P,QP,QP,Q 都等值」的充要条件。

(4) 对存在量词与合取做同样的事：判断 (∃x)(P(x)∧Q(x))⇔(∃x)P(x)∧(∃x)Q(x)(\exists x)\bigl(P(x)\wedge Q(x)\bigr)\Leftrightarrow(\exists x)P(x)\wedge(\exists x)Q(x)(∃x)(P(x)∧Q(x))⇔(∃x)P(x)∧(∃x)Q(x) 是否普遍有效，证明成立的方向并对每个 n≥2n\ge2n≥2 构造反例。

提示+

把量词按语义展开：(∀x)R(x)(\forall x)R(x)(∀x)R(x) 的意思是「对每个 a∈Da\in Da∈D，R(a)R(a)R(a) 真」。于是 (1) 就是「所有 aaa 同时满足 PPP 与 QQQ」与「所有 aaa 满足 PPP，且所有 aaa 满足 QQQ」的互相翻译。

(2) 的反方向之所以失败，是因为「每个 aaa 至少满足 P,QP,QP,Q 之一」并不保证「所有 aaa 都满足同一个谓词」：可以让一半元素满足 PPP、另一半满足 QQQ。

(3) 精确刻画要把「失败」写成一个存在语句：存在 aaa 使 ¬P(a)\neg P(a)¬P(a)，存在 bbb 使 ¬Q(b)\neg Q(b)¬Q(b)，而 a≠ba\ne ba=b（否则 P(a)∨Q(a)P(a)\vee Q(a)P(a)∨Q(a) 不成立）。

解析（先自己做一遍再看）展开
答案

(1) 等值；(2) (∀x)P∨(∀x)Q⇒(∀x)(P∨Q)(\forall x)P\vee(\forall x)Q\Rightarrow(\forall x)(P\vee Q)(∀x)P∨(∀x)Q⇒(∀x)(P∨Q) 成立，反之不成立，对每个 n≥2n\ge2n≥2 构造 P={a},Q=D∖{a}P=\{a\},Q=D\setminus\{a\}P={a},Q=D∖{a}；(3) 给定解释下等值当且仅当 PD=DP^D=DPD=D 或 QD=DQ^D=DQD=D 或 PD∪QD≠DP^D\cup Q^D\ne DPD∪QD=D 或 ∣D∣=1|D|=1∣D∣=1，对所有 P,QP,QP,Q 都等值当且仅当 ∣D∣=1|D|=1∣D∣=1；(4) (∃x)(P∧Q)⇒(∃x)P∧(∃x)Q(\exists x)(P\wedge Q)\Rightarrow(\exists x)P\wedge(\exists x)Q(∃x)(P∧Q)⇒(∃x)P∧(∃x)Q 成立，反之不成立

(1) 设 (∀x)(P∧Q)(\forall x)(P\wedge Q)(∀x)(P∧Q) 真。任取 a∈Da\in Da∈D，有 P(a)∧Q(a)P(a)\wedge Q(a)P(a)∧Q(a) 真，故 P(a)P(a)P(a)、Q(a)Q(a)Q(a) 都真；由 aaa 任意，(∀x)P(\forall x)P(∀x)P 与 (∀x)Q(\forall x)Q(∀x)Q 都真，右边真。

反过来，设 (∀x)P∧(∀x)Q(\forall x)P\wedge(\forall x)Q(∀x)P∧(∀x)Q 真。任取 a∈Da\in Da∈D，P(a)P(a)P(a) 与 Q(a)Q(a)Q(a) 都真，故 P(a)∧Q(a)P(a)\wedge Q(a)P(a)∧Q(a) 真；由 aaa 任意，左边真。所以两边等值。

(2) 成立的方向：若 (∀x)P∨(∀x)Q(\forall x)P\vee(\forall x)Q(∀x)P∨(∀x)Q 真，则至少有一个全称式真。若 (∀x)P(\forall x)P(∀x)P 真，则每个 aaa 都满足 P(a)P(a)P(a)，自然满足 P(a)∨Q(a)P(a)\vee Q(a)P(a)∨Q(a)；若 (∀x)Q(\forall x)Q(∀x)Q 真同理。所以

(∀x)P∨(∀x)Q⇒(∀x)(P∨Q).(\forall x)P\vee(\forall x)Q\Rightarrow(\forall x)(P\vee Q).(∀x)P∨(∀x)Q⇒(∀x)(P∨Q).

反方向不成立，且对每个 n≥2n\ge2n≥2 都可构造。 取 D={a1,…,an}D=\{a_1,\dots,a_n\}D={a1​,…,an​}，令

PD={a1},QD=D∖{a1}.P^D=\{a_1\},\qquad Q^D=D\setminus\{a_1\}.PD={a1​},QD=D∖{a1​}.

则对每个 aia_iai​：a1a_1a1​ 满足 PPP，其余 aia_iai​（i≥2i\ge2i≥2）满足 QQQ，所以 (∀x)(P∨Q)(\forall x)(P\vee Q)(∀x)(P∨Q) 真。但 (∀x)P(\forall x)P(∀x)P 假（a2a_2a2​ 不满足 PPP），(∀x)Q(\forall x)Q(∀x)Q 假（a1a_1a1​ 不满足 QQQ），所以右边假。因此反方向对任何 ∣D∣≥2|D|\ge2∣D∣≥2 的论域都不成立。

(3) 记 PD,QDP^D,Q^DPD,QD 为 P,QP,QP,Q 的外延。左边为真等价于 PD∪QD=DP^D\cup Q^D=DPD∪QD=D。右边为真等价于 PD=DP^D=DPD=D 或 QD=DQ^D=DQD=D。

「等值成立」等价于「左边真时右边必真」，即不存在 PD∪QD=DP^D\cup Q^D=DPD∪QD=D 而 PD≠DP^D\ne DPD=D、QD≠DQ^D\ne DQD=D 的情形。把失败条件写清楚：存在 a∈D∖PDa\in D\setminus P^Da∈D∖PD 与 b∈D∖QDb\in D\setminus Q^Db∈D∖QD；又因 PD∪QD=DP^D\cup Q^D=DPD∪QD=D，必有 b∈PDb\in P^Db∈PD 与 a∈QDa\in Q^Da∈QD，从而 a≠ba\ne ba=b（若 a=ba=ba=b，则 a∉PDa\notin P^Da∈/PD 又 a∈PDa\in P^Da∈PD，矛盾）。所以

等值失败  ⟺  ∃a,b∈D: a≠b, a∉PD, b∉QD, PD∪QD=D.\text{等值失败}\iff \exists a,b\in D:\ a\ne b,\ a\notin P^D,\ b\notin Q^D,\ P^D\cup Q^D=D.等值失败⟺∃a,b∈D: a=b, a∈/PD, b∈/QD, PD∪QD=D.

因此对给定解释，等值成立当且仅当

PD=D 或 QD=D 或 PD∪QD≠D 或 ∣D∣=1.P^D=D\ \text{或}\ Q^D=D\ \text{或}\ P^D\cup Q^D\ne D\ \text{或}\ |D|=1.PD=D 或 QD=D 或 PD∪QD=D 或 ∣D∣=1.

其中 ∣D∣=1|D|=1∣D∣=1 时自动成立，因为唯一的元素必须满足 P∨QP\vee QP∨Q，于是 PPP 或 QQQ 在该元素上真，右边也真。

「对一切 P,QP,QP,Q 都等值」要求上式对任意 PD,QDP^D,Q^DPD,QD 成立。若 ∣D∣≥2|D|\ge2∣D∣≥2，(2) 已给出反例；若 ∣D∣=1|D|=1∣D∣=1，则由上一段知恒等值。所以充要条件是

∣D∣=1.|D|=1.∣D∣=1.

(4) 成立的方向：若 (∃x)(P∧Q)(\exists x)(P\wedge Q)(∃x)(P∧Q) 真，取见证 aaa，则 P(a)P(a)P(a)、Q(a)Q(a)Q(a) 都真，于是 (∃x)P(\exists x)P(∃x)P 与 (∃x)Q(\exists x)Q(∃x)Q 都真，右边真。故

(∃x)(P∧Q)⇒(∃x)P∧(∃x)Q.(\exists x)(P\wedge Q)\Rightarrow(\exists x)P\wedge(\exists x)Q.(∃x)(P∧Q)⇒(∃x)P∧(∃x)Q.

反方向不成立。 对每个 n≥2n\ge2n≥2，取 D={a1,…,an}D=\{a_1,\dots,a_n\}D={a1​,…,an​}，令

PD={a1},QD={a2}.P^D=\{a_1\},\qquad Q^D=\{a_2\}.PD={a1​},QD={a2​}.

则 (∃x)P(\exists x)P(∃x)P 真（a1a_1a1​）、(∃x)Q(\exists x)Q(∃x)Q 真（a2a_2a2​），右边真；但没有一个元素同时满足 PPP 与 QQQ，左边假。所以反方向对任何 ∣D∣≥2|D|\ge2∣D∣≥2 的论域都不成立。

常见错误展开
  • (2) 中把反例造成 P={a1},Q={a1}P=\{a_1\},Q=\{a_1\}P={a1​},Q={a1​}，这时右边也真，反例失效。关键是让 P,QP,QP,Q 的「缺口」落在不同元素上。
  • (3) 的刻画漏掉 ∣D∣=1|D|=1∣D∣=1 或漏掉 PD∪QD≠DP^D\cup Q^D\ne DPD∪QD=D（此时左边假，等值当然成立）。
  • 把「对给定解释等值」与「对一切解释普遍有效」混为一谈。前者依赖 P,QP,QP,Q 的具体取值，后者要求所有取值。
  • (4) 中把成立方向写反，误以为 (∃x)P∧(∃x)Q⇒(∃x)(P∧Q)(\exists x)P\wedge(\exists x)Q\Rightarrow(\exists x)(P\wedge Q)(∃x)P∧(∃x)Q⇒(∃x)(P∧Q)。两个存在量词可能由不同元素见证，不能合并。
