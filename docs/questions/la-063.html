提示+

把三个方程看成同一个二次多项式 p(t)=x1+x2t+x3t2p(t)=x_1+x_2t+x_3t^2p(t)=x1​+x2​t+x3​t2 在 t=a,b,ct=a,b,ct=a,b,c 处的取值。先算系数行列式（范德蒙德），再想："同一个 ttt 会不会被要求同时取到两个不同的值？"

解析（先自己做一遍再看）展开
答案

a,b,ca,b,ca,b,c 两两不同时方程组有唯一解；a=b≠ca=b\ne ca=b=c 时有无穷多解；a=ca=ca=c 或 b=cb=cb=c（含三者相等）时无解

关键想法：方程组的三行分别是 (1,t,t2)(1,t,t^2)(1,t,t2) 在 t=a,b,ct=a,b,ct=a,b,c 处的取值。令

p(t)=x1+x2t+x3t2,p(t)=x_1+x_2t+x_3t^2,p(t)=x1​+x2​t+x3​t2,

三个方程就是

p(a)=1,p(b)=1,p(c)=0.p(a)=1,\qquad p(b)=1,\qquad p(c)=0 .p(a)=1,p(b)=1,p(c)=0.

于是"解方程组"变成"找一个次数不超过 222 的多项式，使它在三点取指定值"，讨论就清楚了：三个不同点给出三个条件，恰好定住一个二次多项式；点重合时，两个条件可能合并，也可能互相矛盾。

系数行列式是范德蒙德行列式：

D=∣1aa21bb21cc2∣=(b−a)(c−a)(c−b).D=\begin{vmatrix} 1&a&a^2\\ 1&b&b^2\\ 1&c&c^2 \end{vmatrix} =(b-a)(c-a)(c-b).D=​111​abc​a2b2c2​​=(b−a)(c−a)(c−b).

一、a,b,ca,b,ca,b,c 两两不同。 此时 D≠0D\ne0D=0，由克莱姆法则，方程组有唯一解。（从多项式看：三个不同点上的值唯一决定次数不超过 222 的多项式。）

二、a=b≠ca=b\ne ca=b=c。 前两个方程完全相同，都是 p(a)=1p(a)=1p(a)=1；第三个是 p(c)=0p(c)=0p(c)=0。因为 a≠ca\ne ca=c，这两个条件互相独立。取

p(t)=t−ca−c+k(t−a)(t−c),k∈R,p(t)=\frac{t-c}{a-c}+k(t-a)(t-c),\qquad k\in\mathbb{R} ,p(t)=a−ct−c​+k(t−a)(t−c),k∈R,

三、a=ca=ca=c 或 b=cb=cb=c（包括三者相等）。 这时第三个方程要求 p(c)=0p(c)=0p(c)=0，而另一个方程要求 p(c)=1p(c)=1p(c)=1：同一个数被要求对应两个不同的函数值，矛盾，所以无解。

结论：a,b,ca,b,ca,b,c 两两不同时唯一解；a=b≠ca=b\ne ca=b=c 时无穷多解；其余情况（a=ca=ca=c 或 b=cb=cb=c）无解。

常见错误展开
  • 只算出 D≠0D\ne0D=0 的情形就收工，不讨论 D=0D=0D=0。而 D=0D=0D=0 时三种重根情形（a=ba=ba=b、a=ca=ca=c、b=cb=cb=c）的结果并不相同：只有 a=ba=ba=b 会得到无穷多解。
  • 把 a=ca=ca=c 也当成"两个方程合并、无穷多解"。此时 p(c)p(c)p(c) 同时被要求等于 111 和 000，是矛盾，不是自由。
  • 认为"两个方程、三个未知数"一定有无穷多解。只有当两个方程线性无关（这里是 a≠ca\ne ca=c）时，才剩下一个自由未知量。
  • 范德蒙德行列式的符号或因子次序写错。写成 (a−b)(a−c)(b−c)(a-b)(a-c)(b-c)(a−b)(a−c)(b−c) 也不影响"是否为零"的判断，但用克莱姆法则求解时会整体差一个符号。
