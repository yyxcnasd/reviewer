在 IEEE 754 单精度浮点环境下回答下列问题。

（1）求 1.0f / 0.0f、-1.0f / 0.0f、0.0f / 0.0f 的值。

（2）求 INFINITY - INFINITY、INFINITY * 0.0f、INFINITY / INFINITY 的值。

（3）位模式 0x7F800000、0xFF800000、0x7FC00000 分别表示什么？

（4）设 float x = 0.0f / 0.0f;，求下列表达式的值：x == x、x != x、x < 1.0f、x > 1.0f、!(x < 1.0f)。

（5）怎样用一条比较判断一个浮点数 x 是不是 NaN？

提示+

IEEE 754 对「除以零」「无穷减无穷」这类运算不中止程序，而是产生特殊值：阶码全 1、尾数为 0 是无穷，阶码全 1、尾数非 0 是 NaN。NaN 与任何数（包括它自己）进行有序比较都返回假，唯一例外是 != 返回真。

解析（先自己做一遍再看）展开
答案

（1）+∞+\infty+∞、−∞-\infty−∞、NaN；（2）NaN、NaN、NaN；（3）+∞+\infty+∞、−∞-\infty−∞、NaN；（4）假、真、假、假、真；（5）判断 x != x

关键的那一步为什么能想到。 把浮点数按位分成三段（符号、阶码、尾数），特殊值就只是「阶码全 1」这一种编码再细分：尾数为 0 表示无穷，尾数非 0 表示 NaN。运算结果该是什么，则按「极限情形」判断：正数除以正零趋于 +∞+\infty+∞，零除以零的极限不存在，无穷减无穷、无穷乘零也都无法确定，因此都落到 NaN。至于比较，只要记住 NaN 是「无序」的，所有 <、>、== 都为假。

（1）1.0f / 0.0f 是正数除以正零，结果为 +∞+\infty+∞；-1.0f / 0.0f 为 −∞-\infty−∞；0.0f / 0.0f 的极限不确定，结果为 NaN（quiet NaN）。

（2）无穷减无穷、无穷乘零、无穷除无穷都是「不确定型」，结果为 NaN。注意题目问的是浮点运算，不是整数除零。

（3）单精度的阶码 8 位、偏置 127。阶码全 1（即 255）表示特殊值：

    0x7F800000：符号 0、阶码全 1、尾数全 0，表示 +∞+\infty+∞； 0xFF800000：符号 1、阶码全 1、尾数全 0，表示 −∞-\infty−∞； 0x7FC00000：符号 0、阶码全 1、尾数为 0x400000（最高尾数位为 1，quiet NaN），表示 NaN。

（4）NaN 与任何数比较都是无序的，因此 x == x 为假、x < 1.0f 为假、x > 1.0f 为假；x != x 为真（这是 NaN 的判定特征）；!(x < 1.0f) 为真（因为 x < 1.0f 本身为假）。

（5）利用 NaN 与自身不相等：

int is_nan(float x) {
    return x != x;
}

也可以调用 isnan(x)，底层同样是在检查「阶码全 1 且尾数非 0」或利用无序比较。

常见错误展开

一是以为整数除以零和浮点除以零表现相同（整数除零在 x86 上会触发异常，浮点按 IEEE 产生 ±∞\pm\infty±∞ 或 NaN）。二是以为 NaN == NaN 为真，从而写出 if (x == x) 判断「不是 NaN」的错误逻辑。三是把 INFINITY - INFINITY 当成 0，或把 INFINITY * 0.0f 当成 0。四是把 0x7FC00000 当成无穷——无穷要求尾数全 0，这里尾数非 0，是 NaN。
