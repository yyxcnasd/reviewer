汇编语言与程序的机器级表示 · 综合题

计算机系统概论 综合题 难度 自编 投稿：自编
导出这道题 ICS-005 · ←→ 翻题 · E 展开 · D 记已做

函数 f 的参数 x 放在 %rdi，返回值放在 %rax。它的汇编实现是

f:
    testq %rdi, %rdi
    jle .L1
    salq $3, %rdi
    leaq 4(%rdi), %rax
    ret
.L1:
    movq %rdi, %rax
    negq %rax
    ret

(1) 写出 f 的 C 语言等价实现。

(2) 求 f(-3) 与 f(2)。

(3) 如果把 salq $3, %rdi 换成 shlq $3, %rdi，语义会不会变？如果换成 32 位的 sall $3, %edi，结果会不会变？各说明理由。

提示+

先看第一条 testq %rdi, %rdi 加 jle：它在判断 x <= 0。注意 lea 不访存、只算地址，所以 leaq 4(%rdi), %rax 是加法而不是读取内存。第三问要盯住「写 32 位寄存器会清零高 32 位」这条规则。

解析（先自己做一遍再看）展开
答案

(1) x≤0x\le0x≤0 时返回 −x-x−x，x>0x>0x>0 时返回 8x+48x+48x+4；(2) f(−3)=3f(-3)=3f(−3)=3、f(2)=20f(2)=20f(2)=20；(3) 换成 shlq 不变；换成 sall $3, %edi 在大 xxx 时出错

(1) 逐段翻译：

    testq %rdi, %rdi; jle .L1：若 x≤0x\le0x≤0 跳到 .L1； .L1 处 movq %rdi, %rax; negq %rax：返回 −x-x−x；
  • 否则 salq $3, %rdi 把 xxx 左移 3 位，即 8x8x8x；leaq 4(%rdi), %rax 把 8x+48x+48x+4 放进返回值。

所以

long f(long x) {
    if (x <= 0)
        return -x;
    else
        return 8 * x + 4;
}

(2) f(−3)f(-3)f(−3)：−3≤0-3\le0−3≤0，走 .L1，返回 −(−3)=3-(-3)=3−(−3)=3。 f(2)f(2)f(2)：2>02>02>0，返回 8×2+4=208\times2+4=208×2+4=20。

(3) sal 和 shl 是同一条左移指令的两种写法（sal 是算术左移，shl 是逻辑左移，左移时两者行为相同），所以换成 shlq 语义不变。

换成 sall $3, %edi 则会变。原因有两条：

  1. 32 位运算只保留低 32 位，结果对 xxx 截断到 2322^{32}232；
  2. 写 32 位寄存器 %edi 会把 %rdi 的高 32 位清零，后续 leaq 4(%rdi) 用的就是零扩展后的值。

例如 x=229x=2^{29}x=229 时，8x=2328x=2^{32}8x=232，sall 得到 0，再 lea 得 444；而正确的 64 位结果是 232+42^{32}+4232+4。对 x<229x<2^{29}x<229 这类小值，两种写法结果相同，所以这类错误容易在测试时漏掉。

常见错误展开

一是把 leaq 4(%rdi), %rax 当成「读 %rdi+4 处的内存」，实际它只是算 x+4x+4x+4。二是把 salq $3 当成右移或除以 8，方向反了。三是认为 sal 与 shl 一个有符号一个无符号、结果会不同——左移时两者等价。四是忽略 32 位写操作清零高 32 位的副作用，只考虑「低 32 位截断」。
