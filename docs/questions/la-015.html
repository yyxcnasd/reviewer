线性方程组与行列式 · 计算题

线性代数 计算题 难度 自编
导出这道题 LA-015 · ←→ 翻题 · E 展开 · D 记已做

设 a2a3⋯an≠0a_2a_3\cdots a_n\ne0a2​a3​⋯an​=0，计算 nnn 阶爪形行列式

D=∣a1b2b3⋯bnc2a20⋯0c30a3⋱⋮⋮⋮⋱⋱0cn0⋯0an∣.D=\begin{vmatrix} a_1&b_2&b_3&\cdots&b_n\\ c_2&a_2&0&\cdots&0\\ c_3&0&a_3&\ddots&\vdots\\ \vdots&\vdots&\ddots&\ddots&0\\ c_n&0&\cdots&0&a_n \end{vmatrix}.D=​a1​c2​c3​⋮cn​​b2​a2​0⋮0​b3​0a3​⋱⋯​⋯⋯⋱⋱0​bn​0⋮0an​​​.

提示+

用对角元 aia_iai​ 作除数，把第一行里的 bib_ibi​ 逐个消掉。目标是把矩阵化成下三角。

解析（先自己做一遍再看）展开
答案

a2a3⋯an(a1−∑i=2nbiciai)a_2a_3\cdots a_n\left(a_1-\displaystyle\sum_{i=2}^{n}\frac{b_ic_i}{a_i}\right)a2​a3​⋯an​(a1​−i=2∑n​ai​bi​ci​​)

第一行除 a1a_1a1​ 外还有 b2,…,bnb_2,\dots,b_nb2​,…,bn​，而第 iii 行（i≥2i\ge2i≥2）在第 iii 列有 aia_iai​、在第一列有 cic_ici​。对每个 i=2,…,ni=2,\dots,ni=2,…,n，把第 iii 行的 −biai-\dfrac{b_i}{a_i}−ai​bi​​ 倍加到第一行上。这是"把一行的倍数加到另一行"的初等行变换，行列式不变，而第一行变成

(a1−∑i=2nbiciai, 0, 0, …, 0).\left(a_1-\sum_{i=2}^{n}\frac{b_ic_i}{a_i},\ 0,\ 0,\ \dots,\ 0\right).(a1​−i=2∑n​ai​bi​ci​​, 0, 0, …, 0).

于是

D=∣a1−∑i=2nbiciai0⋯0c2a2⋯0⋮⋮⋱⋮cn0⋯an∣,D=\begin{vmatrix} a_1-\displaystyle\sum_{i=2}^{n}\frac{b_ic_i}{a_i}&0&\cdots&0\\ c_2&a_2&\cdots&0\\ \vdots&\vdots&\ddots&\vdots\\ c_n&0&\cdots&a_n \end{vmatrix},D=​a1​−i=2∑n​ai​bi​ci​​c2​⋮cn​​0a2​⋮0​⋯⋯⋱⋯​00⋮an​​​,

这是下三角行列式，等于对角线元素之积：

D=a2a3⋯an(a1−∑i=2nbiciai).D=a_2a_3\cdots a_n\left(a_1-\sum_{i=2}^{n}\frac{b_ic_i}{a_i}\right).D=a2​a3​⋯an​(a1​−i=2∑n​ai​bi​ci​​).

用 n=3n=3n=3 的数字验证：取 a1=1a_1=1a1​=1，a2=2a_2=2a2​=2，a3=4a_3=4a3​=4，b2=2b_2=2b2​=2，b3=3b_3=3b3​=3，c2=c3=1c_2=c_3=1c2​=c3​=1。公式给出

D=2⋅4(1−2⋅12−3⋅14)=8(1−1−34)=−6.D=2\cdot4\left(1-\frac{2\cdot1}{2}-\frac{3\cdot1}{4}\right)=8\left(1-1-\frac34\right)=-6 .D=2⋅4(1−22⋅1​−43⋅1​)=8(1−1−43​)=−6.

直接展开 ∣123120104∣=1⋅8−2⋅4+3⋅(0−2)=8−8−6=−6\begin{vmatrix}1&2&3\\1&2&0\\1&0&4\end{vmatrix}=1\cdot8-2\cdot4+3\cdot(0-2)=8-8-6=-6​111​220​304​​=1⋅8−2⋅4+3⋅(0−2)=8−8−6=−6，一致。

常见错误展开

aaa）消元时用 cic_ici​ 或 bib_ibi​ 当除数：能除的是对角元 aia_iai​，题目已经要求 a2⋯an≠0a_2\cdots a_n\ne0a2​⋯an​=0。bbb）只把第 iii 行的 cic_ici​ 消掉、忘了第一列的元素也在变，导致 a1a_1a1​ 那一项算错。ccc）结果里漏掉 a2⋯ana_2\cdots a_na2​⋯an​，或者把 ∑\sum∑ 里 bi,cib_i,c_ibi​,ci​ 的上下标对调。
