汇编语言与程序的机器级表示 · 综合题

计算机系统概论 综合题 难度 自编 投稿：自编
导出这道题 ICS-066 · ←→ 翻题 · E 展开 · D 记已做

函数 f 的参数 x 放在 %rdi，返回值放在 %rax，汇编实现是

f:
    leaq    (%rdi,%rdi,4), %rax     # rax = 5*x
    leaq    (%rax,%rax,2), %rax     # rax = 3*(5x) = 15x
    sarq    $4, %rax                # rax >>= 4（算术右移）
    ret

(1) 用含 floor/ceil 的式子写出 f(x)，并求 f(100)、f(-100)。

(2) 若有人把这段汇编"翻译"成 C 的 return x * 15 / 16;，两者在什么 x 上结果不同？给出反例，并解释编译器为什么不会用 sarq 来实现 C 的 /16。

(3) x 取多大时，第二条 leaq 的中间结果会超出 64 位有符号范围？此时 C 写法是什么行为，而这段汇编实际得到什么？以 x=262x=2^{62}x=262 为例算出结果。

提示+
leaq 只算地址、不访存，所以两条 leaq 是在做常数乘法；sarq 是算术右移，对负数是向下取整而不是向零取整。把「乘 15 再除 16」拆成「乘」和「移位」两步，分别检查舍入方向与溢出。

解析（先自己做一遍再看）展开
答案

f(x)=⌊15x/16⌋=x−⌈x/16⌉f(x)=\lfloor 15x/16\rfloor=x-\lceil x/16\rceilf(x)=⌊15x/16⌋=x−⌈x/16⌉；f(100)=93f(100)=93f(100)=93、f(−100)=−94f(-100)=-94f(−100)=−94；C 的 x*15/16 向零截断，负数会差 1；15x15x15x 超出 64 位时汇编按模 2642^{64}264 回绕，如 x=262x=2^{62}x=262 得 −258-2^{58}−258

(1) 两条 leaq 依次把 xxx 变成 5x5x5x、再变成 15x15x15x；sarq $4 是算术右移 4 位。算术右移对补码数的效果是

x≫4=⌊x16⌋x \gg 4=\left\lfloor \frac{x}{16}\right\rfloorx≫4=⌊16x​⌋

（对正负都成立：−1≫4=−1=⌊−1/16⌋-1 \gg 4=-1=\lfloor -1/16\rfloor−1≫4=−1=⌊−1/16⌋）。所以

f(x)=⌊15x16⌋=x−⌈x16⌉.f(x)=\left\lfloor \frac{15x}{16}\right\rfloor = x-\left\lceil \frac{x}{16}\right\rceil .f(x)=⌊1615x​⌋=x−⌈16x​⌉.

后一个等号来自 ⌊x−a⌋=x−⌈a⌉\lfloor x-a\rfloor=x-\lceil a\rceil⌊x−a⌋=x−⌈a⌉。

数值验证：

  • f(100)=⌊1500/16⌋=⌊93.75⌋=93f(100)=\lfloor1500/16\rfloor=\lfloor93.75\rfloor=93f(100)=⌊1500/16⌋=⌊93.75⌋=93，而 100−⌈6.25⌉=100−7=93100-\lceil6.25\rceil=100-7=93100−⌈6.25⌉=100−7=93；
  • f(−100)=⌊−1500/16⌋=⌊−93.75⌋=−94f(-100)=\lfloor-1500/16\rfloor=\lfloor-93.75\rfloor=-94f(−100)=⌊−1500/16⌋=⌊−93.75⌋=−94，而 −100−⌈−6.25⌉=−100−(−6)=−94-100-\lceil-6.25\rceil=-100-(-6)=-94−100−⌈−6.25⌉=−100−(−6)=−94。

为什么想到：看到 leaq 的 (a,b,4) 形式先还原成「乘 5」，再看到 sarq 立刻换成「除以 2 的幂、向下取整」——这两步是把汇编翻成数学表达式的固定动作。

(2) C 的整数除法 / 是向零截断，而 sarq 向下取整。对负数且不能整除时，两者差 1：

(−100)×15/16=−93(C 向零截断),⌊15⋅(−100)16⌋=−94.(-100)\times15/16=-93\quad(\text{C 向零截断}),\qquad \left\lfloor \frac{15\cdot(-100)}{16}\right\rfloor=-94.(−100)×15/16=−93(C 向零截断),⌊1615⋅(−100)​⌋=−94.

再如 x=−1x=-1x=−1：C 得 000，汇编得 −1-1−1。正数或能整除时两者一致。

编译器不会用 sarq 实现 C 的 /16：C 规定向零截断，负数时要补一个修正（典型做法是对负数先加 151515，或用 idiv），单独一条算术右移会改变负数的结果。只有在编译器能证明 x≥0x\ge0x≥0（或把除法改成无符号）时，才会放心用右移。

(3) 第二条 leaq 计算 15x15x15x 的 64 位结果，数学上超过 263−12^{63}-1263−1 就发生回绕（C 的 x*15 此时是未定义行为）。阈值约为

∣x∣>263−115≈6.15×1017.|x|>\frac{2^{63}-1}{15}\approx6.15\times10^{17}.∣x∣>15263−1​≈6.15×1017.

汇编不会"报错"，而是按模 2642^{64}264 回绕。取 x=262x=2^{62}x=262：

15⋅262=15⋅262,264=16⋅262,15\cdot2^{62}=15\cdot2^{62},\qquad 2^{64}=16\cdot2^{62},15⋅262=15⋅262,264=16⋅262,

所以位模式按有符号解释是

15⋅262−264=−262,15\cdot2^{62}-2^{64}=-2^{62},15⋅262−264=−262,

再算术右移 4 位：

f(262)=−26216=−258=−288230376151711744.f(2^{62})=\frac{-2^{62}}{16}=-2^{58}=-288230376151711744.f(262)=16−262​=−258=−288230376151711744.

为什么想到：要判断溢出，先确定中间结果属于哪一步（这里是 15x15x15x，不是最终值），再用 2642^{64}264 的模运算把回绕结果翻译回有符号数；右移只影响已经回绕后的位模式，所以"先回绕、后移位"的顺序不能反。

常见错误展开

一是把 sarq $4 当成"除以 16 并四舍五入"或"向零截断"，对负数算成 −93-93−93。二是只看到 x*15/16 就以为和汇编等价，忽略了 C 的除法向零、移位的向下取整。三是把溢出判断放在最终结果 15x/1615x/1615x/16 上——实际溢出发生在中间的 15x15x15x，xxx 只要超过约 6.15×10176.15\times10^{17}6.15×1017 就回绕。四是回绕后忘记做有符号解释，把 −262-2^{62}−262 当成巨大的正数再右移，结果符号全错。
