提示+

被积函数里有 xax^{a}xa。作换元 x=1tx=\dfrac{1}{t}x=t1​，看看 1+xa1+x^{a}1+xa 会变成什么；再把换元前后的两个积分相加，试试能不能把 1+xa1+x^{a}1+xa 约掉。

解析（先自己做一遍再看）展开
答案

I(a)=π4I(a)=\dfrac{\pi}{4}I(a)=4π​，与 aaa 无关

关键的那一步为什么能想到。 形如 1+xa1+x^{a}1+xa 的因子在 x↦1xx\mapsto\dfrac{1}{x}x↦x1​ 下会变成 1+tata\dfrac{1+t^{a}}{t^{a}}ta1+ta​，也就是「原来的因子再乘上 t−at^{-a}t−a」。这说明换元后的积分和原积分只差一个 tat^{a}ta 因子；把两者相加，分子正好凑成 1+xa1+x^{a}1+xa 而约掉。于是不必按 aaa 分类去求原函数，只要算 ∫0+∞dx1+x2\displaystyle\int_{0}^{+\infty}\frac{\mathrm{d} x}{1+x^{2}}∫0+∞​1+x2dx​。

先说明收敛性。 被积函数 f(x)>0f(x)>0f(x)>0，只需证明积分收敛（此时也是绝对收敛）。

当 a≥0a\ge0a≥0 时，对 x≥1x\ge1x≥1 有 1+xa≥11+x^{a}\ge11+xa≥1，故 0<f(x)≤1x2,0<f(x)\le\frac{1}{x^{2}},0<f(x)≤x21​, 而 ∫1+∞x−2dx\displaystyle\int_{1}^{+\infty}x^{-2}\mathrm{d} x∫1+∞​x−2dx 收敛；在 0<x≤10<x\le10<x≤1 上 f(x)≤1f(x)\le1f(x)≤1 有界，不是瑕点。

作换元。 令 x=1tx=\dfrac{1}{t}x=t1​，则 dx=−dtt2\mathrm{d} x=-\dfrac{\mathrm{d} t}{t^{2}}dx=−t2dt​，且 1+x2=1+t2t2,1+xa=1+t−a=1+tata.1+x^{2}=\frac{1+t^{2}}{t^{2}},\qquad 1+x^{a}=1+t^{-a}=\frac{1+t^{a}}{t^{a}}.1+x2=t21+t2​,1+xa=1+t−a=ta1+ta​. 于是 dx(1+x2)(1+xa)=t2+a(1+t2)(1+ta)⋅(−dtt2)=−ta(1+t2)(1+ta)dt.\frac{\mathrm{d} x}{\left(1+x^{2}\right)\left(1+x^{a}\right)} =\frac{t^{2+a}}{\left(1+t^{2}\right)\left(1+t^{a}\right)}\cdot\left(-\frac{\mathrm{d} t}{t^{2}}\right) =-\frac{t^{a}}{\left(1+t^{2}\right)\left(1+t^{a}\right)}\mathrm{d} t.(1+x2)(1+xa)dx​=(1+t2)(1+ta)t2+a​⋅(−t2dt​)=−(1+t2)(1+ta)ta​dt. 注意 xxx 从 000 到 +∞+\infty+∞ 时，ttt 从 +∞+\infty+∞ 到 000，换限后负号抵消： I(a)=∫0+∞ta(1+t2)(1+ta)dt.I(a)=\int_{0}^{+\infty}\frac{t^{a}}{\left(1+t^{2}\right)\left(1+t^{a}\right)}\mathrm{d} t.I(a)=∫0+∞​(1+t2)(1+ta)ta​dt. 把积分变量改回 xxx，与原式相加： 2I(a)=∫0+∞1+xa(1+x2)(1+xa)dx=∫0+∞dx1+x2=π2.2I(a)=\int_{0}^{+\infty}\frac{1+x^{a}}{\left(1+x^{2}\right)\left(1+x^{a}\right)}\mathrm{d} x =\int_{0}^{+\infty}\frac{\mathrm{d} x}{1+x^{2}} =\frac{\pi}{2}.2I(a)=∫0+∞​(1+x2)(1+xa)1+xa​dx=∫0+∞​1+x2dx​=2π​. 所以 I(a)=π4,I(a)=\frac{\pi}{4},I(a)=4π​, 与 aaa 无关。

常见错误展开

一是换元时漏掉 dx=−dtt2\mathrm{d} x=-\dfrac{\mathrm{d} t}{t^{2}}dx=−t2dt​ 里的 t−2t^{-2}t−2，或者忘记换限带来的负号，结果符号错掉。二是化简 1+xa1+x^{a}1+xa 时把它写成 1+ta1+t^{a}1+ta 而漏掉分母 tat^{a}ta——正确结果是 1+tata\dfrac{1+t^{a}}{t^{a}}ta1+ta​，这是整个技巧的核心。三是相加后得到 2I=π22I=\dfrac{\pi}{2}2I=2π​ 却忘记除以 2，答成 π2\dfrac{\pi}{2}2π​。四是认为 a<0a<0a<0 时 x→0+x\to0^{+}x→0+ 处 xa→+∞x^{a}\to+\inftyxa→+∞ 就一定发散，其实 f(x)∼x−af(x)\sim x^{-a}f(x)∼x−a 且 −a>−1-a>-1−a>−1，是可积的瑕点。
