汇编语言与程序的机器级表示 · 概念题

计算机系统概论 概念题 难度 自编 投稿：自编
导出这道题 ICS-007 · ←→ 翻题 · E 展开 · D 记已做

函数 f 的两个参数 x、y 分别放在 %rdi、%rsi，返回值放在 %rax。汇编是

f:
    cmpq %rsi, %rdi
    ja .L1
    movl $0, %eax
    ret
.L1:
    movl $1, %eax
    ret

(1) 这段汇编把两个参数按有符号数还是无符号数比较？cmpq %rsi, %rdi 计算的是谁减谁？

(2) 若执行 f(-1, 1)，返回值是多少？f(1, -1) 呢？

(3) 若对应源码是 long f(long x, long y) { return x > y; }，编译器应当生成哪条跳转指令？这段汇编与源码一致吗？

(4) 若源码改成 unsigned long 版本，这段汇编是否正确？

提示+
ja 判的是「无符号大于」，靠的是 CF=0 且 ZF=0；有符号大小要用 jg，靠的是 SF、OF、ZF 的组合。同一个位模式，用哪条 jcc 决定了它的「类型」。

解析（先自己做一遍再看）展开
答案

(1) 按无符号比较，计算 Rrdi−RrsiR_{rdi}-R_{rsi}Rrdi​−Rrsi​；(2) f(−1,1)=1f(-1,1)=1f(−1,1)=1、f(1,−1)=0f(1,-1)=0f(1,−1)=0；(3) 应用 jg，这段汇编不一致；(4) 对 unsigned long 正确

(1) ja 是「无符号大于」，所以这段代码把 %rdi、%rsi 当无符号数比较。AT&T 顺序是「源在前、目的在后」，cmpq %rsi, %rdi 计算的是

Rrdi−Rrsi,R_{rdi}-R_{rsi},Rrdi​−Rrsi​,

即判断 x > y（无符号意义下）。

(2) -1 在 64 位下的位模式是全 1，作为无符号数是 264−12^{64}-1264−1。

f(-1, 1)：比较 (264−1)(2^{64}-1)(264−1) 与 111，无符号意义下前者大，ja 成立，跳到 .L1，返回 1。

f(1, -1)：比较 111 与 (264−1)(2^{64}-1)(264−1)，前者小，ja 不成立，返回 0。

(3) C 的 x > y 中 x、y 是 long，有符号比较应当生成

cmpq %rsi, %rdi
jg .L1

jg（有符号大于）在 x=−1x=-1x=−1、y=1y=1y=1 时判断为假，返回 0，与 C 语义一致。而题中的 ja 对负数会给出相反的结果（f(-1,1)=1），所以两者不一致：这段汇编实际上是「把参数当无符号数」的版本。

(4) 如果源码是 unsigned long x, y，x > y 本来就是无符号比较，编译器会生成 ja，这段汇编正确。

这说明：汇编层没有类型信息，操作同一组寄存器、同一组条件码，「有符号」还是「无符号」完全由指令选择决定。C 的类型在编译后只剩下「选了哪条指令」。

常见错误展开

一是把 ja 当成「大于」的通用写法，忽略它只对无符号数成立。二是把 cmpq %rsi, %rdi 的方向记反，算成 y - x，结论全反。三是认为 set 或 jcc 会检查「操作数声明时的类型」——机器码里没有类型，只有位模式和标志位。四是第 (4) 问答「也要改」，其实 ja 对无符号正是对的。
