提示+

分部积分一次，得到 InI_nIn​ 与 In−2I_{n-2}In−2​ 的递推关系。再看 sin⁡nx\sin^n xsinnx 随 nnn 增大是单调递减的，所以三个相邻的 III 一定是夹着的——夹逼能逼出「比值趋于 1」，但要的是量级，还得把递推乘起来。

常见错误展开
  • 直接迭代递推式：In=n−1n⋅n−3n−2⋯I_n=\frac{n-1}{n}\cdot\frac{n-3}{n-2}\cdotsIn​=nn−1​⋅n−2n−3​⋯ 只给出奇偶两条链，得不到共同的量级。
  • 以为 InI_nIn​ 与 In−1I_{n-1}In−1​ 只差一个常数倍：它们只是比值趋于 1，不能互换着写等式。
