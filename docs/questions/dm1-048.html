命题逻辑的公理化 · 证明题

离散数学1 证明题 难度 自编 投稿：自编
导出这道题 DM1-048 · ←→ 翻题 · E 展开 · D 记已做

仍考虑罗素公理系统：四条公理为

(A1) (p∨p)→p,(A2) p→(p∨q),(A3) (p∨q)→(q∨p),\text{(A1)}\ (p\vee p)\to p,\qquad \text{(A2)}\ p\to(p\vee q),\qquad \text{(A3)}\ (p\vee q)\to(q\vee p),(A1) (p∨p)→p,(A2) p→(p∨q),(A3) (p∨q)→(q∨p),

(A4) (q→r)→((p∨q)→(p∨r)),\text{(A4)}\ (q\to r)\to\bigl((p\vee q)\to(p\vee r)\bigr),(A4) (q→r)→((p∨q)→(p∨r)),

变形规则为代入规则、分离规则、置换规则（按 →\to→、∧\wedge∧、↔\leftrightarrow↔ 的定义互换子公式）。

(1) 验证四条公理都是重言式；

(2) 证明三条变形规则都保持重言性：重言式经代入仍是重言式；由重言式经分离得到的是重言式；重言式经置换仍是重言式；

(3) 由此证明该公理系统是可靠的：系统中推出的每个定理都是重言式；

(4) 由可靠性说明该系统是一致的：不存在公式 AAA 使 ⊢A\vdash A⊢A 与 ⊢¬A\vdash\neg A⊢¬A 同时成立。

提示+

可靠性是"公理都真 + 规则保真 ⟹ 所有定理都真"。所以先把四条公理逐条验证，再逐条检查变形规则是否会把"恒真"破坏掉，最后对证明序列的长度做归纳。一致性则直接用"AAA 与 ¬A\neg A¬A 不可能同时为真"。

解析（先自己做一遍再看）展开
答案

四条公理均为重言式；代入、分离、置换都保持重言性；由证明序列归纳得所有定理都是重言式，故系统可靠；若同时 ⊢A\vdash A⊢A 与 ⊢¬A\vdash\neg A⊢¬A，则 AAA 与 ¬A\neg A¬A 都重言，矛盾，故系统一致

关键的一步是把"可靠性"拆成两件事：公理本身都真（基础），所有变形规则都保真（传递），再对证明序列的长度做归纳，就得到"每一步都真"。

(1) 逐条验证（用"设前件真，推后件真"的语义说法，等价于验证蕴含式恒真）。

  • (A1)：p∨pp\vee pp∨p 与 ppp 真值相同，故 (p∨p)→p(p\vee p)\to p(p∨p)→p 恒真。
  • (A2)：若 ppp 真，则 p∨qp\vee qp∨q 真，故 p→(p∨q)p\to(p\vee q)p→(p∨q) 恒真。
  • (A3)：p∨qp\vee qp∨q 与 q∨pq\vee pq∨p 由交换律等值，故蕴含式恒真。
  • (A4)：设 q→rq\to rq→r 真且 p∨qp\vee qp∨q 真，要证 p∨rp\vee rp∨r 真。由 p∨qp\vee qp∨q 真，分两种情形：若 ppp 真，则 p∨rp\vee rp∨r 真；若 qqq 真，由 q→rq\to rq→r 真得 rrr 真，从而 p∨rp\vee rp∨r 真。两种情形都成立，故 (A4) 恒真。

也可用等值演算验证，例如 (A1)：

(p∨p)→p=¬(p∨p)∨p=(¬p∧¬p)∨p=¬p∨p,(p\vee p)\to p=\neg(p\vee p)\vee p=(\neg p\wedge\neg p)\vee p=\neg p\vee p,(p∨p)→p=¬(p∨p)∨p=(¬p∧¬p)∨p=¬p∨p,

是重言式。

(2) 代入规则。 设 AAA 是重言式，σ\sigmaσ 是任一代入。任取 σ(A)\sigma(A)σ(A) 的一组赋值 vvv，对 AAA 中每个命题变项 ppp 令 v′(p)=v(σ(p))v'(p)=v(\sigma(p))v′(p)=v(σ(p))，对结构归纳可得 v(σ(A))=v′(A)=1v(\sigma(A))=v'(A)=1v(σ(A))=v′(A)=1。故 σ(A)\sigma(A)σ(A) 是重言式。

分离规则。 设 AAA 与 A→BA\to BA→B 都是重言式。任取赋值 vvv：由 v(A)=1v(A)=1v(A)=1 与 v(A→B)=1v(A\to B)=1v(A→B)=1，蕴含式只有在"前件真、后件假"时才假，故必有 v(B)=1v(B)=1v(B)=1。所以 BBB 是重言式。

置换规则。 置换是按定义把子公式在定义式左右两边互换，例如把 A→BA\to BA→B 换成 ¬A∨B\neg A\vee B¬A∨B。定义式两边对任意赋值真值相同，所以替换后整个公式的真值不变，重言性保持。

(3) 设 AAA 是系统中的定理，则存在一个有限的证明序列

A1, A2, …, An=A,A_1,\ A_2,\ \dots,\ A_n=A,A1​, A2​, …, An​=A,

其中每个 AiA_iAi​ 要么是公理，要么是由前面的某些 AjA_jAj​ 经变形规则得到的（代入、分离、置换）。

对下标 iii 归纳证明每个 AiA_iAi​ 都是重言式：

  • AiA_iAi​ 是公理时，由 (1) 它是重言式；
  • AiA_iAi​ 由代入或置换得到时，由 (2) 保持重言性；
  • AiA_iAi​ 由分离得到时，由 (2) 保持重言性。

归纳完毕，An=AA_n=AAn​=A 是重言式。由 AAA 的任意性，所有定理都是重言式，即系统可靠。

(4) 反设存在 AAA 使 ⊢A\vdash A⊢A 且 ⊢¬A\vdash\neg A⊢¬A。由 (3)，AAA 与 ¬A\neg A¬A 都是重言式。但任取一组赋值 vvv，v(A)v(A)v(A) 与 v(¬A)v(\neg A)v(¬A) 互为相反的真值，不可能同时为 111。矛盾。所以这样的 AAA 不存在，系统是一致的。

注意可靠性只说"推出的都是重言式"，并没有说"所有重言式都能推出"——后者是完备性，是另一个方向的性质，不能由本题的论证得到。

常见错误展开
  • 把可靠性与完备性弄反。可靠性是"定理 ⟹ 重言式"，完备性是"重言式 ⟹ 定理"；本题只证前者。
  • 验证公理时只代几组赋值试算。要说明恒真，必须给出覆盖任意赋值的论证。
  • 归纳时漏掉置换规则，或把"置换"当成"用任意等值公式替换"。置换规则只按定义左右互换，不能拿一般等值式随意替换。
  • 用"系统一致"直接推出"系统完备"。一致、可靠、完备是三个不同性质，互不蕴含（可靠且完备才有"定理 = 重言式"）。
