一台机器采用三级存储层次。设一次访存先查 L1：

  • L1 命中时间 111 个周期，命中率 95%95\%95%；
  • 未命中则查 L2：L2 命中时间 101010 个周期，在「L1 未命中」的访问中有 80%80\%80% 能在 L2 命中；
  • 仍未命中则访问主存，主存访问时间 100100100 个周期。

(1) 求平均访存时间 AMAT。

(2) 程序一共产生 1.0×1091.0\times10^{9}1.0×109 次访存，主频 2 GHz2\ \text{GHz}2 GHz，求访存部分的总时间。

(3) 通过循环分块把 L1 命中率提高到 99%99\%99%，其他条件不变，求新的 AMAT 与总时间、加速比。

(4) 另有两个候选改进：把 L2 命中率从 80%80\%80% 提高到 90%90\%90%，或把主存访问时间从 100100100 个周期降到 505050 个周期。分别算出 AMAT，并说明三者中哪个最值得做。

提示+

AMAT 要从外到内一层层算：111 个周期是「无论如何都要付」的，L1 缺失时再付 L2 的代价，L2 也缺失时再付主存的代价。每一层的代价都要乘上「真的走到这一层」的概率——概率是逐层相乘的。

解析（先自己做一遍再看）展开
答案

(1) AMAT=2.5\text{AMAT}=2.5AMAT=2.5 周期；(2) 2.5×1092.5\times10^{9}2.5×109 周期，1.25 s1.25\ \text{s}1.25 s；(3) 分块后 AMAT=1.3\text{AMAT}=1.3AMAT=1.3，时间 0.65 s0.65\ \text{s}0.65 s，加速比约 1.921.921.92；(4) 三种改动分别得 1.31.31.3、2.02.02.0、2.02.02.0，提高 L1 命中率收益最大

(1) 先理清概率：

  • L1 缺失率 1−0.95=0.051-0.95=0.051−0.95=0.05；
  • 走到 L2 的访问里，20%20\%20% 会继续缺失，所以 L2 缺失对全部访问的概率是 0.05×0.2=0.010.05\times0.2=0.010.05×0.2=0.01；
  • 走到主存对全部访问的概率也是 0.010.010.01。

于是

AMAT=1+0.05×(10+0.2×100)=1+0.05×(10+20)=1+1.5=2.5 周期.\text{AMAT}=1+0.05\times\Bigl(10+0.2\times100\Bigr) =1+0.05\times(10+20) =1+1.5=2.5\ \text{周期}.AMAT=1+0.05×(10+0.2×100)=1+0.05×(10+20)=1+1.5=2.5 周期.

也可以用「逐层乘概率」的写法：

AMAT=1+0.05×10+0.01×100=1+0.5+1.0=2.5.\text{AMAT}=1+0.05\times10+0.01\times100=1+0.5+1.0=2.5.AMAT=1+0.05×10+0.01×100=1+0.5+1.0=2.5.

两种写法一致，第二种更不容易错。

(2) 访存总周期数

1.0×109×2.5=2.5×109,1.0\times10^{9}\times2.5=2.5\times10^{9},1.0×109×2.5=2.5×109,

在 2 GHz2\ \text{GHz}2 GHz 下

T=2.5×1092×109=1.25 s.T=\frac{2.5\times10^{9}}{2\times10^{9}}=1.25\ \text{s}.T=2×1092.5×109​=1.25 s.

(3) L1 命中率 99%99\%99%，缺失率 0.010.010.01：

AMAT′=1+0.01×(10+0.2×100)=1+0.01×30=1.3 周期.\text{AMAT}'=1+0.01\times(10+0.2\times100)=1+0.01\times30=1.3\ \text{周期}.AMAT′=1+0.01×(10+0.2×100)=1+0.01×30=1.3 周期.

总时间

T′=1.0×109×1.32×109=0.65 s,T'=\frac{1.0\times10^{9}\times1.3}{2\times10^{9}}=0.65\ \text{s},T′=2×1091.0×109×1.3​=0.65 s,

加速比

1.250.65≈1.92.\frac{1.25}{0.65}\approx1.92.0.651.25​≈1.92.

省下的 0.6 s0.6\ \text{s}0.6 s 全部来自「L1 缺失次数从 5%5\%5% 降到 1%1\%1%」。

(4) 分别计算：

  • L1 命中率 99%99\%99%：AMAT=1+0.01×30=1.3\text{AMAT}=1+0.01\times30=1.3AMAT=1+0.01×30=1.3；
  • L2 命中率 90%90\%90%：L2 缺失概率变成 0.05×0.1=0.0050.05\times0.1=0.0050.05×0.1=0.005，

AMAT=1+0.05×10+0.005×100=1+0.5+0.5=2.0;\text{AMAT}=1+0.05\times10+0.005\times100=1+0.5+0.5=2.0;AMAT=1+0.05×10+0.005×100=1+0.5+0.5=2.0;

  • 主存降到 505050 个周期：

AMAT=1+0.05×(10+0.2×50)=1+0.05×20=2.0.\text{AMAT}=1+0.05\times(10+0.2\times50)=1+0.05\times20=2.0.AMAT=1+0.05×(10+0.2×50)=1+0.05×20=2.0.

三者从 2.52.52.5 分别降到 1.31.31.3、2.02.02.0、2.02.02.0，提高 L1 命中率收益最大。原因：L1 缺失会同时触发 L2 和主存两级代价，每一次「少一次 L1 缺失」都省掉整条 10+20=3010+20=3010+20=30 周期的链；而 L2 命中率或主存延迟的改进只作用在已经很少的深层访问上。

常见错误展开

一是把 L2 的 80%80\%80% 当成「全部访问的 80%80\%80%」——它是「L1 缺失的访问中」的 80%80\%80%，必须乘 0.050.050.05。二是把 AMAT 写成 1+10+1001+10+1001+10+100 或 0.95×1+0.05×100.95\times1+0.05\times100.95×1+0.05×10 这类漏掉主存项的形式。三是第 (3) 问忘记 L2、主存的代价不变，只把 111 换成 111 却没改系数。四是第 (4) 问直接比较「L2 命中率 +10%」与「主存延迟减半」的百分比，而不换算成 AMAT 的实际节省。
