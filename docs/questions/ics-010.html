数组与结构体 · 计算题

计算机系统概论 计算题 难度 自编 投稿：自编
导出这道题 ICS-010 · ←→ 翻题 · E 展开 · D 记已做

有下面的 C 代码：

long a[5] = {10, 20, 30, 40, 50};
long *p = a + 2;
char *c = (char *)a;

(1) *p 与 *(p + 1) 的值分别是多少？

(2) p - a 的值是多少？p 与 a 的地址相差多少字节？

(3) c + 3 指向哪里？*(long *)(c + 8) 的值是多少？

(4) &a[3] 相对 a 的偏移是多少字节？

提示+
long 占 8 字节：long * 每加 1 走 8 字节，char * 每加 1 走 1 字节。数组名 a 是首元素地址，a + i 与 &a[i] 等价。

解析（先自己做一遍再看）展开
答案

(1) 303030 与 404040；(2) 222，相差 16 字节；(3) 指向 a\texttt{a}a 起始后第 3 个字节，值为 202020；(4) 24 字节

(1) a + 2 指向 a[2]，所以 \*p 是 30；p + 1 指向 a[3]，\*(p + 1) 是 40。

(2) 指针相减得到「相隔多少个元素」，不是字节数：

p−a=2.p-a=2.p−a=2.

一个 long 是 8 字节，所以地址相差 2×8=162\times8=162×8=16 字节。

(3) c 是 char *，指向 a 的第 0 个字节；c + 3 指向 a 起始地址之后第 3 个字节（它在 a[0] 这 8 个字节的内部，不是 a[3]）。

c + 8 就是 a 的起始地址加 8 字节，即 a[1] 的地址；把它转成 long * 再解引用，得到

\*(long∗)(c+8)=a[1]=20.\*(long *)(c+8)=a[1]=20.\*(long∗)(c+8)=a[1]=20.

(4) &a[3] 的偏移是

3×8=24 字节.3\times8=24\ \text{字节}.3×8=24 字节.

三个问题的共同点：指针算术按所指类型的大小缩放。a + 2 是加 16 字节，c + 2 是加 2 字节，数字一样但走的距离不一样。

常见错误展开

一是把 p - a 算成 16（把字节差当元素差）。二是把 c + 3 当成 a[3] 的地址——c 是 char *，只走了 3 个字节。三是以为 a 有「数组长度」信息，sizeof(a) 才是 40 字节，而 a 本身作为地址只占 8 字节。四是解引用 (long *)(c + 3) 这类未对齐访问——本题故意只让你算 c + 3 的位置，不要去读它，x86-64 上这种访问虽然能跑但属于未对齐访问。
