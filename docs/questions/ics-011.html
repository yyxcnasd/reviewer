数组与结构体 · 综合题

计算机系统概论 综合题 难度 自编 投稿：自编
导出这道题 ICS-011 · ←→ 翻题 · E 展开 · D 记已做

考虑下面的结构体：

struct S {
    char   c;
    int    i;
    char   d;
    double x;
    short  s;
};

(1) 求各成员的偏移与 sizeof(struct S)。

(2) 重排成员顺序，使 sizeof(struct S) 最小，写出新的定义与大小。

(3) struct S arr[4]; 中 arr[2] 相对 arr 的偏移是多少字节？

(4) 在原来的 struct S 末尾再加一个 char e;，sizeof(struct S) 会变成多少？为什么？

提示+

对齐三规则：成员偏移是自身对齐的倍数；结构体总大小是最大对齐的倍数；不满足时插填充。double 要 8 字节对齐，int 要 4，short 要 2，char 要 1。注意尾部填充，以及结构体数组的步长等于 sizeof(struct)。

解析（先自己做一遍再看）展开
答案

(1) 偏移 0,4,8,16,240,4,8,16,240,4,8,16,24，sizeof=32\texttt{sizeof}=32sizeof=32；(2) 顺序 double x; int i; short s; char c; char d;，大小 161616；(3) 646464；(4) 仍是 323232

(1) 最大对齐是 double 的 8，所以结构体总大小要是 8 的倍数。

c i d x s
成员 大小 对齐 偏移
1 1 0
4 4 4（1–3 填充）
1 1 8
8 8 16（9–15 填充）
2 2 24

成员占到偏移 25，结构体大小向上取到 8 的倍数：

sizeof(struct S)=32.\texttt{sizeof(struct S)}=32.sizeof(struct S)=32.

(2) 原则是「大的在前、小的在后」，让填充尽量少：

struct T {
    double x;  /* 0 */
    int    i;  /* 8 */
    short  s;  /* 12 */
    char   c;  /* 14 */
    char   d;  /* 15 */
};

成员占 16 字节，正好是 8 的倍数，所以

sizeof(struct T)=16,\texttt{sizeof(struct T)}=16,sizeof(struct T)=16,

比原来省了一半。

(3) 数组元素之间按 sizeof(struct S) 等距排列，所以

&arr[2]=&arr[0]+2×32,\&arr[2]=\&arr[0]+2\times32,&arr[2]=&arr[0]+2×32,

即偏移 64 字节。注意这里是 32 而不是成员大小之和 26：填充也算进步长。

(4) s 占偏移 24–25，末尾追加的 e 放在偏移 26，需要 27 字节；向上取到 8 的倍数得

sizeof=32,\texttt{sizeof}=32,sizeof=32,

不变。原来 s 后面就从 26 到 31 是尾部填充，正好把这个 char 塞进去。这说明「末尾加个小成员」不一定让结构体变大——这也是实际工程里用「末尾保留字段」做版本兼容的原因之一。

常见错误展开

一是按「1+4+1+8+2=16」直接给出 sizeof，忽略填充。二是重排时只把 char 挪到前面，忘了 double 必须在 8 的倍数偏移上，排出来的大小不是最优。三是把 arr[2] 的偏移算成 2×26=522\times26=522×26=52，用了成员大小之和而不是 sizeof。四是第 (4) 问认为加了成员就一定要扩大 8 字节——尾部填充可能刚好容纳它。
