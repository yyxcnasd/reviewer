x86-64 上 int 的除法用 sarl（算术右移）与一个偏置来实现。回答：

（1）设 int x = -7;，分别求 x / 4 与 x >> 2 的值（假设 >> 是算术右移），并解释为什么编译器不能把 x / 4 直接编译成 sarq $2。

（2）编译器对 x / 4（x 为 int）常生成下面的序列：

    leal 3(%rdi), %eax
    testl %edi, %edi
    cmovs %eax, %edi
    sarl $2, %edi

说明偏置 3 是怎么来的，并验证 x / 8 的偏置应为 7、x = -9 时结果为 -1。

（3）如果 x 是 unsigned，为什么编译器可以直接用 shrl $2？

（4）分别求 -1 >> 1、-1 / 2、-6 >> 2、-6 / 4 的值。

提示+

C 的整数除法向零截断，而算术右移是向下取整。对负数且不能整除时，两者恰好差 1；偏置 2k−12^{k}-12k−1 就是用来把「向下取整」修正成「向零取整」的。注意偏置只对负数加。

解析（先自己做一遍再看）展开
答案

（1）−7/4=−1-7/4=-1−7/4=−1，−7≫2=−2-7\gg2=-2−7≫2=−2；（2）偏置为 2k−12^{k}-12k−1，x=−9x=-9x=−9 时 (−9+7)≫3=−1(-9+7)\gg3=-1(−9+7)≫3=−1；（3）无符号右移就是逻辑右移，等价于向下取整的除法；（4）−1≫1=−1-1\gg1=-1−1≫1=−1、−1/2=0-1/2=0−1/2=0、−6≫2=−2-6\gg2=-2−6≫2=−2、−6/4=−1-6/4=-1−6/4=−1

关键的那一步为什么能想到。 把「除法」和「移位」都写成对 2k2^{k}2k 的取整，就看出了差别：算术右移 x≫kx\gg kx≫k 等于 ⌊x/2k⌋\lfloor x/2^{k}\rfloor⌊x/2k⌋，而 C 的 / 是 trunc⁡(x/2k)\operatorname{trunc}(x/2^{k})trunc(x/2k)。对负数、不能整除时 ⌊⋅⌋\lfloor\cdot\rfloor⌊⋅⌋ 比 trunc⁡(⋅)\operatorname{trunc}(\cdot)trunc(⋅) 小 1；给负数加上 2k−12^{k}-12k−1 再向下取整，正好把少掉的 1 补回来。于是「为什么是 2k−12^{k}-12k−1」和「为什么只对负数加」就都有了解释。

（1）C 的除法向零截断： −7/4=trunc⁡(−1.75)=−1.-7/4=\operatorname{trunc}(-1.75)=-1.−7/4=trunc(−1.75)=−1. 算术右移是向下取整： −7≫2=⌊−1.75⌋=−2.-7\gg2=\lfloor-1.75\rfloor=-2.−7≫2=⌊−1.75⌋=−2. 两者不相等，所以编译器不能直接把 x / 4 翻译成一条 sarq $2。

（2）对负数加偏置 22−1=32^{2}-1=322−1=3 后再算术右移： (−7+3)≫2=−4≫2=−1,(-7+3)\gg2=-4\gg2=-1,(−7+3)≫2=−4≫2=−1, 正好等于 −7/4-7/4−7/4。一般地，除以 2k2^{k}2k 时偏置为 2k−12^{k}-12k−1，所以 x / 8（k=3k=3k=3）的偏置是 777。验证 x=−9x=-9x=−9： −9/8=trunc⁡(−1.125)=−1,-9/8=\operatorname{trunc}(-1.125)=-1,−9/8=trunc(−1.125)=−1, 而 (−9+7)≫3=−2≫3=−1.(-9+7)\gg3=-2\gg3=-1.(−9+7)≫3=−2≫3=−1. 序列里的 testl + cmovs 就是「仅当 x<0x<0x<0 时把 x+3x+3x+3 送回 %edi」，正数不加偏置（否则 (7+3)≫2=2(7+3)\gg2=2(7+3)≫2=2，而 7/4=17/4=17/4=1 就错了）。

（3）无符号数的值是 000 到 232−12^{32}-1232−1，逻辑右移 x≫kx\gg kx≫k 就是 ⌊x/2k⌋\lfloor x/2^{k}\rfloor⌊x/2k⌋，而它本来就是非负的，与向零截断一致，所以无需偏置，shrl $2 即可。

（4）算术右移是向下取整，除法是向零截断： −1≫1=−1,−1/2=0,-1\gg1=-1,\qquad -1/2=0,−1≫1=−1,−1/2=0, −6≫2=⌊−1.5⌋=−2,−6/4=trunc⁡(−1.5)=−1.-6\gg2=\lfloor-1.5\rfloor=-2,\qquad -6/4=\operatorname{trunc}(-1.5)=-1.−6≫2=⌊−1.5⌋=−2,−6/4=trunc(−1.5)=−1. 这也说明：只有在「负数且除不尽」时两者才不同；能整除或非负时结果相同。

常见错误展开

一是把 C 的 / 当成向下取整，于是认为 −7/4=−2-7/4=-2−7/4=−2，与移位混为一谈。二是把偏置加到所有数上，忘了它只对负数使用（cmovs 的作用）。三是把偏置记成 2k2^{k}2k 或 2k−12^{k-1}2k−1：除以 2k2^{k}2k 的偏置是 2k−12^{k}-12k−1，即 3,7,15,…3,7,15,\dots3,7,15,…。四是以为右移负数在 C 里也保证算术右移——C 标准对负数右移是实现定义的，本题按 x86-64 的实际行为（算术右移）讨论。
