信息的表示与处理 · 概念题

计算机系统概论 概念题 难度 自编 投稿：自编
导出这道题 ICS-017 · ←→ 翻题 · E 展开 · D 记已做

单精度浮点数的位模式用十六进制给出。回答：

(1) 分别写出下列位模式表示的值或类别：0x7F800000、0xFF800000、0x7FC00000、0x00800000、0x007FFFFF、0x80000000。

(2) 计算 +∞+(−∞)+\infty+(-\infty)+∞+(−∞) 的结果。

(3) 判断：对任意浮点数 xxx，x == x 是否总成立？-0.0 == 0.0 是否成立？

提示+

阶码为 255255255 时是特殊值：尾数为 000 表示无穷，尾数非 000 表示 NaN。阶码为 000 时是非规格化数，尾数前没有隐含的 111，阶固定为 2−1262^{-126}2−126。符号位单独决定正负，零也有正负之分。

解析（先自己做一遍再看）展开
答案

(1) +∞+\infty+∞、−∞-\infty−∞、NaN、2−1262^{-126}2−126、(1−2−23)2−126(1-2^{-23})2^{-126}(1−2−23)2−126、−0-0−0；(2) NaN；(3) 前者不成立，后者成立

(1) 逐个拆开 1+8+231+8+231+8+23 位：

    0x7F800000：符号位 000，阶码 255255255，尾数 000，表示 +∞+\infty+∞； 0xFF800000：符号位 111，阶码 255255255，尾数 000，表示 −∞-\infty−∞； 0x7FC00000：阶码 255255255，尾数不为 000，表示 NaN； 0x00800000：阶码为 111，尾数为 000，是最小的规格化正数，

21−127=2−126≈1.1754944×10−38;2^{1-127}=2^{-126}\approx1.1754944\times10^{-38};21−127=2−126≈1.1754944×10−38;

    0x007FFFFF：阶码为 000，尾数全 111，是最大的非规格化正数。非规格化数的阶固定为 2−1262^{-126}2−126，尾数是 0.f0.f0.f，所以

(1−2−23)2−126=2−126−2−149≈1.1754942×10−38;\left(1-2^{-23}\right)2^{-126}=2^{-126}-2^{-149}\approx1.1754942\times10^{-38};(1−2−23)2−126=2−126−2−149≈1.1754942×10−38;

    0x80000000：符号位 111、其余全 000，表示 −0-0−0。

(2) 无穷大减无穷大在 IEEE 754 中没有确定值，规定结果为 NaN：

+∞+(−∞)=NaN.+\infty+(-\infty)=\text{NaN}.+∞+(−∞)=NaN.

(3) NaN 表示「不是一个数」，它和任何数（包括它自己）比较都不相等，所以 x == x 对 NaN 不成立。而 −0-0−0 与 +0+0+0 的位模式不同，但按数值比较是相等的，所以 -0.0 == 0.0 成立。

结论：(1) 依次为 +∞+\infty+∞、−∞-\infty−∞、NaN、2−1262^{-126}2−126、(1−2−23)2−126(1-2^{-23})2^{-126}(1−2−23)2−126、−0-0−0；(2) 结果为 NaN；(3) x == x 对 NaN 不成立，-0.0 == 0.0 成立。

常见错误展开

一是把 0x7F800000 当成「最大的有限数」，其实最大有限数的阶码是 254254254、尾数全 111。二是把 0x007FFFFF 加上隐含的 111 算成 (1+1−2−23)2−126(1+1-2^{-23})2^{-126}(1+1−2−23)2−126，非规格化数没有隐含的 111。三是认为 0x80000000 就是普通的 000，忘了它表示 −0-0−0，在 1/x 这类运算中会得到 −∞-\infty−∞ 而不是 +∞+\infty+∞。四是认为 NaN 与自身相等，或者认为 -0.0 与 0.0 不相等。
