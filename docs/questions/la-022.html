矩阵 · 证明题

线性代数 证明题 难度 自编
导出这道题 LA-022 · ←→ 翻题 · E 展开 · D 记已做

设 AAA 是 m×nm\times nm×n 矩阵，BBB 是 n×sn\times sn×s 矩阵，证明

(AB)⊤=B\TA⊤.(AB)^{\top}=B\TA^{\top}.(AB)⊤=B\TA⊤.

解析（先自己做一遍再看）展开

记 A=(aij)m×nA=(a_{ij})_{m\times n}A=(aij​)m×n​，B=(bij)n×sB=(b_{ij})_{n\times s}B=(bij​)n×s​。则 ABABAB 是 m×sm\times sm×s 矩阵，(AB)⊤(AB)^{\top}(AB)⊤ 是 s×ms\times ms×m 矩阵；B⊤B^{\top}B⊤ 是 s×ns\times ns×n 矩阵，A⊤A^{\top}A⊤ 是 n×mn\times mn×m 矩阵，所以 B\TA⊤B\TA^{\top}B\TA⊤ 也是 s×ms\times ms×m 矩阵。两边同型。

设 cijc_{ij}cij​ 是 ABABAB 的 (i,j)(i,j)(i,j) 元素，则

cij=∑k=1naikbkj.c_{ij}=\sum_{k=1}^{n}a_{ik}b_{kj}.cij​=k=1∑n​aik​bkj​.

按转置的定义，(AB)⊤(AB)^{\top}(AB)⊤ 的 (i,j)(i,j)(i,j) 元素就是 cjic_{ji}cji​，于是

[(AB)⊤]ij=cji=∑k=1najkbki.\left[(AB)^{\top}\right]_{ij}=c_{ji}=\sum_{k=1}^{n}a_{jk}b_{ki}.[(AB)⊤]ij​=cji​=k=1∑n​ajk​bki​.

再看右边：B⊤B^{\top}B⊤ 的 (i,k)(i,k)(i,k) 元素是 bkib_{ki}bki​，A⊤A^{\top}A⊤ 的 (k,j)(k,j)(k,j) 元素是 ajka_{jk}ajk​，所以

(B\TA⊤)ij=∑k=1nbkiajk=∑k=1najkbki.\left(B\TA^{\top}\right)_{ij}=\sum_{k=1}^{n}b_{ki}a_{jk}=\sum_{k=1}^{n}a_{jk}b_{ki}.(B\TA⊤)ij​=k=1∑n​bki​ajk​=k=1∑n​ajk​bki​.

两个表达式完全相同，故 (AB)⊤=B\TA⊤(AB)^{\top}=B\TA^{\top}(AB)⊤=B\TA⊤。

推广到多个因子：(A1A2⋯As)⊤=As⊤⋯A2\TA1⊤(A_{1}A_{2}\cdots A_{s})^{\top}=A_{s}^{\top}\cdots A_{2}\TA_{1}^{\top}(A1​A2​⋯As​)⊤=As⊤​⋯A2​\TA1⊤​，顺序全部反过来；特别地 (Ak)⊤=(A⊤)k(A^{k})^{\top}=(A^{\top})^{k}(Ak)⊤=(A⊤)k。

常见错误展开

写成 (AB)⊤=A\TB⊤(AB)^{\top}=A\TB^{\top}(AB)⊤=A\TB⊤。A⊤A^{\top}A⊤ 是 n×mn\times mn×m，B⊤B^{\top}B⊤ 是 s×ns\times ns×n，两者相乘要求 m=sm=sm=s，一般不成立；而且即使尺寸凑巧配上，元素也对不上。只有加法与数乘不改变顺序，乘积的转置一定要换序。
