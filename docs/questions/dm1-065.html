谓词逻辑的等值和推理演算 · 综合题

离散数学1 综合题 难度 自编 投稿：自编
导出这道题 DM1-065 · ←→ 翻题 · E 展开 · D 记已做

设语言含一元函数符号 fff 与二元谓词符号 PPP。项指由个体变元与 fff 有限次作用得到的有限表达式；替换指从变元到项的有限映射 σ={x1↦t1,…,xk↦tk}\sigma=\{x_1\mapsto t_1,\dots,x_k\mapsto t_k\}σ={x1​↦t1​,…,xk​↦tk​}，并按通常方式延拓到所有项与公式。

(1) 判断原子公式 P(x,f(x))P(x,f(x))P(x,f(x)) 与 P(f(y),y)P(f(y),y)P(f(y),y) 是否可合一。若可合一，求出最一般合一；若不可合一，证明不存在有限替换 σ\sigmaσ 使两者相同。

(2) 证明：不存在有限项 ttt 使 t=f(t)t=f(t)t=f(t)，也不存在有限项 ttt 使 t=f(f(t))t=f(f(t))t=f(f(t))。

(3) 若在合一算法中去掉 occurs check，算法会对 P(x)P(x)P(x) 与 P(f(x))P(f(x))P(f(x)) 输出替换 σ={x↦f(x)}\sigma=\{x\mapsto f(x)\}σ={x↦f(x)}。说明这个替换为什么不是合法的有限合一者，并解释 occurs check 在算法中的作用。

(4) 在带等词的一阶逻辑中，公式 x=f(x)x=f(x)x=f(x) 是否可满足？这与 (2) 是否矛盾？由此说明「存在有限合一」与「语义可满足」的区别。

提示+

(1) 合一就是解方程：由两个原子公式对应位置相等，得到 x=f(y)x=f(y)x=f(y) 与 f(x)=yf(x)=yf(x)=y，把第一式代入第二式。

(2) 对项的深度（fff 的嵌套层数）归纳：f(t)f(t)f(t) 的深度比 ttt 大 1。

(3) 反复把 x↦f(x)x\mapsto f(x)x↦f(x) 作用下去，会得到 x,f(x),f(f(x)),…x,f(x),f(f(x)),\dotsx,f(x),f(f(x)),… 的无限序列。有限合一者必须是一个「作用一次就稳定」的替换。

(4) 在某个模型里让 fff 是恒等映射，再给 xxx 任取一个元素。

解析（先自己做一遍再看）展开
答案

P(x,f(x))P(x,f(x))P(x,f(x)) 与 P(f(y),y)P(f(y),y)P(f(y),y) 不可合一，合一化归为 t=f(f(t))t=f(f(t))t=f(f(t)) 与有限项矛盾；不存在有限项 ttt 使 t=f(t)t=f(t)t=f(t)；去掉 occurs check 得到的 x↦f(x)x\mapsto f(x)x↦f(x) 不是有限合一；x=f(x)x=f(x)x=f(x) 在带等词逻辑中可满足（如 N\mathbb{N}N 上 fff 取恒等），与有限项条件不矛盾

(1) 反设存在有限替换 σ\sigmaσ 使两个原子公式相同。比较第一个变元位置，得

σ(x)=f(σ(y));\sigma(x)=f(\sigma(y));σ(x)=f(σ(y));

比较第二个位置，得

f(σ(x))=σ(y).f(\sigma(x))=\sigma(y).f(σ(x))=σ(y).

令 t=σ(y)t=\sigma(y)t=σ(y)，则第一式给出 σ(x)=f(t)\sigma(x)=f(t)σ(x)=f(t)。代入第二式：

f(f(t))=t.f(f(t))=t.f(f(t))=t.

由 (2)，不存在有限项 ttt 满足 t=f(f(t))t=f(f(t))t=f(f(t))，矛盾。因此这两个原子公式不可合一。直观上，合一要求 xxx 与 yyy 互相「包裹」对方，形成无限下降，有限项做不到。

(2) 定义项的深度 d(t)d(t)d(t)：变元的深度为 0，d(f(t))=d(t)+1d(f(t))=d(t)+1d(f(t))=d(t)+1。若 t=f(t)t=f(t)t=f(t)，则

d(t)=d(f(t))=d(t)+1,d(t)=d(f(t))=d(t)+1,d(t)=d(f(t))=d(t)+1,

矛盾。若 t=f(f(t))t=f(f(t))t=f(f(t))，则 d(t)=d(t)+2d(t)=d(t)+2d(t)=d(t)+2，同样矛盾。所以不存在这样的有限项。这个论证只用到「项是有限语法对象、fff 每作用一次深度加 1」，不涉及任何语义。

(3) 替换 σ={x↦f(x)}\sigma=\{x\mapsto f(x)\}σ={x↦f(x)} 从形式上看确实是一个「变元到有限项」的映射，但它不是合一者：合一要求 σ(P(x))=σ(P(f(x)))\sigma(P(x))=\sigma(P(f(x)))σ(P(x))=σ(P(f(x)))，即

σ(x)=f(σ(x)).\sigma(x)=f(\sigma(x)).σ(x)=f(σ(x)).

而把 σ\sigmaσ 再作用一次会得到 σ(σ(x))=σ(f(x))=f(f(x))\sigma(\sigma(x))=\sigma(f(x))=f(f(x))σ(σ(x))=σ(f(x))=f(f(x))，并不等于 f(x)=σ(x)f(x)=\sigma(x)f(x)=σ(x)。也就是说，σ\sigmaσ 不幂等；反复作用会得到无限序列

x, f(x), f(f(x)), f(f(f(x))),…x,\ f(x),\ f(f(x)),\ f(f(f(x))),\dotsx, f(x), f(f(x)), f(f(f(x))),…

永远不会稳定。要让它成为合一者，只能允许无限项，而无限项不是本题语言中的项。occurs check 的作用就是在算法执行「xxx 与项 ttt 合一」这一步时检查 xxx 是否出现在 ttt 中：若出现，立即报告不可合一，从而保证算法输出的替换是有限且幂等的。去掉它，算法可能在 xxx 与 f(x)f(x)f(x) 上无限展开，或者输出一个无法用于有限归结的伪替换。

(4) 可满足。取论域 D=ND=\mathbb{N}D=N，把 fff 解释为恒等映射 f(n)=nf(n)=nf(n)=n，并令 xxx 取 000，则 0=f(0)=00=f(0)=00=f(0)=0 成立。所以公式 x=f(x)x=f(x)x=f(x) 有模型（事实上任何让 fff 有不动点的解释都行）。

这与 (2) 不矛盾。(2) 说的是：在自由项代数中，不存在有限项 ttt 与 f(t)f(t)f(t) 语法相同。而 x=f(x)x=f(x)x=f(x) 是可满足性断言，允许我们在模型中把 fff 解释成任意函数，包括恒等映射；此时 fff 不再要求「每作用一次深度加 1」。换言之：

  • 「存在有限合一」是语法层面的断言，要求存在有限替换把两个项变成同一个有限项；
  • 「语义可满足」是模型层面的断言，只要求存在一个解释使等式为真。

因此不能用「x=f(x)x=f(x)x=f(x) 可满足」来论证「xxx 与 f(x)f(x)f(x) 可合一」，也不能用 occurs check 失败来断言 x=f(x)x=f(x)x=f(x) 不可满足。在带等词的归结中，等词需要额外的公理或 paramodulation 处理，普通合一不能替代等词推理。

常见错误展开
  • 认为 P(x,f(x))P(x,f(x))P(x,f(x)) 与 P(f(y),y)P(f(y),y)P(f(y),y) 可合一，并写出 {x/f(y),y/f(x)}\{x/f(y),y/f(x)\}{x/f(y),y/f(x)}。这个替换不幂等，代入后两个公式并不相同。
  • 把 occurs check 的失败解释成「等式 x=f(x)x=f(x)x=f(x) 不可满足」。两者一个在语法层、一个在语义层，不能混。
  • 在 (2) 中用「fff 是函数所以 t=f(t)t=f(t)t=f(t) 无解」一句话带过。必须用深度（或长度）归纳，因为没有假设 fff 是单射或没有不动点。
  • 在 (3) 中只说「会产生无限项」却不说明为什么无限项不合法：本题的项按定义就是有限表达式。
