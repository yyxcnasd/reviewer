函数调用 · 计算题

计算机系统概论 计算题 难度 自编 投稿：自编
导出这道题 ICS-008 · ←→ 翻题 · E 展开 · D 记已做

函数 sum 的参数 n 放在 %rdi，返回值放在 %rax。汇编是

sum:
    testq %rdi, %rdi
    jle .L2
    pushq %rbx
    movq %rdi, %rbx
    leaq -1(%rdi), %rdi
    call sum
    addq %rbx, %rax
    popq %rbx
    ret
.L2:
    movl $0, %eax
    ret

(1) 这个函数计算的是什么？求 sum(4)。

(2) 为什么把 n 存在 %rbx 里，而不是随便用一个 %rcx？

(3) 执行 sum(3) 的过程中，栈上最多同时有几个返回地址、几个保存的 %rbx？若 main 调用 sum 前 %rsp = 0x1000，每层占「8 字节返回地址 + 8 字节 rbx」，求最深时的 %rsp。

提示+
testq 判断 n <= 0，是递归的出口。注意 call sum 会覆盖调用者保存寄存器，%rbx 则是被调用者保存的。数栈深度时，别漏掉 main 调用 sum(3) 的那一次。

解析（先自己做一遍再看）展开
答案

(1) ∑i=1ni\sum_{i=1}^{n}i∑i=1n​i，sum(4)=10\texttt{sum}(4)=10sum(4)=10；(2) %rbx 是被调用者保存的；(3) 4 个返回地址、3 个保存的 %rbx，最深时 %rsp 为 0x0fc8\texttt{0x0fc8}0x0fc8

(1) 逐句看：

    testq %rdi, %rdi; jle .L2：n <= 0 时返回 0；
  • 否则先把 n 存进 %rbx，令参数变成 n-1，递归调用 sum(n-1)；
  • 返回后执行 addq %rbx, %rax，即把 n 加到 sum(n-1) 的结果上。

所以

sum(n)=n+sum(n−1),sum(0)=0,\text{sum}(n)=n+\text{sum}(n-1),\qquad \text{sum}(0)=0,sum(n)=n+sum(n−1),sum(0)=0,

即 sum(n)=∑i=1ni=n(n+1)2\text{sum}(n)=\sum_{i=1}^{n}i=\dfrac{n(n+1)}{2}sum(n)=∑i=1n​i=2n(n+1)​（n≥0n\ge0n≥0）。于是

sum(4)=4+3+2+1=10.\text{sum}(4)=4+3+2+1=10.sum(4)=4+3+2+1=10.

(2) 关键在于 call sum 之后还要用 n。%rcx 是调用者保存寄存器，被调用者（这里就是 sum 自己，以及它调用的其他函数）可以随意覆盖它，返回后 %rcx 里的值不可信。%rbx 是被调用者保存寄存器：谁要用它，谁就必须先 push、返回前 pop 恢复。这段代码正是 pushq %rbx 保存旧值、popq %rbx 恢复旧值，于是 %rbx 在当前帧里能稳定地保存 n。

(3) 逐层展开：

    main 调用 sum(3)：压入 1 个返回地址； sum(3)：push %rbx（存 3），call sum(2)（压返回地址）； sum(2)：push %rbx（存 2），call sum(1)（压返回地址）； sum(1)：push %rbx（存 1），call sum(0)（压返回地址）； sum(0) 直接返回，不再压栈。

最深时栈上有 4 个返回地址、3 个保存的 %rbx（sum(0) 还没执行到 push）。

地址计算：从 %rsp=0x1000 开始，main 的 call 减 8，之后每层减 16：

0x1000−8=0x0ff8,0x0ff8−16=0x0fe8,0x0fe8−16=0x0fd8,0x0fd8−16=0x0fc8.0x1000-8=0x0ff8,\qquad 0x0ff8-16=0x0fe8,\qquad 0x0fe8-16=0x0fd8,\qquad 0x0fd8-16=0x0fc8.0x1000−8=0x0ff8,0x0ff8−16=0x0fe8,0x0fe8−16=0x0fd8,0x0fd8−16=0x0fc8.

所以最深时 %rsp = 0x0fc8，总共用掉 0x38=560x38=560x38=56 字节。

常见错误展开

一是认为返回地址只有一个——每层递归调用都会压入自己的返回地址。二是把 %rcx 当成能跨 call 保留的寄存器，这样写出来的代码在递归里会拿到被覆盖的值。三是数栈深度时漏掉 main 的那一次调用，把返回地址数成 3 个。四是地址算成「每层 8 字节」，忘了 push %rbx 也要占 8 字节。
