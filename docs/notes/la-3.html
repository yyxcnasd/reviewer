3.1 n 维向量及其运算

分量运算与八条运算律

nnn 维列向量 α=(a1,a2,…,an)T\alpha=(a_1,a_2,\dots,a_n)^{\mathrm{T}}α=(a1​,a2​,…,an​)T，加法与数乘都按分量做：α+β=(ai+bi)\alpha+\beta=(a_i+b_i)α+β=(ai​+bi​)，kα=(kai)k\alpha=(ka_i)kα=(kai​)。

八条运算律：加法交换、结合，有零向量，有负向量，1α=α1\alpha=\alpha1α=α，k(lα)=(kl)αk(l\alpha)=(kl)\alphak(lα)=(kl)α，两条分配律。满足八条就叫数域 FFF 上的 nnn 维向量空间 FnF^nFn。

什么时候用：本章所有运算最终都落到分量上，先把向量统一写成同维列向量。

注意维数不同不能加减；kα=0k\alpha=0kα=0 必有 k=0k=0k=0 或 α=0\alpha=0α=0。

3.2 线性表示与线性组合

"能否表示"就是方程组有没有解

若存在 k1,…,kmk_1,\dots,k_mk1​,…,km​ 使

β=k1α1+k2α2+⋯+kmαm,\beta=k_1\alpha_1+k_2\alpha_2+\cdots+k_m\alpha_m,β=k1​α1​+k2​α2​+⋯+km​αm​,

称 β\betaβ 可由 α1,…,αm\alpha_1,\dots,\alpha_mα1​,…,αm​ 线性表示。以 αi\alpha_iαi​ 为列拼成 AAA，这就等价于 Ax=βAx=\betaAx=β 有解。

什么时候用：判断能否表示，看 (A∣β)(A\mid\beta)(A∣β) 化成阶梯形后有没有矛盾行；有自由未知量说明表示不唯一。

注意系数允许全为 000，所以零向量总能被任何向量组表示；方程个数多于未知量时，解出的系数必须代回每个方程验证。

向量组等价要双向验证

两个向量组 (I) 与 (II) 能互相线性表示，称它们等价。等价是等价关系：自反、对称、传递。

什么时候用：判断等价必须两个方向都做；只把 (II) 用 (I) 表示出来，只能说明 (II) 可由 (I) 表示，不叫等价。

传递性也好用：若 (I) 可由 (II) 表示、(II) 可由 (III) 表示，把 (II) 的表示式代进 (I)，就得到 (I) 可由 (III) 表示。

3.3 线性相关与线性无关

定义与它的否定式

存在不全为零的 k1,…,kmk_1,\dots,k_mk1​,…,km​ 使

k1α1+k2α2+⋯+kmαm=0,k_1\alpha_1+k_2\alpha_2+\cdots+k_m\alpha_m=0,k1​α1​+k2​α2​+⋯+km​αm​=0,

称 α1,…,αm\alpha_1,\dots,\alpha_mα1​,…,αm​ 线性相关；否则称线性无关。

否定式必须会写：线性无关   ⟺  \iff⟺ 只要 ∑ikiαi=0\sum_i k_i\alpha_i=0∑i​ki​αi​=0，就一定有 k1=⋯=km=0k_1=\cdots=k_m=0k1​=⋯=km​=0。

什么时候用：证明"无关"用否定式；证明"相关"只需找出一组不全为零的系数。

齐次方程组判据

以 αi\alpha_iαi​ 为列拼成 AAA，则

α1,…,αm 线性相关  ⟺  Ax=0 有非零解  ⟺  阶梯形非零行数<m.\alpha_1,\dots,\alpha_m\ \text{线性相关}\iff Ax=0\ \text{有非零解}\iff \text{阶梯形非零行数}<m .α1​,…,αm​ 线性相关⟺Ax=0 有非零解⟺阶梯形非零行数<m.

当 m=nm=nm=n（方阵）时还可写成   ⟺  ∣A∣=0\iff\left|A\right|=0⟺∣A∣=0。

什么时候用：数值向量组判相关，方阵就算 ∣A∣\left|A\right|∣A∣，个数与维数不等就化阶梯形数非零行。

五条常用判定

  • 含零向量的向量组必线性相关。
  • 个数大于维数必相关：FnF^nFn 中任意 n+1n+1n+1 个向量都线性相关。
  • 部分相关则整体相关；等价地，整体无关则部分无关（方向不能反）。
  • 单个向量 α\alphaα 相关   ⟺  α=0\iff\alpha=0⟺α=0；两个向量相关   ⟺  \iff⟺ 对应分量成比例。
  • 线性无关组添上 β\betaβ 后变成相关组   ⟺  β\iff\beta⟺β 可由该无关组表示，且表示唯一。

什么时候用：判断题先扫这五条，往往不用算行列式就有结论。

含参数向量组的讨论流程

  1. 个数等于维数：以向量为列拼方阵，算含参数的 ∣A∣\left|A\right|∣A∣，令 ∣A∣=0\left|A\right|=0∣A∣=0 解出参数；
  2. 个数不等于维数：化阶梯形，比较非零行数与向量个数；
  3. 每个临界参数值代回原向量组，写出具体的线性关系。

注意只报"相关/无关"不写关系，很多题只给一半分；临界值必须逐个代回。

3.4 向量组的秩与极大无关组

极大无关组与向量组的秩

向量组中线性无关、且能线性表示其余每个向量的部分组，叫极大无关组；所含向量的个数叫这个向量组的秩。

什么时候用：两个向量组等价时秩相同；比较向量组"大小"就看秩。

一条常用对应：向量组线性无关   ⟺  \iff⟺ 秩等于向量个数；含零向量、或个数大于维数时，秩一定小于个数。

用矩阵求秩与极大无关组

以向量为列拼成 AAA，化行最简形：非零行数就是秩；主元所在列对应的原向量，就是一组极大无关组。

什么时候用：给一堆向量求秩或找极大无关组，这是唯一通用算法。

注意主元列要回到原矩阵去取列，不能拿行变换之后的列。

常见问法与易错点

  • 表示题先看 (A∣β)(A\mid\beta)(A∣β) 有无矛盾行；有自由未知量就写通式，别只给一组系数。
  • 判相关：方阵算行列式，非方阵化阶梯形；"行列式不为零"对应线性无关。
  • "部分相关则整体相关"方向不能反：整体相关推不出部分相关。
  • 含参数题：临界值必须代回，写出成比例或和为 000 的具体关系。
  • 极大无关组取原矩阵的主元列，不是化完阶梯形后的列。
  • 向量组等价必须两个方向都写出来，只写一个方向只能叫"可表示"。
