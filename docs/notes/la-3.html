3.1 n 维向量及其运算

定义

数域 FFF 上 nnn 个有序的数排成一列，叫 nnn 维列向量：

α=(a1a2⋮an),\alpha=\begin{pmatrix}a_1\\a_2\\\vdots\\a_n\end{pmatrix},α=​a1​a2​⋮an​​​,

其中 aia_iai​ 叫第 iii 个分量。两个向量相等指同维且对应分量全相等。加法与数乘按分量定义：α+β=(ai+bi)\alpha+\beta=(a_i+b_i)α+β=(ai​+bi​)，kα=(kai)k\alpha=(ka_i)kα=(kai​)。分量全为零的向量叫零向量，记作 000。

定理（线性运算的性质）

对任意 α,β,γ∈Fn\alpha,\beta,\gamma\in F^nα,β,γ∈Fn 与 k,l∈Fk,l\in Fk,l∈F：加法满足交换律与结合律；存在零向量使 α+0=α\alpha+0=\alphaα+0=α；每个 α\alphaα 有负向量使 α+(−α)=0\alpha+(-\alpha)=0α+(−α)=0；数乘满足 k(lα)=(kl)αk(l\alpha)=(kl)\alphak(lα)=(kl)α 与 1α=α1\alpha=\alpha1α=α；分配律 k(α+β)=kα+kβk(\alpha+\beta)=k\alpha+k\betak(α+β)=kα+kβ、(k+l)α=kα+lβ(k+l)\alpha=k\alpha+l\beta(k+l)α=kα+lβ 成立。满足这八条，FnF^nFn 就叫数域 FFF 上的 nnn 维向量空间。

由定义还得到 0α=00\alpha=00α=0，k0=0k0=0k0=0，(−1)α=−α(-1)\alpha=-\alpha(−1)α=−α，以及 kα=0k\alpha=0kα=0 时必有 k=0k=0k=0 或 α=0\alpha=0α=0。

套路

  1. 参与运算的向量先统一写成同维列向量，维数不同不能加减；
  2. 线性组合按分量逐个算，系数与负号一起带；
  3. 遇到"求某个向量"的等式，先移项，再按分量算，通常不用解方程组。

例题

设 α=(1,2,−1)T\alpha=(1,2,-1)^Tα=(1,2,−1)T，β=(2,0,3)T\beta=(2,0,3)^Tβ=(2,0,3)T，求 2α−β2\alpha-\beta2α−β，并求 γ\gammaγ 使 2α+γ=β2\alpha+\gamma=\beta2α+γ=β。

按分量计算：

2α−β=(2,4,−2)T−(2,0,3)T=(0,4,−5)T,2\alpha-\beta=(2,4,-2)^T-(2,0,3)^T=(0,4,-5)^T,2α−β=(2,4,−2)T−(2,0,3)T=(0,4,−5)T,

γ=β−2α=(2,0,3)T−(2,4,−2)T=(0,−4,5)T.\gamma=\beta-2\alpha=(2,0,3)^T-(2,4,-2)^T=(0,-4,5)^T .γ=β−2α=(2,0,3)T−(2,4,−2)T=(0,−4,5)T.

这里 γ\gammaγ 就是解一个以向量为未知量的线性方程，移项即可，不需要解方程组。

3.2 线性表示与线性组合

定义

设 α1,…,αm∈Fn\alpha_1,\dots,\alpha_m\in F^nα1​,…,αm​∈Fn，k1,…,km∈Fk_1,\dots,k_m\in Fk1​,…,km​∈F。称

k1α1+k2α2+⋯+kmαmk_1\alpha_1+k_2\alpha_2+\cdots+k_m\alpha_mk1​α1​+k2​α2​+⋯+km​αm​

是 α1,…,αm\alpha_1,\dots,\alpha_mα1​,…,αm​ 的一个线性组合；若 β\betaβ 等于这样一个线性组合，称 β\betaβ 可由 α1,…,αm\alpha_1,\dots,\alpha_mα1​,…,αm​ 线性表示，也叫线性表出。系数允许全为 000，所以零向量总能被任何向量组表示。

定理（翻译成方程组）

以 α1,…,αm\alpha_1,\dots,\alpha_mα1​,…,αm​ 为列拼成矩阵 A=(α1,…,αm)A=(\alpha_1,\dots,\alpha_m)A=(α1​,…,αm​)，则：

  • β\betaβ 可由 α1,…,αm\alpha_1,\dots,\alpha_mα1​,…,αm​ 线性表示   ⟺  \iff⟺ 方程组 Ax=βAx=\betaAx=β 有解；
  • 表示唯一   ⟺  Ax=β\iff Ax=\beta⟺Ax=β 有唯一解；表示不唯一   ⟺  \iff⟺ 齐次方程组 Ax=0Ax=0Ax=0 有非零解。

判断只看增广矩阵 (A∣β)(A\mid\beta)(A∣β) 的阶梯形：出现 (0,…,0∣d)(0,\dots,0\mid d)(0,…,0∣d) 且 d≠0d\ne0d=0 就不能表示；否则能表示，回代即得全部系数。

向量组等价

若向量组 (I) 中每个向量都可由 (II) 线性表示，且 (II) 中每个向量都可由 (I) 线性表示，称 (I) 与 (II) 等价。等价关系有自反、对称、传递三条性质。传递性最实用：若每个 αi\alpha_iαi​ 可由 γ1,…,γs\gamma_1,\dots,\gamma_sγ1​,…,γs​ 表示，而 β\betaβ 可由 α1,…,αm\alpha_1,\dots,\alpha_mα1​,…,αm​ 表示，把 αi\alpha_iαi​ 的表示式代进 β\betaβ 的组合式，β\betaβ 就由 γ1,…,γs\gamma_1,\dots,\gamma_sγ1​,…,γs​ 表示。

套路

  1. 把 α1,…,αm\alpha_1,\dots,\alpha_mα1​,…,αm​ 按列排成 AAA，把 β\betaβ 接在后面成为增广列，得 (A∣β)(A\mid\beta)(A∣β)；
  2. 只用行变换化成阶梯形，看有没有矛盾行；
  3. 没有矛盾行就可表示，回代求系数；有自由未知量说明表示不唯一，写出通式；
  4. 有矛盾行就不能表示，不要再去凑系数。

例题

判断 β=(1,2,3)T\beta=(1,2,3)^Tβ=(1,2,3)T 能否由 α1=(1,0,1)T\alpha_1=(1,0,1)^Tα1​=(1,0,1)T，α2=(0,1,1)T\alpha_2=(0,1,1)^Tα2​=(0,1,1)T，α3=(1,1,2)T\alpha_3=(1,1,2)^Tα3​=(1,1,2)T 线性表示，并写出表示式。

(A∣β)=(101101121123)→r3−r1−r2(101101120000).(A\mid\beta)= \begin{pmatrix} 1&0&1&1\\ 0&1&1&2\\ 1&1&2&3 \end{pmatrix} \xrightarrow{r_3-r_1-r_2} \begin{pmatrix} 1&0&1&1\\ 0&1&1&2\\ 0&0&0&0 \end{pmatrix}.(A∣β)=​101​011​112​123​​r3​−r1​−r2​​​100​010​110​120​​.

没有矛盾行，可以表示。由前两行得 k1=1−k3k_1=1-k_3k1​=1−k3​，k2=2−k3k_2=2-k_3k2​=2−k3​，k3k_3k3​ 任意，所以表示不唯一。取 k3=0k_3=0k3​=0 得 β=α1+2α2\beta=\alpha_1+2\alpha_2β=α1​+2α2​；取 k3=1k_3=1k3​=1 得 β=α2+α3\beta=\alpha_2+\alpha_3β=α2​+α3​。两种写法都对，原因是 α3=α1+α2\alpha_3=\alpha_1+\alpha_2α3​=α1​+α2​。

3.3 向量组的线性相关性

定义

设 α1,…,αm∈Fn\alpha_1,\dots,\alpha_m\in F^nα1​,…,αm​∈Fn。若存在不全为零的数 k1,…,kmk_1,\dots,k_mk1​,…,km​ 使

k1α1+k2α2+⋯+kmαm=0,k_1\alpha_1+k_2\alpha_2+\cdots+k_m\alpha_m=0,k1​α1​+k2​α2​+⋯+km​αm​=0,

称 α1,…,αm\alpha_1,\dots,\alpha_mα1​,…,αm​ 线性相关；若这样的系数不存在，即只有 k1=⋯=km=0k_1=\cdots=k_m=0k1​=⋯=km​=0 才能使等式成立，称它们线性无关。

否定式必须会写：α1,…,αm\alpha_1,\dots,\alpha_mα1​,…,αm​ 线性无关   ⟺  \iff⟺ 只要 k1α1+⋯+kmαm=0k_1\alpha_1+\cdots+k_m\alpha_m=0k1​α1​+⋯+km​αm​=0，就有 k1=⋯=km=0k_1=\cdots=k_m=0k1​=⋯=km​=0。

定理（判定口径）

以 αi\alpha_iαi​ 为列拼成 AAA，则 α1,…,αm\alpha_1,\dots,\alpha_mα1​,…,αm​ 线性相关   ⟺  \iff⟺ 齐次方程组 Ax=0Ax=0Ax=0 有非零解   ⟺  \iff⟺ 阶梯形中非零行的行数小于 mmm。当 m=nm=nm=n 即 AAA 是方阵时，还可以直接用 ∣A∣=0|A|=0∣A∣=0 判定。

常用判定

  1. 含零向量的向量组一定线性相关；单个向量 α\alphaα 线性相关   ⟺  α=0\iff\alpha=0⟺α=0。
  2. 个数大于维数必相关：FnF^nFn 中任意 n+1n+1n+1 个向量都线性相关，因为方程个数少于未知量个数，齐次方程组必有非零解。
  3. 部分相关则整体相关；等价地，整体无关则部分无关。这条用来"部分推整体"，方向不能反。
  4. 线性无关组中每个向量都不能由其余向量表示；线性相关组中至少有一个向量能由其余表示，但不一定每个都能。
  5. 两个向量线性相关   ⟺  \iff⟺ 对应分量成比例，几何上就是共线。
  6. 线性无关组添上 β\betaβ 后变成相关组   ⟺  β\iff\beta⟺β 可由这个无关组表示，而且表示法唯一。

套路：含参数的向量组

  1. 若向量个数等于维数，以向量为列拼成方阵，算含参数的行列式 ∣A∣|A|∣A∣；
  2. 令 ∣A∣=0|A|=0∣A∣=0 解出参数值，这些值下线性相关，其余值下线性无关；
  3. 若个数与维数不相等，不能用行列式，直接对 AAA 作行变换，看非零行数是否小于向量个数；
  4. 边界参数值必须代回原向量组，指出具体的相关关系（常见的是成比例或者和为零），只写"相关"拿不到分。

例题

讨论 α1=(1,1,t)T\alpha_1=(1,1,t)^Tα1​=(1,1,t)T，α2=(1,t,1)T\alpha_2=(1,t,1)^Tα2​=(1,t,1)T，α3=(t,1,1)T\alpha_3=(t,1,1)^Tα3​=(t,1,1)T 的线性相关性。

三个向量都是 333 维的，拼成方阵算行列式：

∣A∣=∣11t1t1t11∣=(t−1)−(1−t)+t(1−t2)=−t3+3t−2=−(t−1)2(t+2).|A|=\begin{vmatrix}1&1&t\\1&t&1\\t&1&1\end{vmatrix} =(t-1)-(1-t)+t(1-t^2)=-t^3+3t-2=-(t-1)^2(t+2).∣A∣=​11t​1t1​t11​​=(t−1)−(1−t)+t(1−t2)=−t3+3t−2=−(t−1)2(t+2).

所以 ∣A∣≠0|A|\ne0∣A∣=0，即 t≠1t\ne1t=1 且 t≠−2t\ne-2t=−2 时，α1,α2,α3\alpha_1,\alpha_2,\alpha_3α1​,α2​,α3​ 线性无关。再看两个根：

  • t=1t=1t=1：三个向量都是 (1,1,1)T(1,1,1)^T(1,1,1)T，彼此相等，线性相关；
  • t=−2t=-2t=−2：α1+α2+α3=(0,0,0)T\alpha_1+\alpha_2+\alpha_3=(0,0,0)^Tα1​+α2​+α3​=(0,0,0)T，系数全为 111 且不全为零，线性相关。

结论：t≠1t\ne1t=1 且 t≠−2t\ne-2t=−2 时线性无关，t=1t=1t=1 或 t=−2t=-2t=−2 时线性相关。参数值要代回验证，只报"相关"或"无关"都不算完整。
