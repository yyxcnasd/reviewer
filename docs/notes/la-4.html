4.1 矩阵的秩

行秩等于列秩，三种刻画

设 A∈Rm×nA\in\mathbb{R}^{m\times n}A∈Rm×n。行向量组的秩叫行秩，列向量组的秩叫列秩，两者总相等，统称矩阵的秩 rank⁡(A)\operatorname{rank}(A)rank(A)。并且 0≤rank⁡(A)≤min⁡{m,n}0\le\operatorname{rank}(A)\le\min\{m,n\}0≤rank(A)≤min{m,n}；nnn 阶方阵满足 rank⁡(A)=n\operatorname{rank}(A)=nrank(A)=n 时叫满秩，否则叫降秩。

三种等价刻画：

  • rank⁡(A)=r\operatorname{rank}(A)=rrank(A)=r   ⟺  \iff⟺ 存在 rrr 阶非零子式，且所有 r+1r+1r+1 阶子式为零；
  • rank⁡(A)\operatorname{rank}(A)rank(A) 等于相抵标准形 (Er000)\begin{pmatrix}E_r&0\\0&0\end{pmatrix}(Er​0​00​) 中 111 的个数；
  • rank⁡(A)\operatorname{rank}(A)rank(A) 等于列向量组（也等于行向量组）的极大无关组所含向量的个数。

什么时候用：算秩靠第一条与阶梯形；说理时用第三条，"秩 = 极大无关组的大小"。

用阶梯形求秩

步骤：初等行变换化阶梯形 → 数非零行 → 非零行数就是秩。

什么时候用：几乎所有求秩的题都这么做；要找极大无关组就继续化行最简形，主元列对应的原向量就是极大无关组。

注意

数的是非零行，不是非零列；初等变换不改变秩，换行、倍加都可以放心做。对 nnn 阶方阵还有 rank⁡(A)=n  ⟺  ∣A∣≠0  ⟺  A\operatorname{rank}(A)=n\iff\left|A\right|\ne0\iff Arank(A)=n⟺∣A∣=0⟺A 可逆。

例

A=(123456)A=\begin{pmatrix}1&2&3\\4&5&6\end{pmatrix}A=(14​25​36​)，第二行减第一行的 444 倍得 (0,−3,−6)(0,-3,-6)(0,−3,−6)，非零行 222 行，所以 rank⁡(A)=2\operatorname{rank}(A)=2rank(A)=2。

秩的三条不等式

设 A∈Rm×nA\in\mathbb{R}^{m\times n}A∈Rm×n，B∈Rn×sB\in\mathbb{R}^{n\times s}B∈Rn×s，则

rank⁡(A+B)≤rank⁡(A)+rank⁡(B),\operatorname{rank}(A+B)\le\operatorname{rank}(A)+\operatorname{rank}(B),rank(A+B)≤rank(A)+rank(B),

rank⁡(AB)≤min⁡{rank⁡(A),rank⁡(B)},\operatorname{rank}(AB)\le\min\{\operatorname{rank}(A),\operatorname{rank}(B)\},rank(AB)≤min{rank(A),rank(B)},

rank⁡(AB)≥rank⁡(A)+rank⁡(B)−n.\operatorname{rank}(AB)\ge\operatorname{rank}(A)+\operatorname{rank}(B)-n.rank(AB)≥rank(A)+rank(B)−n.

最后一个叫 Sylvester 不等式。另有两条：AAA 列满秩时 rank⁡(AB)=rank⁡(B)\operatorname{rank}(AB)=\operatorname{rank}(B)rank(AB)=rank(B)，BBB 行满秩时 rank⁡(AB)=rank⁡(A)\operatorname{rank}(AB)=\operatorname{rank}(A)rank(AB)=rank(A)。

什么时候用：估上界用前两条；要下界、或由 AB=0AB=0AB=0 得到 rank⁡(A)+rank⁡(B)≤n\operatorname{rank}(A)+\operatorname{rank}(B)\le nrank(A)+rank(B)≤n 时用 Sylvester。

另外两条常见：rank⁡(A⊤)=rank⁡(A)\operatorname{rank}(A^{\top})=\operatorname{rank}(A)rank(A⊤)=rank(A)；rank⁡(A00B)=rank⁡(A)+rank⁡(B)\operatorname{rank}\begin{pmatrix}A&0\\0&B\end{pmatrix}=\operatorname{rank}(A)+\operatorname{rank}(B)rank(A0​0B​)=rank(A)+rank(B)。

子式决定秩

rank⁡(A)=k\operatorname{rank}(A)=krank(A)=k 的含义是：存在 kkk 阶非零子式，并且所有 k+1k+1k+1 阶子式为零。

什么时候用：证 rank⁡(A)≥k\operatorname{rank}(A)\ge krank(A)≥k 只需找一个 kkk 阶非零子式；证 rank⁡(A)≤k\operatorname{rank}(A)\le krank(A)≤k 必须说明所有 k+1k+1k+1 阶子式为零。

注意

最高阶行列式为零只说明秩小于 nnn，降到几还要看低阶子式，别顺手写"秩是 n−1n-1n−1"。

例

三阶矩阵若第三行是前两行之和，则三阶子式为零，秩不超过 222；而前两行不成比例时秩恰为 222。

伴随矩阵的秩：三种情况

对 nnn 阶方阵 AAA：

rank⁡(A∗)={n,rank⁡(A)=n,1,rank⁡(A)=n−1,0,rank⁡(A)≤n−2.\operatorname{rank}(A^*)=\begin{cases} n, & \operatorname{rank}(A)=n,\\ 1, & \operatorname{rank}(A)=n-1,\\ 0, & \operatorname{rank}(A)\le n-2. \end{cases}rank(A∗)=⎩⎨⎧​n,1,0,​rank(A)=n,rank(A)=n−1,rank(A)≤n−2.​

什么时候用：题目给 rank⁡(A)=n−1\operatorname{rank}(A)=n-1rank(A)=n−1 求 A∗A^*A∗ 的秩，直接答 111。

理由：由 AA∗=∣A∣EAA^*=\left|A\right|EAA∗=∣A∣E。∣A∣≠0\left|A\right|\ne0∣A∣=0 时 A∗A^*A∗ 可逆；∣A∣=0\left|A\right|=0∣A∣=0 时 AA∗=0AA^*=0AA∗=0，Sylvester 给 rank⁡(A)+rank⁡(A∗)≤n\operatorname{rank}(A)+\operatorname{rank}(A^*)\le nrank(A)+rank(A∗)≤n，再看 A∗A^*A∗ 是否为零矩阵，定出 111 或 000。

4.2 齐次与非齐次线性方程组解的结构

齐次组：解空间维数是 n−rn-rn−r

Ax=0Ax=0Ax=0 的解集 N(A)N(A)N(A) 对加法与数乘封闭，是 Rn\mathbb{R}^nRn 的子空间，且

dim⁡N(A)=n−rank⁡(A).\dim N(A)=n-\operatorname{rank}(A).dimN(A)=n−rank(A).

什么时候用：判齐次组有没有非零解——rank⁡(A)<n\operatorname{rank}(A)<nrank(A)<n 就有非零解，自由未知量正好 n−rn-rn−r 个。

例

n=4n=4n=4、rank⁡(A)=2\operatorname{rank}(A)=2rank(A)=2 时，基础解系恰含 222 个向量。

基础解系的三步求法

  1. 把 AAA 化成行最简形，定出主元列与自由未知量（共 n−rn-rn−r 个）；
  2. 让自由未知量依次取"一个为 111、其余为 000"，回代求主元未知量，得到 n−rn-rn−r 个解；
  3. 这 n−rn-rn−r 个解就是基础解系，齐次通解为

x=c1ξ1+c2ξ2+⋯+cn−rξn−r.x=c_1\xi_1+c_2\xi_2+\cdots+c_{n-r}\xi_{n-r}.x=c1​ξ1​+c2​ξ2​+⋯+cn−r​ξn−r​.

什么时候用：写齐次组通解，或给非齐次组找导出组的解时。

解空间里取一组基，就是基础解系；所以"基础解系"与"解空间的基"是同一件事，个数都是 n−rn-rn−r。

注意

基础解系必须恰好 n−rn-rn−r 个且线性无关，少一个、或者取成相关的都不算。

求出后把每个 ξi\xi_iξi​ 代回 Aξi=0A\xi_i=0Aξi​=0 验一遍，比逐步检查回代过程快。

非齐次组：比较两个秩

对 Ax=bAx=bAx=b：

  • rank⁡(A)<rank⁡(A∣b)\operatorname{rank}(A)<\operatorname{rank}(A\mid b)rank(A)<rank(A∣b) 时无解；
  • rank⁡(A)=rank⁡(A∣b)=n\operatorname{rank}(A)=\operatorname{rank}(A\mid b)=nrank(A)=rank(A∣b)=n 时唯一解；
  • rank⁡(A)=rank⁡(A∣b)=r<n\operatorname{rank}(A)=\operatorname{rank}(A\mid b)=r<nrank(A)=rank(A∣b)=r<n 时无穷多解，自由未知量 n−rn-rn−r 个。

什么时候用：凡是问"解的个数"，先算这两个秩；rank⁡(A∣b)\operatorname{rank}(A\mid b)rank(A∣b) 最多比 rank⁡(A)\operatorname{rank}(A)rank(A) 大 111。

解题顺序：写 (A∣b)(A\mid b)(A∣b) → 化行最简形 → 数两个秩 → 定解的个数 → 写自由未知量 → 取特解与基础解系。

注意

不能只看"方程个数等于未知量个数"就说唯一解，必须比较秩。

通解 = 特解 + 导出组通解

若 η\etaη 是 Ax=bAx=bAx=b 的一个特解，ξ1,…,ξn−r\xi_1,\dots,\xi_{n-r}ξ1​,…,ξn−r​ 是 Ax=0Ax=0Ax=0 的基础解系，则

x=η+c1ξ1+c2ξ2+⋯+cn−rξn−r.x=\eta+c_1\xi_1+c_2\xi_2+\cdots+c_{n-r}\xi_{n-r}.x=η+c1​ξ1​+c2​ξ2​+⋯+cn−r​ξn−r​.

什么时候用：非齐次组写通解就是这个结构；两个非齐次解之差必是导出组的解，可用来验算。

注意

非齐次解的线性组合 ∑ikiηi\sum_i k_i\eta_i∑i​ki​ηi​ 仍是解，当且仅当 ∑iki=1\sum_i k_i=1∑i​ki​=1。

例

η1,η2\eta_1,\eta_2η1​,η2​ 都是 Ax=bAx=bAx=b 的解时，2η1−η22\eta_1-\eta_22η1​−η2​ 也是解（系数和 2−1=12-1=12−1=1），而 η1+η2\eta_1+\eta_2η1​+η2​ 一般不是。

常见问法与易错点

  • 求秩只数阶梯形的非零行；"最高阶子式为零"推不出"秩是 n−1n-1n−1"。
  • rank⁡(A+B)≤rank⁡(A)+rank⁡(B)\operatorname{rank}(A+B)\le\operatorname{rank}(A)+\operatorname{rank}(B)rank(A+B)≤rank(A)+rank(B) 管和，rank⁡(AB)≤min⁡{rank⁡(A),rank⁡(B)}\operatorname{rank}(AB)\le\min\{\operatorname{rank}(A),\operatorname{rank}(B)\}rank(AB)≤min{rank(A),rank(B)} 管积，别混。
  • 由 AB=0AB=0AB=0 得 rank⁡(A)+rank⁡(B)≤n\operatorname{rank}(A)+\operatorname{rank}(B)\le nrank(A)+rank(B)≤n，这是 Sylvester 最常用的形式。
  • 齐次组的自由未知量个数、基础解系个数、n−rank⁡(A)n-\operatorname{rank}(A)n−rank(A) 是同一个数，且解向量必须线性无关。
  • 非齐次通解别漏特解；解的组合系数之和为 111 的才是解。
  • rank⁡(A)=n−1\operatorname{rank}(A)=n-1rank(A)=n−1 时 rank⁡(A∗)=1\operatorname{rank}(A^*)=1rank(A∗)=1，不是 000，也不是 nnn。
  • 判"解的个数"先算 rank⁡(A)\operatorname{rank}(A)rank(A) 与 rank⁡(A∣b)\operatorname{rank}(A\mid b)rank(A∣b)，两者相等才有解。
  • 求伴随矩阵的秩，先看 rank⁡(A)\operatorname{rank}(A)rank(A) 是满秩、n−1n-1n−1 还是更小，三种情况对应 n,1,0n,1,0n,1,0。
