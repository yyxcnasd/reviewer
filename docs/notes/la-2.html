2.1 矩阵及其运算

乘法：不交换、无零因子、无消去律

设 AAA 是 m×sm\times sm×s 的、BBB 是 s×ns\times ns×n 的，则 ABABAB 是 m×nm\times nm×n 的：

(AB)ij=∑k=1saikbkj.(AB)_{ij}=\sum_{k=1}^{s}a_{ik}b_{kj}.(AB)ij​=k=1∑s​aik​bkj​.

什么时候用：先核对形状再乘；结果第 iii 行第 jjj 列，就是 AAA 的第 iii 行与 BBB 的第 jjj 列对应相乘再相加。

三条常考的"不成立"：AB≠BAAB\ne BAAB=BA；AB=0AB=0AB=0 推不出 A=0A=0A=0 或 B=0B=0B=0；AB=ACAB=ACAB=AC 且 A≠0A\ne0A=0 也推不出 B=CB=CB=C。例：

(1111)(1−1−11)=(0000).\begin{pmatrix}1&1\\1&1\end{pmatrix} \begin{pmatrix}1&-1\\-1&1\end{pmatrix} =\begin{pmatrix}0&0\\0&0\end{pmatrix}.(11​11​)(1−1​−11​)=(00​00​).

注意

能从 AB=ACAB=ACAB=AC 两边消去 AAA 的唯一情形是 AAA 可逆。

转置反序与对称矩阵

(AB)⊤=B⊤A⊤,(A⊤)⊤=A,(A+B)⊤=A⊤+B⊤.(AB)^{\top}=B^{\top} A^{\top},\qquad (A^{\top})^{\top}=A,\qquad (A+B)^{\top}=A^{\top}+B^{\top}.(AB)⊤=B⊤A⊤,(A⊤)⊤=A,(A+B)⊤=A⊤+B⊤.

什么时候用：见到乘积的转置一律反序；顺序写错，整道题都错。

对称矩阵是 A⊤=AA^{\top}=AA⊤=A，反对称矩阵是 A⊤=−AA^{\top}=-AA⊤=−A；反对称矩阵的主对角线元素全为 000。

幂与二项式展开的条件

AkAl=Ak+lA^kA^l=A^{k+l}AkAl=Ak+l，(Ak)l=Akl(A^k)^l=A^{kl}(Ak)l=Akl，但一般 (AB)k≠AkBk(AB)^k\ne A^kB^k(AB)k=AkBk。只有 AB=BAAB=BAAB=BA 时才能用二项式：

(A+B)n=∑k=0n(nk)AkBn−k.(A+B)^n=\sum_{k=0}^{n}\binom nk A^kB^{n-k}.(A+B)n=k=0∑n​(kn​)AkBn−k.

什么时候用：求 AnA^nAn 有三条路——算低次幂找规律再归纳；A=E+NA=E+NA=E+N 且 NNN 幂零时用二项式；A=αβ⊤A=\alpha\beta^{\top}A=αβ⊤ 时 β⊤α\beta^{\top}\alphaβ⊤α 是一个数，An=(β⊤α)n−1AA^n=(\beta^{\top}\alpha)^{n-1}AAn=(β⊤α)n−1A。

行列式的乘性

∣AB∣=∣A∣∣B∣,∣A⊤∣=∣A∣,∣kA∣=kn∣A∣(A 为 n 阶).\left|AB\right|=\left|A\right|\left|B\right|,\qquad \left|A^{\top}\right|=\left|A\right|,\qquad \left|kA\right|=k^n\left|A\right|\quad(A\text{ 为 }n\text{ 阶}).∣AB∣=∣A∣∣B∣,​A⊤​=∣A∣,∣kA∣=kn∣A∣(A 为 n 阶).

什么时候用：把乘积的行列式拆成行列式之积，是算 ∣An∣\left|A^n\right|∣An∣、判断乘积可逆的主力。

注意

∣A+B∣≠∣A∣+∣B∣\left|A+B\right|\ne\left|A\right|+\left|B\right|∣A+B∣=∣A∣+∣B∣；∣kA∣\left|kA\right|∣kA∣ 是 kn∣A∣k^n\left|A\right|kn∣A∣，不是 k∣A∣k\left|A\right|k∣A∣。

2.2 逆矩阵

伴随矩阵与两条基本恒等式

把代数余子式排成矩阵再转置，得伴随矩阵 A∗=(Aij)⊤A^*=(A_{ij})^{\top}A∗=(Aij​)⊤，即 A∗A^*A∗ 的第 iii 行第 jjj 列是 AjiA_{ji}Aji​。

AA∗=A∗A=∣A∣E,∣A∗∣=∣A∣n−1.AA^*=A^*A=\left|A\right|E,\qquad \left|A^*\right|=\left|A\right|^{n-1}.AA∗=A∗A=∣A∣E,∣A∗∣=∣A∣n−1.

什么时候用：求逆、算 ∣A∗∣\left|A^*\right|∣A∗∣、证明 AAA 不可逆，都从第一式出发。

注意

A∗A^*A∗ 的元素是"先算 AijA_{ij}Aij​、再转置"；另外全体代数余子式之和 ∑ijAij\sum_{ij}A_{ij}∑ij​Aij​ 是 A∗A^*A∗ 全部元素之和，不是 ∣A∗∣\left|A^*\right|∣A∗∣。

逆矩阵公式与二阶速记

∣A∣≠0\left|A\right|\ne0∣A∣=0 时

A−1=1∣A∣A∗.A^{-1}=\frac{1}{\left|A\right|}A^*.A−1=∣A∣1​A∗.

二阶直接套：

(abcd)−1=1ad−bc(d−b−ca).\begin{pmatrix}a&b\\c&d\end{pmatrix}^{-1}=\frac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}.(ac​bd​)−1=ad−bc1​(d−c​−ba​).

什么时候用：二阶、三阶且 ∣A∣\left|A\right|∣A∣ 好算时用伴随法；阶数一高就改用初等变换（见 2.5）。

可逆的等价条件清单

对 nnn 阶方阵 AAA，下面每条都等价：

  • ∣A∣≠0\left|A\right|\ne0∣A∣=0；
  • AAA 可逆，A−1A^{-1}A−1 存在；
  • Ax=0Ax=0Ax=0 只有零解，且对任意 bbb，Ax=bAx=bAx=b 有唯一解；
  • AAA 的 nnn 个列向量（行向量）线性无关；
  • rank⁡(A)=n\operatorname{rank}(A)=nrank(A)=n；
  • AAA 与 EEE 相抵，即 AAA 是有限个初等矩阵的乘积。

什么时候用：证明"可逆"时挑最容易验证的一条；要判不可逆，就找一个非零解或算 ∣A∣=0\left|A\right|=0∣A∣=0。

2.3 分块矩阵

分块乘法的匹配条件

只要左矩阵对列的分法与右矩阵对行的分法一致，小块就可以按"数"来乘：

(A11A12A21A22)(B11B12B21B22)=(A11B11+A12B21A11B12+A12B22A21B11+A22B21A21B12+A22B22).\begin{pmatrix}A_{11}&A_{12}\\A_{21}&A_{22}\end{pmatrix} \begin{pmatrix}B_{11}&B_{12}\\B_{21}&B_{22}\end{pmatrix} =\begin{pmatrix}A_{11}B_{11}+A_{12}B_{21}&A_{11}B_{12}+A_{12}B_{22}\\ A_{21}B_{11}+A_{22}B_{21}&A_{21}B_{12}+A_{22}B_{22}\end{pmatrix}.(A11​A21​​A12​A22​​)(B11​B21​​B12​B22​​)=(A11​B11​+A12​B21​A21​B11​+A22​B21​​A11​B12​+A12​B22​A21​B12​+A22​B22​​).

什么时候用：矩阵里零块多，或题目的行、列天然分段。

准对角与上三角块求逆

(A00B)−1=(A−100B−1),\begin{pmatrix}A&0\\0&B\end{pmatrix}^{-1}=\begin{pmatrix}A^{-1}&0\\0&B^{-1}\end{pmatrix},(A0​0B​)−1=(A−10​0B−1​),

(AC0B)−1=(A−1−A−1CB−10B−1).\begin{pmatrix}A&C\\0&B\end{pmatrix}^{-1}=\begin{pmatrix}A^{-1}&-A^{-1}CB^{-1}\\0&B^{-1}\end{pmatrix}.(A0​CB​)−1=(A−10​−A−1CB−1B−1​).

什么时候用：有明显零块时分块求逆比整体消元快得多。

注意

右上角的负号与 A−1CB−1A^{-1}CB^{-1}A−1CB−1 的先后顺序都不能动；记不住就设未知块乘原矩阵解出来。

分块对角的行列式

∣A00B∣=∣A∣∣B∣.\begin{vmatrix}A&0\\0&B\end{vmatrix}=\left|A\right|\left|B\right|.​A0​0B​​=∣A∣∣B∣.

什么时候用：矩阵能分成两块互不相干的部分，行列式直接乘。

2.4 初等变换与初等矩阵

三类初等矩阵与左右乘的对应

对 EEE 作一次初等变换得到初等矩阵：换行得 PijP_{ij}Pij​，第 iii 行乘 k≠0k\ne0k=0 得 Pi(k)P_i(k)Pi​(k)，第 jjj 行的 kkk 倍加到第 iii 行得 Pij(k)P_{ij}(k)Pij​(k)。

左乘 PPP 等于对 AAA 作同一种行变换，右乘等于作同一种列变换：

PijA 换 A 的两行,APij 换 A 的两列.P_{ij}A\ \text{换 }A\text{ 的两行},\qquad AP_{ij}\ \text{换 }A\text{ 的两列}.Pij​A 换 A 的两行,APij​ 换 A 的两列.

什么时候用：证明题里把"作了一次变换"翻译成"乘了一个可逆矩阵"，就能用矩阵等式推理。

初等矩阵的逆仍是同类

Pij−1=Pij,Pi(k)−1=Pi(1/k),Pij(k)−1=Pij(−k).P_{ij}^{-1}=P_{ij},\qquad P_i(k)^{-1}=P_i(1/k),\qquad P_{ij}(k)^{-1}=P_{ij}(-k).Pij−1​=Pij​,Pi​(k)−1=Pi​(1/k),Pij​(k)−1=Pij​(−k).

什么时候用：反推变换方向，或证明初等矩阵都可逆。这条也说明"相抵"是对称关系。

可逆等价于有限个初等矩阵之积

AAA 可逆，当且仅当 AAA 是有限个初等矩阵的乘积。理由：AAA 可逆时能用行变换化成 EEE，每一步对应左乘一个初等矩阵，Ps⋯P1A=EP_s\cdots P_1A=EPs​⋯P1​A=E，两端取逆即得。

什么时候用：凡涉及"相抵""初等变换"的证明，背后都是这一条。

2.5 矩阵的相抵与相抵标准形

相抵的定义与不变量

AAA 经有限次初等变换化成 BBB，称 AAA 与 BBB 相抵，记 A∼BA\sim BA∼B。相抵是等价关系：自反、对称、传递。

什么时候用：判断两个矩阵"像不像"看它们的标准形；相抵不改变秩，秩就是它的不变量。

相抵标准形

任意 m×nm\times nm×n 矩阵都相抵于

(Er000),\begin{pmatrix}E_r&0\\0&0\end{pmatrix},(Er​0​00​),

其中 r=rank⁡(A)r=\operatorname{rank}(A)r=rank(A)（第 4 章）。两个同型矩阵相抵，当且仅当它们的相抵标准形相同。

什么时候用：求标准形、判断同型矩阵是否相抵。

用初等变换求逆与化标准形

求逆：并排写 (A∣E)(A\mid E)(A∣E)，只用行变换把左边化成 EEE，右边同时变成 A−1A^{-1}A−1：

(A∣E) ⟶ (E∣A−1).(A\mid E)\ \longrightarrow\ (E\mid A^{-1}).(A∣E) ⟶ (E∣A−1).

化标准形：行、列变换都可以用，拿左上角的非零元清掉它所在的行与列，再对右下子块重复，最后把主元化成 111。

什么时候用：三阶以上求逆首选 (A∣E)(A\mid E)(A∣E) 法；左边化不出 EEE（出现零行）就说明 ∣A∣=0\left|A\right|=0∣A∣=0，不可逆。

常见问法与易错点

  • (AB)⊤=B⊤A⊤(AB)^{\top}=B^{\top} A^{\top}(AB)⊤=B⊤A⊤ 顺序反了是最常见的错；(ABC)⊤=C⊤B⊤A⊤(ABC)^{\top}=C^{\top} B^{\top} A^{\top}(ABC)⊤=C⊤B⊤A⊤ 同理。
  • ∣kA∣=kn∣A∣\left|kA\right|=k^n\left|A\right|∣kA∣=kn∣A∣：指数是阶数 nnn，不是 111。
  • 伴随矩阵先算代数余子式再转置；∣A∗∣=∣A∣n−1\left|A^*\right|=\left|A\right|^{n-1}∣A∗∣=∣A∣n−1，不是 ∣A∣\left|A\right|∣A∣。
  • ∣A+B∣≠∣A∣+∣B∣\left|A+B\right|\ne\left|A\right|+\left|B\right|∣A+B∣=∣A∣+∣B∣，而 ∣AB∣=∣A∣∣B∣\left|AB\right|=\left|A\right|\left|B\right|∣AB∣=∣A∣∣B∣：两个方向别记混。
  • 求逆先验 ∣A∣≠0\left|A\right|\ne0∣A∣=0；化 (A∣E)(A\mid E)(A∣E) 时只许用行变换。
  • 分块求逆的右上角是 −A−1CB−1-A^{-1}CB^{-1}−A−1CB−1，负号与顺序都要对。
